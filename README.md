# 进阶数字支持（ihr360-faq-thinking）v0.1

**i人事（iHR360）业务分析思考引导技能（Skill）**

面向「i人事」HR SaaS 平台的业务分析助手技能：当用户询问某个考勤/薪资/组织等字段或指标"怎么算、为什么是这个数"时，引导 AI 还原计算链、定位配置依赖、暴露口径歧义、给出查证路径，输出结构化的分析结论。

## 定位

- **思考引导型 Skill**：产出"分析思路与答案"，而非页面
- 覆盖口径溯源、异常诊断、趋势归因、操作指引四类问题
- 与「页面生成型」Skill（rowan-ihr360-openapi-skill）互补：前者讲道理，后者摆数据

## 核心能力

1. **口径溯源**：字段/指标"怎么算"——区分内置字段（文档口径）与自定义字段（API 公式），还原计算链
2. **异常诊断**：考勤异常/操作被拦——数据溯源 + 鱼骨图排查法（按"用户自查→系统配置"逐类排查）
3. **流程走向**：具体员工发起某审批走哪条分支——员工定位 → 属性匹配 → 条件分支 → 输出 Mermaid 全流程图（命中分支高亮）
4. **假期余额**：余额快照 + 规则 + 额度变更流水还原完整计算链
5. **薪资公式**：按员工+方案+月份还原公式并验证数值

## 数据来源约定

- **接口规格**：本地 `api-handbook/`（99+ 接口文档，双向同步自 API 参考手册）
- **业务口径**：官方语雀知识库（`ihr360.yuque.com/ihr/help` 与 `/ihr/faq`）——优先走 `query_faq` 官方搜索接口（`IHR360_API_TOKEN` 环境变量鉴权，勿硬编码）
- **字段公式**：内置字段走文档；自定义字段公式+值走 API

## 使用前提

- 宿主 AI 环境需具备：联网抓取能力（WebFetch）+ `IHR360_API_TOKEN` 环境变量
- OAuth 客户端凭证（AppID/AppSecret）由客户开放平台提供，用于 OpenAPI 全量接口
