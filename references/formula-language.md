# iHR360 公式语言参考手册

> iHR360 系统内置的薪资/考勤/人事计算公式语言。本文档定义完整的词法、语法、函数签名及格式化规范。

---

## 一、词法规则（Lexer）

### 1.1 Token 类型

| 类型 | 优先级 | 正则 / 规则 | 示例 |
|------|--------|-------------|------|
| `str` | 1 | `"…"` 之间的所有字符，不支持转义 | `"全职A"` |
| `fn` | 2 | `[A-Za-z_][A-Za-z0-9_]*` 且后跟 `(` | `IF`, `CHOOSE`, `SEARCH` |
| `field` | 3 | `表名$字段名`，表名可含中文 | `员工基本信息$员工类型` |
| `num` | 4 | `-?\d+(\.\d+)?` | `100`, `0.5`, `-1` |
| `word` | 5 | 中英文/数字/下划线组成的词 | `薪资所属月`, `员工类型` |
| `ws` | 6 | `\s` 空白直接跳过 | 空格、换行、Tab |
| `ch` | 7 | 单字符运算符或分隔符 | `(`, `)`, `{`, `}`, `,`, `+`, `-`, `*`, `/`, `=`, `<`, `>`, `!` |

### 1.2 字段引用规则

```
表名$字段名
```

- 表名：以中文/字母/下划线开头，后跟中文/字母/数字/下划线
- `$` 分隔符
- 字段名：中文/字母/数字/下划线（不能以数字开头）

常见字段表名：
- `员工基本信息` — 姓名、员工类型、转正日期、部门名称、员工编号等
- `员工薪资` — 岗位工资、试用期岗位工资等
- `考勤` — 法定工作日天数、实际计薪正班工时、年假、哺乳假、婚假、计薪产假、工伤假、丧假等
- `薪资所属月` — 薪资核算月份

### 1.3 运算符

| 类别 | 符号 |
|------|------|
| 算术 | `+`, `-`, `*`, `/` |
| 比较 | `=`, `>`, `<`, `>=`, `<=`, `<>`（不等） |
| 其他 | `,`（参数分隔）、`(` `)`（函数/分组）、`{` `}`（数组字面量） |

## 二、语法结构

### 2.1 BNF 概要

```
Expr       → FuncCall | Group | ArrayLiteral | Field | Number | String | Word | BinaryOp
FuncCall   → Name '(' ArgList ')'
ArgList    → Expr (',' Expr)*
Group      → '(' Expr (',' Expr)* ')'
ArrayLiteral → '{' Expr (',' Expr)* '}'
BinaryOp   → Expr Operator Expr
```

### 2.2 AST 节点类型

| 节点 | 属性 | 说明 |
|------|------|------|
| `call` | `name`, `args: Node[][]` | 函数调用，`args` 的每个元素是一个 Node 数组 |
| `arr` | `items: Node[][]` | 数组字面量 `{...}` |
| `grp` | `inner: Node[]` | 括号分组 `(...)` |
| `tok` | `tk: Token` | 原子 token（字段、数字、字符串、运算符等） |

### 2.3 解析规则

- 顶层表达式可以是逗号分隔的多个 Expr
- `parseExpr()` 循环读取 token，按优先级：
  1. 遇到 `fn` 类型 token + 后跟 `(` → 创建 `call` 节点并递归解析参数
  2. 遇到 `{` → 创建 `arr` 节点
  3. 遇到 `(` → 创建 `grp` 节点
  4. 其余 → 创建 `tok` 节点
- 参数分隔符为 `,`
- 有死循环保护（跳过连续 5 次未推进的 token）
- 嵌套深度上限为 60 层，超过时截断显示

## 五、错误校验

### 5.1 括号 / 引号匹配

| 错误类型 | 检测规则 |
|----------|---------|
| `extra_rparen` | `)` 前没有匹配的 `(` |
| `extra_rbrace` | `}` 前没有匹配的 `{` |
| `unclosed_lparen` | `(` 后缺少 `)` |
| `unclosed_lbrace` | `{` 后缺少 `}` |
| `unclosed_quote` | `"` 后缺少闭合引号 |

### 5.2 函数参数校验

按函数签名表逐节点校验，规则互斥（命中一条即跳过后续）：
- `fn_exact_args` — 精确参数个数不匹配
- `fn_min_args` — 参数少于最小值
- `fn_max_args` — 参数多于最大值
- `fn_pairs` — 参数不成对（如 IFS / COUNTIFS）

### 5.3 SEARCH 用法校验

**强制规则**：`SEARCH(...)` 的返回值必须与 `>0` 比较。
- 正确的写法：`IF(SEARCH(字段, "关键词")>0, "匹配", "不匹配")`
- 错误的写法：`IF(SEARCH(字段, "关键词"), "匹配", "不匹配")`
- 因为 SEARCH 返回的是位置（从 1 开始），未找到时返回错误，所以必须显式比较 `>0`

## 六、逻辑树语义识别

格式化后的公式可解析为中文理解的逻辑树，识别以下模式：

### 6.1 IF 分支结构
- `IF(条件, 真值, 假值)` → 条件分支 / ✅ 为真 / ❌ 为假 三段式

### 6.2 CHOOSE-MATCH 多路选择
- `CHOOSE(MATCH(1=1, {条件1, 条件2, ...}), {值1, 值2, ...}, 默认值)` 
- MATCH(1=1) 识别为"查找第一个为真的条件"
- CHOOSE 展开每个选项编号

### 6.3 AND-OR 条件组合
- `AND(条件1, 条件2)` — 展开每个子条件
- `OR(条件1, 条件2)` — 展开每个子条件
- `AND(YEAR(A)=YEAR(B), MONTH(A)=MONTH(B))` → 识别为"同年且同月"

### 6.4 比较运算语义
| 模式 | 识别为 |
|------|--------|
| `YEAR(A) = YEAR(B)` | 同年 |
| `MONTH(A) = MONTH(B)` | 同月 |
| `DAY(A) = DAY(B)` | 同日 |
| `字段 = 值` | 等于比较 |

## 八、典型公式场景

### 8.1 薪资计算（转正员工工资）

```iHR360
IF(
  AND(
    员工基本信息$员工类型 = "全职A",
    员工基本信息$员工类型 = "全职B"
  ),
  CHOOSE(
    MATCH(1=1, {
      (MONTH(员工基本信息$转正日期) - 薪资所属月) < 0,
      (MONTH(员工基本信息$转正日期) - 薪资所属月) = 0,
      (MONTH(员工基本信息$转正日期) - 薪资所属月) > 0
    }),
    { …试用期工资计算…, …转正当月折算…, …正式工资… },
    0
  ),
  CHOOSE(…非全职条件…)
)
```

### 8.2 部门判断

```iHR360
IF(SEARCH(员工基本信息$部门名称, "技术部") > 0, "是", "否")
```

### 8.3 年假计算

```iHR360
DATEDIF(员工基本信息$入职日期, TODAY(), "Y")
```

### 8.4 ★迟到分档处罚（CHOOSE-MATCH 多档次实战，2026-08-13）

**规则**（客户实际场景，字段名 m=分钟/h=小时）：
- ① 迟到 10m 内次数 >3：每超 1 次扣 20 元（前 3 次豁免）
- ② 10~30m 每次：扣 100 元（⚠️ 占位金额，按 HR 规则替换）
- ③ 30~60m 每次：扣 200 元
- ④ 1~3h 每次：扣 500 元
- ⑤ 3~8h 每次：扣 `薪资$绩效工资 × 3`（视为旷工 1 天）

```iHR360
CHOOSE(
  MATCH(1=1, {
    考勤$迟到10m内次数 > 3,
    考勤$迟到10到30m次数 > 0,
    考勤$迟到30到60m次数 > 0,
    考勤$迟到1到3h次数 > 0,
    考勤$迟到3到8h次数 > 0
  }),
  {
    (考勤$迟到10m内次数 - 3) * 20,
    考勤$迟到10到30m次数 * 100,
    考勤$迟到30到60m次数 * 200,
    考勤$迟到1到3h次数 * 500,
    考勤$迟到3到8h次数 * 薪资$绩效工资 * 3
  },
  0
)
```

> **要点**：
> 1. MATCH 按顺序取首个命中分支（多档互斥，不会叠加扣款）
> 2. 全部不命中 → CHOOSE 默认 `0`（10m 内且 ≤3 次 = 不扣款）
> 3. 若规则按"时长"计（如"每超 1 分钟扣 X"），引用时长字段（如 `考勤$迟到10到30m时长 * X`）替代次数
> 4. 字段实际名以 i人事系统为准，本例为客户命名习惯（m=分钟/h=小时）
