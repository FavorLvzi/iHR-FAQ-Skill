# 假期设置 · 限制规则类型（二方接口）

> 接口编号：#111（03-Gateway接口 扩展）  
> 端点：`GET /web/gateway/attendance/api/leaveSetting/restriction/types`  
> Host：`v5.ihr360.com`  
> 鉴权：前端插件 Cookie+XSRF｜宿主 AI 环境：`Authorization: Bearer ${IHR360_API_TOKEN}`（环境变量自动注入，Base URL `v5.ihr360.com`）

---

## 描述

「假期设置」页面的限制规则类型查询。按 `vacationId` 查某假期的规则配置。

> ⚠️ 2026-08-04 抓包确认 URL 与参数，**响应结构待实测**（用户登录态下操作触发）。

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| vacationId | query | String | 是 | 假期类型 ID（如病假 `57aae9fcaac348b29713f11b0cc0748f`） |
| r_id | query | String | 是 | 租户/路由标识（如 `oqe0655893xl3tw5`） |
| u_id | query | String | 是 | 用户标识（如 `992311676526956544`） |

## 请求示例

```
GET /web/gateway/attendance/api/leaveSetting/restriction/types?vacationId=57aae9fcaac348b29713f11b0cc0748f&r_id=oqe0655893xl3tw5&u_id=992311676526956544
Host: v5.ihr360.com
```
