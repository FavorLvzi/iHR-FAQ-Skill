# 薪资项目 · 公式解析接口（二方，★ 问题4 核心）

> 二方 Gateway 接口（v5.ihr360.com），2026-08-06 抓包确认。
> **薪资项公式的可读来源**——响应 `exprItems` 是公式的 token 序列，可拼回完整公式文本！

---

## 端点

```
GET https://v5.ihr360.com/gateway/component/manage/api/component/table/manage/enable
    ?code=payroll.table.companysalaryfield
```
> `?r_id={requestId}&u_id={userId}` 是浏览器端追踪参数，**宿主 AI 调用可省略**，只需带 `?code=payroll.table.companysalaryfield`。

## 鉴权

- **前端插件（浏览器）**：Cookie + XSRF-TOKEN
- **宿主 AI 环境**：`Authorization: Bearer {IHR360_API_TOKEN}`（环境变量，v5.ihr360.com）
- 另见响应 Headers 中 `staffid: 81f9eea8-...`（当前登录员工），`authorization: authorization-text`

## 响应：data.exprItems[]（公式 token 流）

| 字段 | 说明 |
|------|------|
| exprCategory | **token 类型**：`FUNCTION` 函数 / `TOKEN` 括号逗号 / `CONSTANT` 常量 / `VARIABLE` 变量 / `BINARYOPERATOR` 二元运算符 |
| value | **公式原文**（可读，如 `IF`、`"居民"`、`当前累计应发月薪资合计`） |
| code | 变量内部码（如 `STAFF_ROSTER$taxrole`）；函数/常量时同 value |

**exprCategory 与 formula-language.md 词法对应**：FUNCTION→fn / TOKEN→ch / CONSTANT→str,num / VARIABLE→field / BINARYOPERATOR→ch。

## 实测样例（2026-08-06，还原后公式）

某薪资项公式（累计应纳税所得额，个税累计预扣用）：

```
MAX(0, IF(员工基本信息$纳税人身份 = "居民",
    (当前累计应发月薪资合计
     - IF(社保个人部分实际承担方 = "单位", 0, 当前累计社保个人合计)
     - IF(公积金个人部分实际承担方 = "单位", 0, 当前累计公积金个人合计)
     - 累计专项附加扣除及其他合计 - 当前累计减除费用 - 累计个人养老金扣除),
    (当月应发月薪资合计 - 当月月薪金减除费用)))
```

**变量 code 映射样例**：`员工基本信息$纳税人身份`→`STAFF_ROSTER$taxrole`、`当前累计应发月薪资合计`→`cumulativegrosssalary`、`社保个人部分实际承担方`→`eescactualpayer`、`当月应发月薪资合计`→`grosssalary`。

## ★ 薪资公式解读链路（问题4 完整闭环）

```

3. 值验证    → OpenAPI #67（按员工+方案+年月，91 项值 {'v':'xxx'}）

```
