> 接口编号：#112（03-Gateway接口 扩展）  
> 端点：`POST /web/gateway/attendance/api/limitutil/leaveSettingType`  
> Host：`v5.ihr360.com`  
> 鉴权：前端插件 Cookie+XSRF｜宿主 AI 环境：`Authorization: Bearer ${IHR360_API_TOKEN}`（环境变量自动注入，Base URL `v5.ihr360.com`）

---

## 描述

「假期余报表」页面加载时，先调用本接口获取**需要显示额度的假期类型列表**（含额度显示设置 `showLimitType`）。是报表页的前置配置接口，返回的每个假期类型决定后续按哪些类型查询额度明细。

## 响应数据

`data[]` 每项 = 假期类型配置，关键字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 假期类型 ID |
| leaveName | String | 假期名（年假/调休/全薪病假/婚假/育儿假/公休 + 自定义） |
| vacationType | String | 类型枚举（ANNUAL_LEAVE/ADJUST_REST/SICK_LEAVE/MARITAL_LEAVE/PARENTAL_LEAVE/SABBATICAL_LEAVE/USER_DEFINED_VACATION） |
| standardUnit / calculationUnit | String | 计发单位 DAY/HOUR |
| smallestUnit | Double | 最小申请单位（DAY 型=天数，HOUR 型=分钟数） |
| **showLimitType** | String | **额度显示方式：LIMIT_DETAIL（显示额度详情）** |
| limitApartShowType | String | 额度拆分显示：NO_APART |
| displayAtClient | Boolean | 是否客户端可见 |
| using | Boolean | 是否启用 |

## 对问题2 的价值

- **确认二方额度路径族**：`/web/gateway/attendance/api/limitutil/...` = 假期**额度/限额**相关接口（区别于 `leaveSetting/...` 的设置接口）
- 本接口只是"显示哪些类型"，**额度数字（发放/剩余）应由同路径族下的后续接口返回**，待继续抓包定位（如 `limitutil/limit/search`、`limitutil/report/...` 等）
- 13 种 vs OpenAPI #79 的 21 种：报表只显示配置了额度的类型，二者可交叉印证
