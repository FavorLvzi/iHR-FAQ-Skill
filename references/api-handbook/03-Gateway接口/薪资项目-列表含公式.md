# 薪资项目列表 · 含公式明文（二方，★ 问题4 核心）

> 二方 Gateway 接口（v5.ihr360.com），2026-08-06 抓包确认。
> **薪资项目全量列表，每个项目带 `formula` 明文公式**——问题4"公式从哪来"的最终答案！

---

## 端点

```
POST /gateway/payroll/api/companySalaryfieldMetas/list
     ?r_id={requestId}&u_id={userId}
```

## 鉴权

- **前端插件（浏览器）**：Cookie + XSRF-TOKEN
- **宿主 AI 环境**：`Authorization: Bearer {IHR360_API_TOKEN}`（环境变量，v5.ihr360.com）

## 请求体（分页）

```json
{ "current": 1, "size": 100 }   // ★ 实测：分页参数是 current/size（page/size 只返回第一页部分数据）
```

> 2026-08-06 实测：`{"current":1,"size":100}` + `{"current":2,"size":100}` 两页拿全 185 项；用 `{"page":1,"size":100}` 只返回 85 项。

## 响应：data.content[]（薪资项目，每项含公式）

关键字段：

| 字段 | 说明 |
|------|------|
| **formula** | **★ 明文公式**（如 `=STAFF_ROSTER$positiveDate`），空 = 纯输入项 |
| oldFormula / sysExprItems / exprItems | 历史公式 / 解析 token（本接口一般为 null，token 解析走 manage/enable） |
| name / fieldCode | 项目显示名 / 字段码 |
| systemsalaryfieldCode / Name | 系统字段码 / 名（系统预置项才有） |
| categoryName / categoryCode | 分类：其他项 CUSTOM / 税前减项 BENIFIT / 税前加项 BASE |
| typeName / typeId / typeCode | 类型：员工基本信息 staff / 其它 other / 工资 salary / 专项扣除 personsihf 等 |
| taxTypeName / taxTypeId / taxTypeCode | 个税类型（工资薪金税 salary_tax 等） |
| roundingMode | 取整：PRIMITIVE 原始 / ROUND 四舍五入 |
| source | 来源：FUNCTION 公式 / INPUT 输入 |
| salaryFieldValueType | 值类型：NUMBER / TEXT / DATE |
| companyCostNumOp / personalSalaryNumOp | 公司/个人成本加减（ADD 加项 / SUBTRACT 减项） |
| meta.valueMeta.formula | 内层 valueMeta 里的公式（与顶层 formula 通常一致） |
| meta.valueMeta.phasedFormula | 分段公式（阶梯计价场景） |
| valid / formulaEditDisable | 是否有效 / 公式是否可编辑 |

## 实测公式样例（2026-08-06）

```
=STAFF_ROSTER$positiveDate                                   简单字段引用
=STAFF_SAL$salaryScale                                       薪资表引用
=left(STAFF_ROSTER$positionLevelName,1)                      函数调用
=SIHF$HF_TYPE_0001_ADJUST_P                                  社保公积金表引用
=SMARTAPPSTANDARDsa1097463344624844800$C7dr6mb753tsotqu5n2b  智搭云自定义表引用
=TAXABLE_CUMUL_CUR_MONTH$communicationFee                    累计应纳税表引用
=IF(STAFF_ROSTER$taxrole="居民",VLOOKUP(taxablesalary,$TAX_TABLE$salary_tax,5,7),...)  税率表 VLOOKUP
=IF(STAFF_ROSTER$taxrole="居民",grossincome-yearendbonustotal-compensationtotal,...)    多分支 IF
='%based_on_salaryplan_name%'!totaltakehomepay               跨方案/跨期引用（%based_on_salaryplan_name%!）
=CHOOSE(MATCH(1=1,{(corporationEffectiveDate=null),...}),{null,eomonth(...)},date(...)) 复杂嵌套
```

**函数与语法与 `references/formula-language.md` 完全对应**（CHOOSE/MATCH/left/eomonth/day/month/year/and/or + `表名$字段` + `{数组}` + `'%based_on_salaryplan_name%'!` 跨方案引用）。

**分类体系**（categoryName/categoryCode）：统计项 / 税费项 / 税前加项（BASE）/ 税前减项（BENIFIT）/ 其他项（CUSTOM）——统计项=聚合计算（grossincome/taxablesalary 等），税费项=个税类，税前加项/减项=参与应发计算的明细项。

## ★ 薪资公式解读完整链路（问题4 闭环）

```
1. 项目列表+公式 → 本接口（companySalaryfieldMetas/list，每项 formula 明文）
2. 公式 token 解析 → component/table/manage/enable（exprItems 校验，可选）
3. 语法解读      → references/formula-language.md（函数/字段引用）
4. 值验证        → OpenAPI #67（按员工+方案+年月，91 项值 {'v':'xxx'}）
   → formula 中的变量 → #67 的值 → 逐步代入验证最终结果
```

## 关联接口

- `GET /gateway/component/manage/api/component/table/manage/enable?code=payroll.table.companysalaryfield` — 公式 token 解析（exprItems），见 `薪资项目-公式解析.md`
- `GET /gateway/payroll/api/salaryFieldTypes/search?projection=salaryFieldTypeFullProjection` — 字段类型/分类（表名体系）
- OpenAPI #67 / #56 / #68（值/字段定义/系统项目）见 `api-handbook/05-薪资管理/`
