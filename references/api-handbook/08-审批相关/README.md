## 模块说明

- **#103/#104** 为 OA 回调接口，URL 由第三方提供，非标准 OpenAPI
- **#105** 用于消息推送场景，返回 PC/H5 待办入口链接
- **#106** 是最复杂的审批查询接口，支持按发起人/时间/类型/状态/年份等多维筛选
- **#107** 仅支持开启了**三方审批推送**的流程，可修改为 PASS/DENIED，不支持作废/撤销
- **#108** 需要 JWT `dataToken`，需联系实施经理申请 SecretKey 对接码
- **#109** 用于模拟第三方系统执行审批，`nodeId` 需从客服或同步接口获取
