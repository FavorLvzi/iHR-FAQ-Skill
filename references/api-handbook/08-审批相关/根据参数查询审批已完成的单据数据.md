# 根据参数查询审批已完成的单据数据

| 属性 | 值 |
|------|-----|
| **编号** | #106 |
| **接口地址** | `POST https://openapi.ihr360.com/openapi/thirdparty/api/workflow/v1/process/finish/page` |
| **请求方式** | POST |
| **认证方式** | Bearer Token |
| **创建人** | Haoqi Wang |
| **创建/更新** | 2023-06-12（初版）→ 2024-05-23（+唯一码+流程ID）→ 2025-03-10（+编码集合）→ 2026-05-19（+processUniqueId） |

## 功能描述

按多维度筛选查询**已完成审批**的单据列表，支持分页和跨年查询。是目前字段最丰富的审批接口。

## 请求参数

### Query 参数

| 参数 | 类型 | 必填 | 备注 |
|------|------|------|------|
| companyId | String | 是 | 公司ID |

### Body 参数（searchVo 对象）

| 参数 | 类型 | 必填 | 备注 |
|------|------|------|------|
| applicantName | String | 否 | 发起人名称（模糊搜索） |
| staffNo | String | 否 | 工号 |
| staffMobileNo | String | 否 | 手机号 |
| startTimeStart | Date | 否 | 发起时间起始（yyyy-MM-ddTHH:mm:ss） |
| startTimeEnd | Date | 否 | 发起时间终止，缺HH:mm:ss自动补00:00:00 |
| endTimeStart | Date | 否 | 结束时间起始 |
| endTimeEnd | Date | 否 | 结束时间终止 |
| processUniqueId | String | 否 | 审批模版唯一编码 |
| processUniqueIds | Array | 否 | 审批模版唯一编码集合 |
| modelShowTypeList | Array | 否 | 审批类型（见下表） |
| **statuses** | Array | **是** | **★只接受单元素数组**（如 `["PASS"]`）——传多元素 `["PASS","DENIED"]` 触发 JSON 解析错误 code=-1（2026-08-10 宿主 AI 实测）。流程状态（仅限已完结状态，见下表） |
| **page** | Integer | **是** | 页码，**从 1 开始** |
| **rows** | Integer | **是** | 每页行数，**最大 50** |
| source | String | 否 | 数据年份源：空/main=当前，也可传"2023"等跨年查询 |
| requireComments | Boolean | 否 | 是否返回评论数据，默认 false |

### 请求示例

```json
{
  "applicantName": "发起人名称搜索",
  "startTimeStart": "2023-02-01",
  "startTimeEnd": "2023-06-30",
  "processUniqueId": "824887961446420480",
  "requireComments": true,
  "modelShowTypeList": ["VACATION"],
  "statuses": ["PASS"],
  "page": 1,
  "rows": 50
}
```

## 关键注意点

| 点 | 说明 |
|------|------|
| **分页从 1 开始** | page=1 为第一页，与大多数接口（page=0）不同 |
| **跨年查询** | 通过 `source` 参数（"2023"/"2022"等），`reset=true` 时需切换到指定年份源。**2026-08-07 实测：不传/main → 返回当前年 source=2026，且 `reset=true`；传 `source=2025` → 查到 2025 年 2 条出差单（totalElements=2）；传 `source=2026` 反而返回 source=2025（reset 语义=需按响应重新查询）**。**查历史年数据必须显式传 source=具体年份** |
| **VACATION 是大类** | modelShowType 中用 VACATION 过滤所有假期，suiteType 中用具体假期类型 |
| **processUniqueId** | 2026-05-19 新增，支持按模版唯一编码过滤。**★ 因环境而异（同 approvalSettingId）：文档示例 824887961446420480 / skill 记录的 992311786902663168 都是某环境的值，宿主环境用其过滤必然查空——查空时先去掉此参数** |
