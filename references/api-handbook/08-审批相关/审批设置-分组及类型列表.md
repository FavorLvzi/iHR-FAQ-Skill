# 审批设置-分组及类型列表（二方，问题5 定位链路第 2 层 ★缺口已补）

## 基本信息

| 项目 | 内容 |
|------|------|
| 接口名称 | 获取审批设置分组及类型列表 |
| 接口地址 | `GET /gateway/workflow/aggregate/approval/setting/findApprovalGroupVo` |
| 请求方式 | GET |
| 鉴权方式 | Cookie+XSRF（前端插件）/ 宿主 AI 环境 `Authorization: Bearer {IHR360_API_TOKEN}` |
| Host | `v5.ihr360.com` |
| 实测时间 | 2026-08-07（用户抓包）→ 2026-08-12（宿主 Bearer 事假文档实测，✅确认可用） |

> 一次性返回**所有审批类型分组 + 每组下的全部审批类型**（含 `id`=approvalSettingId / `suiteType` / `processUniqueId` / `status` / `ranges` 等）——**问题5 定位链路第 2 层（最后一层），补上后三层全通**：`findApprovalGroupVo`（分组+类型）→ `approval/setting/draft/{id}`（流程定义）。

## 响应结构

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Number | 0=成功 |
| data | Array | 分组列表（含类型） |
| id | String | 分组ID（如 `d9131e67-...` = 考勤假期） |
| groupName | String | 分组名（考勤假期/薪资福利/人事相关/招聘相关/i招聘相关） |
| groupType | String | `GROUP_ATTENDANCE` 考勤 / `GROUP_SALARY_BENEFIT` 薪资福利 / `GROUP_PERSONNEL` 人事 / `GROUP_RECRUIT` 招聘 / `GROUP_IVVA_RECRUIT` i招聘 |
| seqNo | Integer | 排序号 |
| approvalSettingListVos | Array | **该分组下审批类型列表（核心）** |

### approvalSettingListVos 字段（审批类型）

| 字段 | 类型 | 说明 |
|------|------|------|
| **id** | String | **★审批类型ID = approvalSettingId（可直接用于 `approval/setting/draft/{id}`）** |
| groupId | String | 所属分组ID |
| name | String | 类型名（如"补卡"） |
| status | String | `ENABLE` 启用 / `DISABLE` 停用 |
| ranges | String | 发起人范围（"所有人"/"指定人员"） |
| updatedAt | Long | 更新时间（ms） |
| formId | String | **表单定义ID**（与 draft 返回的 `formVo.id` 一致，可交叉验证） |
| processUniqueId | Long | **审批模板唯一编码**（对应 #106 单据查询过滤参数） |
| suiteType | String | **套件类型**（APPEAL=补卡 / LEAVE_ADJUST=请假 / OVER_TIME=加班 等，枚举见下） |
| versionId | Integer | 版本号 |
| pushStatus | String | SYNCING / NOT_SYNCED |
| approvalUserScopeVersion | String | V2 / OLD |
| applyToAll | Boolean | 是否所有人可发起 |
| suite | Boolean | 是否套件 |
| batch / allowBatch | Boolean | 是否支持批量 |

> **★ ID 体系三件套（关键）**：`id`(UUID) → 流程定义 draft 接口；`processUniqueId`(Long) → #106 单据查询；`formId`(UUID) → 表单定义。三者可通过本接口一次性全部拿到。

## 定位链路（★三层全通，2026-08-07 收口 + 08-12 恢复确认）

```
① findApprovalGroupVo → 分组 + 审批类型列表（含 approvalSettingId / suiteType / processUniqueId / formId）
   ✅ 2026-08-12 宿主 Bearer 实测可用（事假文档为证）
   （approvalGroup/selector 简化版宿主 Bearer 404，不必用，本接口已覆盖）
   ↓ 按 name 找目标类型（如"事假"/"补卡"），取 id
② approval/setting/{approvalSettingId} → 流程定义（★已发布版，首选）
   （备选：draft/{id} 草稿版，可能被锁/非正式）
```

> **AI 使用路径**：收到"查 XX 审批流程"问题 → 调 findApprovalGroupVo → 按 name 匹配类型 → 拿 id 调 `approval/setting/{id}`（已发布）→ 解析节点结构。全自主，无需用户手工提供 ID。
