# 根据标记码变更流程实例数据

**接口编号**：#108  
**接口路径**：`POST /openapi/thirdparty/api/workflow/v1/form/update/instance`  
**请求方式**：POST  
**鉴权方式**：Bearer Token + JWT dataToken  
**所属模块**：审批相关  
**创建日期**：2024-05-29  
**创建人**：Haoqi Wang  

---

## 接口描述

根据流程 id 以及需要更新的**组件标记码**（表单设置 → 具体组件 → 右侧最下方），更新对应标记码的表单实例数据。

---

## JWT dataToken 生成

> ⚠️ **前置条件**：调用此接口需要 `dataToken`，需联系实施经理或客户成功申请技术支持获取对接码（SecretKey）。

| 字段 | 说明 |
|------|------|
| SecretKey | 联系实施经理/客户成功经理申请 |
| expiresAt | 令牌过期时间 60 分钟 |
| businessCode | 固定值 `ihr` |
| 算法 | HS256（Hutool JWT.create） |

**Java 示例**：

```java
import cn.hutool.jwt.JWT;

public static String getJwtsString(String secretKey) {
    Date issuedAt = new Date();
    Date expiresAt = new Date(issuedAt.getTime() + (600 * 1000));
    return JWT.create()
            .setPayload("businessCode", "ihr")
            .setIssuedAt(issuedAt)
            .setExpiresAt(expiresAt)
            .setKey(secretKey.getBytes())
            .sign();
}
```

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 备注 |
|------|------|------|------|------|
| companyId | QueryParam | String | 是 | 公司 id |
| processId | QueryParam | String | 是 | 需要修改的流程实例 id |
| dataToken | QueryParam | String | 是 | JWT 验证 token，验证不通过不允许写入 |
| (动态 key) | Body | Object | 是 | key 为需要更新的组件标记码，value 为更新后的值 |

---

## 请求示例

**URL**：
```
POST .../workflow/v1/form/update/instance?companyId=123456&processId=xxxx&dataToken=xxxx
```

**Body**（key 来自表单组件标记码）：
```json
{
  "endTime": "2024-05-20 00:05:20"
}
```

---

## 响应参数

| 参数 | 类型 | 父节点 | 备注 |
|------|------|--------|------|
| code | String | Response Body | 返回码 |
| message | String | Response Body | 错误信息 |
| errorResult | Boolean | Response Body | 是否正确返回 |

---

## 响应示例

```json
{
  "code": 0,
  "message": null,
  "url": null,
  "data": null,
  "showType": 0,
  "errorResult": false
}
```

---

## 注意事项

1. **组件标记码**在表单设计器的每个组件右侧属性面板最下方
2. Body 是**动态字段**：key 为标记码（如 `endTime`、`applyReason`），value 为新值
3. 需要 JWT `dataToken`——无 token 则拒绝写入
4. Token 有效期仅 60 分钟，超时需重新生成
