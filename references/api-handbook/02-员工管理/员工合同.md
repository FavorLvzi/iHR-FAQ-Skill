# 员工合同

包含接口：#4, #35

---

## 接口 #4：获取员工合同清单

批量获取多个员工的合同信息，支持查询生效中、历史、未来等各类合同。

### 端点

```
POST /openapi/thirdparty/api/staff/v1/contracts
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |
| Headers | `Content-Type: application/json` |

### 请求体

> ⚠️ **纯数组请求体**：直接传入员工 UUID 数组，无需对象包裹。
> ⚠️ **数量限制**：最多 **100 个**员工 UUID。

| 类型 | 说明 |
|------|------|
| `String[]` | 员工 UUID 数组，如 `["uuid1", "uuid2"]` |

### 请求示例

```json
[
  "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "b2c3d4e5-f6a7-8901-bcde-f12345678901"
]
```

### 响应字段说明

> ⚠️ **嵌套结构最深的接口之一**，包含合同历史记录和未来记录。

| 字段 | 类型 | 说明 |
|------|------|------|
| `contractNo` | String | 合同编号 |
| `contractType` | String | 合同类型：`LABOR`（劳动合同）、`SERVICE`（劳务合同）、`TRAINING`（培训协议）、`NO_LIMIT`（无限期）、`OTHER_CONTRACT`（其他） |
| `contractProperty` | String | 合同属性：`CUR`（当前）、`HIS`（历史）、`FUTURE`（未来） |
| `contractBeginDate` | String | 合同开始日期，`yyyy-MM-dd` |
| `contractEndDate` | String | 合同结束日期，`yyyy-MM-dd` |
| `contractSignDate` | String | 合同签订日期，`yyyy-MM-dd` |
| `contractTermDate` | String | 合同期限日期，`yyyy-MM-dd` |
| `contractTermType` | String | 合同期限类型：`FIXED`（固定期限）、`NO_FIXED_TERM`（无固定期限） |
| `contractStatus` | String | 合同状态：`EFFECTIVE`（生效中）、`PENDING`（待生效）、`TERMINATED`（已终止） |
| `contractAction` | String | 合同操作类型：`CHANGE`（变更）、`RENEW`（续签） |
| `applicationStatus` | String | 申请状态：`NOT_LAUNCHED`（未发起）、`INITIATE`（发起中）、`PASS`（已通过）、`WAITING_HR_APPROVAL`（待HR审批）、`DENIED`（已拒绝）、`CANCEL`（已取消）、`ABANDONED`（已废弃）、`BACK`（已退回）、`DELETE`（已删除） |
| `esignStatus` | String | 电子签状态：`UNSTART`（未发起）、`SENDING`（发送中）、`SIGNING`（签署中）、`SUCCESS`（签署成功）、`REVOKED`（已撤销）、`REJECTED`（已拒绝）、`EXPIRED`（已过期） |
| `warningStatus` | Integer | 预警状态：`0`（无预警）、`1`（即将到期）、`2`（已到期） |
| `signedNum` | Integer | 已签署份数 |
| `digitalContractNum` | Integer | 电子合同份数 |
| `staffStatus` | String | 员工状态 |
| `corporationId` | String | 法人主体ID |
| `corporationName` | String | 法人主体名称 |
| `positionId` | String | 岗位ID |
| `positionName` | String | 岗位名称 |
| `probationEndDate` | String | 试用期结束日期，`yyyy-MM-dd` |
| `mobileNo` | String | 手机号 |
| `contractHistoryRecordList` | Array | 合同历史记录列表（嵌套，详见下方） |
| `contractFutureRecord` | Object | 合同未来记录（嵌套，详见下方） |

#### contractHistoryRecordList[]

| 字段 | 类型 | 说明 |
|------|------|------|
| `contractBeginDate` | String | 合同开始日期 |
| `contractEndDate` | String | 合同结束日期 |
| `contractSignDate` | String | 合同签订日期 |
| `contractTermDate` | String | 合同期限日期 |
| `contractTermType` | String | 合同期限类型 |
| `contractType` | String | 合同类型 |

#### contractFutureRecord

| 字段 | 类型 | 说明 |
|------|------|------|
| `contractBeginDate` | String | 未来合同开始日期 |
| `contractEndDate` | String | 未来合同结束日期 |
| `contractType` | String | 未来合同类型 |
| `contractAction` | String | 未来合同操作类型 |

### 示例请求

```bash
curl -X POST "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v1/contracts" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..." \
  -H "Content-Type: application/json" \
  -d '["a1b2c3d4-e5f6-7890-abcd-ef1234567890", "b2c3d4e5-f6a7-8901-bcde-f12345678901"]'
```

## 接口 #35：获取员工当前合同

获取单个员工的当前生效合同，不包含历史嵌套记录。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/contracts/current
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `staffId` | String | 是 | 员工 UUID |

### 响应字段说明

> 仅返回当前合同（`contractProperty=CUR`），无嵌套的 `contractHistoryRecordList` 和 `contractFutureRecord`。

| 字段 | 类型 | 说明 |
|------|------|------|
| `contractNo` | String | 合同编号 |
| `contractType` | String | 合同类型 |
| `contractProperty` | String | 固定为 `CUR` |
| `contractBeginDate` | String | 合同开始日期 |
| `contractEndDate` | String | 合同结束日期 |
| `contractSignDate` | String | 合同签订日期 |
| `contractTermDate` | String | 合同期限日期 |
| `contractTermType` | String | 合同期限类型 |
| `contractStatus` | String | 合同状态 |
| `contractAction` | String | 合同操作类型 |
| `applicationStatus` | String | 申请状态 |
| `esignStatus` | String | 电子签状态 |
| `warningStatus` | Integer | 预警状态 |
| `signedNum` | Integer | 已签署份数 |
| `digitalContractNum` | Integer | 电子合同份数 |
| `staffStatus` | String | 员工状态 |
| `corporationId` | String | 法人主体ID |
| `corporationName` | String | 法人主体名称 |
| `positionId` | String | 岗位ID |
| `positionName` | String | 岗位名称 |
| `probationEndDate` | String | 试用期结束日期 |
| `mobileNo` | String | 手机号 |

### 与 #4 的对比

| 对比项 | #4 | #35 |
|--------|----|-----|
| 方法 | POST | GET |
| 请求体 | 纯数组（≤100个UUID） | Query 参数 `staffId` |
| 查询范围 | 所有合同（当前+历史+未来） | 仅当前合同 |
| 数据量 | 可批量（最多100人） | 单员工 |
| `contractHistoryRecordList` | ✅ 返回 | ❌ 不返回 |
| `contractFutureRecord` | ✅ 返回 | ❌ 不返回 |
| 使用场景 | 合同盘点、批量同步 | 快速获取单员工当前合同 |

### 示例请求

```bash
curl -X GET "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v1/contracts/current?staffId=a1b2c3d4-e5f6-7890-abcd-ef1234567890" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```
