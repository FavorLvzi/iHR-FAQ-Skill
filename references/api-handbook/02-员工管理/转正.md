# 转正

包含接口：#41, #42, #43

---

## 接口 #41：根据转正日期获取转正清单

根据指定的转正日期获取当天应转正的员工清单。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/positiveForms/positive
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `date` | String | 是 | 转正日期，格式 `yyyy-MM-dd` |

### 响应结构

```
data[] → PositiveFormVO
```

### 响应参数（PositiveFormVO）

| 字段 | 类型 | 说明 |
|------|------|------|
| `staffId` | String | 员工 UUID |
| `staffName` | String | 员工姓名 |
| `staffNo` | String | 员工工号 |
| `departmentId` | String | 部门 ID |
| `departmentName` | String | 部门名称 |
| `positionId` | String | 职位 ID |
| `positionName` | String | 职位名称 |
| `enrollInDate` | String | 入职日期，格式 `yyyy-MM-dd` |
| `probationEndDate` | String | 试用期结束日期，格式 `yyyy-MM-dd` |
| `positiveDate` | String | 计划转正日期，格式 `yyyy-MM-dd` |
| `actualPositiveDate` | String | 实际转正日期，格式 `yyyy-MM-dd` |
| `entryApplicationStatus` | String | 转正申请状态（见下方说明） |
| `positiveStatus` | String | 转正状态：`STAY_CONFIRM`（待确认）、`HAS_CONFIRM`（已确认）、`COMPLETED`（已完成）、`GIVE_UP`（已放弃） |
| `positiveEvaluationResultsType` | String | 转正评估结果类型：`NORMAL_POSITIVE`（正常转正）、`ADVANCE_POSITIVE`（提前转正）、`DELAY_POSITIVE`（延期转正） |

### entryApplicationStatus 枚举（10 种）

| 状态值 | 说明 |
|--------|------|
| `UN_START` | 未开始 |
| `PROCESSING` | 审批中 |
| `WAITING_HR_APPROVAL` | 待HR审批 |
| `AUDIT` | 待审核 |
| `PASSED` | 已通过 |
| `REJECTED` | 已拒绝 |
| `ABANDON` | 已放弃 |
| `RECALL` | 已撤回 |
| `BACKFILL` | 待回填 |
| `ARCHIVE` | 已归档 |

### 示例请求

```bash
curl -X GET "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v1/positiveForms/positive?date=2025-07-01" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

### 示例响应

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "staffId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
      "staffName": "张三",
      "staffNo": "EMP2024001",
      "departmentId": "dept-001",
      "departmentName": "技术部",
      "positionId": "pos-001",
      "positionName": "高级开发工程师",
      "enrollInDate": "2025-04-01",
      "probationEndDate": "2025-06-30",
      "positiveDate": "2025-07-01",
      "actualPositiveDate": null,
      "entryApplicationStatus": "WAITING_HR_APPROVAL",
      "positiveStatus": "STAY_CONFIRM",
      "positiveEvaluationResultsType": "NORMAL_POSITIVE"
    }
  ]
}
```

## 接口 #42：获取当日已转正员工清单

V2 版本接口，固定返回**当天**已转正的员工清单，不接受日期参数。

> ⚠️ **与 #41 的对比**：#41 为 v1 版支持 `date` 参数可查指定日期；#42 为 v2 版固定查当天，无日期参数。

### 端点

```
GET /openapi/thirdparty/api/staff/v2/positiveForms/positive
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数

无（固定查当天，无需 Query 参数）

### 响应参数

与 #41 完全一致，返回 `PositiveFormVO[]`。

| 字段 | 类型 | 说明 |
|------|------|------|
| `staffId` | String | 员工 UUID |
| `staffName` | String | 员工姓名 |
| `staffNo` | String | 员工工号 |
| `departmentId` | String | 部门 ID |
| `departmentName` | String | 部门名称 |
| `positionId` | String | 职位 ID |
| `positionName` | String | 职位名称 |
| `enrollInDate` | String | 入职日期 |
| `probationEndDate` | String | 试用期结束日期 |
| `positiveDate` | String | 计划转正日期 |
| `actualPositiveDate` | String | 实际转正日期 |
| `entryApplicationStatus` | String | 转正申请状态（10 种） |
| `positiveStatus` | String | 转正状态 |
| `positiveEvaluationResultsType` | String | 转正评估结果类型 |

### 与 #41 的对比

| 对比项 | #41（v1） | #42（v2） |
|--------|----------|----------|
| 端点版本 | `/api/staff/v1/positiveForms/positive` | `/api/staff/v2/positiveForms/positive` |
| date 参数 | 必填，指定日期 | 无，固定当天 |
| 返回结构 | PositiveFormVO[] | PositiveFormVO[]（完全一致） |
| 使用场景 | 查询任意日期转正清单 | 获取当天已转正记录 |

### 示例请求

```bash
curl -X GET "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v2/positiveForms/positive" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

### 示例响应

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "staffId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
      "staffName": "张三",
      "staffNo": "EMP2024001",
      "departmentName": "技术部",
      "positionName": "高级开发工程师",
      "enrollInDate": "2025-04-01",
      "probationEndDate": "2025-06-30",
      "positiveDate": "2025-07-01",
      "actualPositiveDate": "2025-07-01",
      "entryApplicationStatus": "PASSED",
      "positiveStatus": "COMPLETED",
      "positiveEvaluationResultsType": "NORMAL_POSITIVE"
    }
  ]
}
```

## 接口 #43：根据员工 id 获取待转正清单

根据员工 ID 数组批量查询待转正信息。

> ⚠️ **数量限制**：最多 **500 个**员工 UUID（比其他接口 100 个更宽松）。
> ⚠️ **请求体格式**：**纯数组** `["id1","id2"]`，非对象包裹。

### 端点

```
POST /openapi/thirdparty/api/staff/v1/positiveForms/findStaffPendingForms
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |
| Headers | `Content-Type: application/json` |

### 请求体

**纯数组格式**（非对象包裹）：

```json
[
  "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "b2c3d4e5-f6a7-8901-bcde-f12345678901"
]
```

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 请求体 | String[] | 是 | 员工 UUID 数组，**纯数组格式**，≤500 个 |

### 响应参数

`data` 直接返回 PositiveFormVO 数组（与 #41/#42 结构一致）。

| 字段 | 类型 | 说明 |
|------|------|------|
| `data` | Array | PositiveFormVO 数组 |
| `data[].staffId` | String | 员工 UUID |
| `data[].staffName` | String | 员工姓名 |
| `data[].staffNo` | String | 员工工号 |
| `data[].departmentId` | String | 部门 ID |
| `data[].departmentName` | String | 部门名称 |
| `data[].positionId` | String | 职位 ID |
| `data[].positionName` | String | 职位名称 |
| `data[].enrollInDate` | String | 入职日期 |
| `data[].probationEndDate` | String | 试用期结束日期 |
| `data[].positiveDate` | String | 计划转正日期 |
| `data[].actualPositiveDate` | String | 实际转正日期 |
| `data[].entryApplicationStatus` | String | 转正申请状态（10 种） |
| `data[].positiveStatus` | String | 转正状态 |
| `data[].positiveEvaluationResultsType` | String | 转正评估结果类型 |

### 三个转正接口对比

| 对比项 | #41（v1 按日期） | #42（v2 当天） | #43（按员工 ID） |
|--------|----------------|---------------|----------------|
| 端点 | `/v1/positiveForms/positive` | `/v2/positiveForms/positive` | `/v1/positiveForms/findStaffPendingForms` |
| 方法 | GET | GET | **POST** |
| 请求方式 | Query `?date=x` | 无参数 | **纯数组**请求体 |
| 最大数量 | 分页（默认 100） | 分页（默认 100） | **≤500 个** |
| 返回结构 | PositiveFormVO[] | PositiveFormVO[] | PositiveFormVO[]（完全一致） |
| 使用场景 | 查询指定日期待转正 | 获取当天已转正 | 按员工 ID 批量查待转正状态 |
| 数据范围 | 按日期筛选 | 当天 | 按 ID 精确匹配 |

### 示例请求

```bash
curl -X POST "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v1/positiveForms/findStaffPendingForms" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..." \
  -H "Content-Type: application/json" \
  -d '["a1b2c3d4-e5f6-7890-abcd-ef1234567890","b2c3d4e5-f6a7-8901-bcde-f12345678901"]'
```

### 示例响应

```json
  "message": "success",

    {
      "staffId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
      "staffName": "张三",
      "staffNo": "EMP2024001",
      "departmentName": "技术部",
      "positionName": "高级开发工程师",
      "enrollInDate": "2025-04-01",
      "probationEndDate": "2025-06-30",
      "positiveDate": "2025-07-01",
      "actualPositiveDate": null,
      "entryApplicationStatus": "WAITING_HR_APPROVAL",
      "positiveStatus": "STAY_CONFIRM",
      "positiveEvaluationResultsType": "NORMAL_POSITIVE"
    }
  ]
}
```
