# 绩效档案

> 接口 #50 — 获取绩效档案清单

---

## #50 获取绩效档案清单

> **路径**：`POST /openapi/thirdparty/api/staff/v1/staff/performances/staffIds`  
> **鉴权**：Bearer token（OpenAPI）  
> **状态**：✅ 已验证

### 请求体

纯数组格式，传入员工 ID 列表，单次最多 **100 个** 员工 ID。

```json
[
  "staff-id-1",
  "staff-id-2"
]
```

### 响应结构

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "staffId": "staff-id-1",
      "assessPlanName": "2025年度绩效考核",
      "assessType": "ANNUAL",
      "yearOfAssess": "2025",
      "assessCycle": "2025-01-01~2025-12-31",
      "finalScore": 95.5,
      "performanceLevel": "A",
      "assessResult": "优秀",
      "rankingInCompany": 10,
      "rankingInDepartment": 3,
      "departmentNameInPeriod": "技术部",
      "positionNameInPeriod": "高级工程师",
      "flexAttributes": {
        "D_customField1": "自定义值1",
        "D_customField2": "自定义值2"
      }
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `staffId` | string | 员工 ID |
| `assessPlanName` | string | 考核方案名称 |
| `assessType` | string | 考核类型 |
| `yearOfAssess` | string | 考核年份 |
| `assessCycle` | string | 考核周期（日期范围） |
| `finalScore` | number | 最终评分 |
| `performanceLevel` | string | 绩效等级（如 A/B/C） |
| `assessResult` | string | 考核结果描述 |
| `rankingInCompany` | integer | 公司内排名 |
| `rankingInDepartment` | integer | 部门内排名 |
| `departmentNameInPeriod` | string | 考核期内所属部门 |
| `positionNameInPeriod` | string | 考核期内岗位名称 |
| `flexAttributes` | object | 动态扩展字段，以 `D_` 为前缀的键值对 |

### 注意事项

- **同一员工可能返回多条记录**：同一员工在不同考核周期有独立的绩效记录。
- **限制**：单次请求最多传入 **100 个** 员工 ID。
- **动态字段**：`flexAttributes` 中包含租户自定义的扩展字段，Key 以 `D_` 开头（如 `D_customField1`），具体字段因租户配置而异。
