# 多维组织任职记录

包含接口：#52

---

## 接口 #52：获取多维组织任职记录

获取员工在多维组织架构中的任职记录，支持按元数据编码筛选不同的维度组织。

### 端点

```
GET /openapi/thirdparty/api/staffDimensionOrg/v1/staffDimensionOrg/{staffId}
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数

**Path 参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `staffId` | String | 是 | 员工 UUID |

**Query 参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `metaDataCode` | String | 是 | 维度元数据编码。取值：`tab_staff_dimension_01` ~ `tab_staff_dimension_05` |

### 响应结构

> ⚠️ 响应包含顶层 `result` 和 `errorCode` 字段，与其它接口的结构不同。

| 字段 | 类型 | 说明 |
|------|------|------|
| `result` | Boolean | 是否成功 |
| `errorCode` | String | 错误码，成功时为 `null` |
| `data` | Array | 任职记录列表 |

### data[] 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `departmentId` | String | 部门ID |
| `departmentName` | String | 部门名称 |
| `fullDepartmentName` | String | 完整部门路径 |
| `positionId` | String | 岗位ID |
| `positionName` | String | 岗位名称 |
| `positionType` | String | 岗位类型：`Enum.PrimaryPosition`（主岗）、`Enum.ConcurrentPosition`（兼岗） |
| `startDate` | String | 任职开始日期，`yyyy-MM-dd` |
| `endDate` | String | 任职结束日期，`yyyy-MM-dd`（仍在任时为 `null`） |
| `dimensionName` | String | 维度名称 |
| `extendField1`~`extendField10` | String | 扩展字段（1~10） |

### 与 #28 的对比

| 对比项 | #28 企业内任职记录 | #52 多维组织任职记录 |
|--------|-------------------|---------------------|
| 端点 | `/staff/v1/employmentRecords` | `/staffDimensionOrg/v1/staffDimensionOrg/{staffId}` |
| 方法 | POST | GET |
| 请求参数 | Body `{"staffIds":[...]}` | Path `{staffId}` + Query `metaDataCode` |
| 数据范围 | 批量（≤100人） | 单员工 |
| 岗位类型 | `employType: 1/2` | `positionType: Enum.PrimaryPosition/ConcurrentPosition` |
| 维度信息 | 无 | 有（`dimensionName`、`extendField1~10`） |
| 响应顶层结构 | `code/message/data` | `result/errorCode/data` |
| 部门字段 | `departmentId/Name` | `departmentId/Name/fullDepartmentName` |
| 职务/职级 | 包含 `jobTitleId/Name`、`positionGradeId/Name` | 无 |
| 扩展字段 | 无 | 10 个扩展字段 |
| 使用场景 | 获取标准组织架构中的任职信息 | 获取多维/矩阵式组织中的任职信息 |

### metaDataCode 说明

| 编码 | 说明 |
|------|------|
| `tab_staff_dimension_01` | 维度一 |
| `tab_staff_dimension_02` | 维度二 |
| `tab_staff_dimension_03` | 维度三 |
| `tab_staff_dimension_04` | 维度四 |
| `tab_staff_dimension_05` | 维度五 |

> 系统支持最多 5 个自定义维度，每个维度可定义不同的组织架构视图。
