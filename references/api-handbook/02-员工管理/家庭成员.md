# 家庭成员

> 接口 #51 — 获取家庭成员清单

---

## #51 获取家庭成员清单

> **路径**：`POST /openapi/thirdparty/api/staff/v1/familyMembers`  
> **鉴权**：Bearer token（OpenAPI）  
> **状态**：✅ 已验证

### 请求体

纯数组格式，传入员工 ID 列表，单次最多 **100 个** 员工 ID。

```json
[
  "staff-id-1",
  "staff-id-2"
]
```

### 响应结构

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "staffId": "staff-id-1",
      "memberName": "王芳",
      "birthDate": "1985-03-15",
      "relationship": "SPOUSE",
      "certificateFile": "file-uuid",
      "flexAttributes": {
        "D_company": "某公司",
        "D_phone": "138****5678"
      }
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `staffId` | string | 员工 ID |
| `memberName` | string | 家庭成员姓名 |
| `birthDate` | string | 出生日期（yyyy-MM-dd） |
| `relationship` | string | 与员工关系，可选值：`CHILDREN`（子女）、`PARENTS`（父母）、`SPOUSE`（配偶） |
| `certificateFile` | string\|null | 证件文件 ID（可能为空） |
| `flexAttributes` | object | 动态扩展字段，以 `D_` 为前缀的键值对 |

### 注意事项

- **限制**：单次请求最多传入 **100 个** 员工 ID。
- **关系枚举**：`CHILDREN`（子女）、`PARENTS`（父母）、`SPOUSE`（配偶）。
- **动态字段**：`flexAttributes` 中包含租户自定义的扩展字段，Key 以 `D_` 开头（如 `D_company`、`D_phone`），具体字段因租户配置而异。
