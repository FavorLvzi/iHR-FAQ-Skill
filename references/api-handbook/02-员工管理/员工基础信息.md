## 接口 #1：获取员工ID清单

获取指定状态的员工 UUID 清单，支持分页。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/staffs/ids
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `staffStatus` | String | 是 | 员工状态。取值：`IN_SERVICE`（在职）、`QUIT`（离职） |
| `pageNo` | Integer | 是 | 页码，从 1 开始 |

### 响应参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `pageInfo` | Object | 分页信息 |
| `pageInfo.pageNo` | Integer | 当前页码 |
| `pageInfo.pageSize` | Integer | 每页条数 |
| `pageInfo.totalCount` | Integer | 总记录数 |
| `pageInfo.totalPages` | Integer | 总页数 |
| `dataList` | String[] | 员工 UUID 数组 |

### 示例请求

```bash
curl -X GET "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v1/staffs/ids?staffStatus=IN_SERVICE&pageNo=1" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

### 示例响应

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "pageInfo": {
      "pageNo": 1,
      "pageSize": 100,
      "totalCount": 256,
      "totalPages": 3
    },
    "dataList": [
      "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
      "b2c3d4e5-f6a7-8901-bcde-f12345678901",
      "c3d4e5f6-a7b8-9012-cdef-123456789012"
    ]
  }
}
```

## 接口 #2：获取员工信息详情（单员工）

根据员工 UUID 获取单个员工的详细信息。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/staffs/{staffId}/detail
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Path）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `staffId` | String | 是 | 员工 UUID |

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | String | 员工 UUID |
| `staffName` | String | 员工姓名 |
| `staffNo` | String | 员工工号 |
| `staffStatus` | String | 员工状态：`IN_SERVICE`（在职）、`QUIT`（离职） |
| `staffType` | String | 员工类型：`FULLTIME`（全职）、`PARTTIME`（兼职）、`INTERSHIP`（实习）、`EXPATRIATE`（外派）、`TEMPORARY`（临时）、`REHIRE_RETIREMENT`（返聘退休） |
| `departmentName` | String | 部门名称 |
| `fullDepartmentName` | String | 完整部门路径（如"总公司/技术部/研发组"） |
| `positionName` | String | 岗位名称 |
| `enrollInDate` | String | 入职日期，格式 `yyyy-MM-dd` |
| `probationStatus` | String | 试用期状态：`PASSED`（已通过）、`ONPROBATION`（试用中） |
| `isProbation` | Boolean | 是否在试用期 |
| `probationEndDate` | String | 试用期结束日期，格式 `yyyy-MM-dd` |
| `probationLength` | Integer | 试用期时长（月） |
| `positiveDate` | String | 转正日期，格式 `yyyy-MM-dd` |
| `contractType` | String | 合同类型 |
| `contractBeginDate` | String | 合同开始日期，格式 `yyyy-MM-dd` |
| `contractEndDate` | String | 合同结束日期，格式 `yyyy-MM-dd` |
| `mobileNo` | String | 手机号 |

### 示例请求

```bash
curl -X GET "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v1/staffs/a1b2c3d4-e5f6-7890-abcd-ef1234567890/detail" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

### 示例响应

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "staffName": "张三",
    "staffNo": "EMP2024001",
    "staffStatus": "IN_SERVICE",
    "staffType": "FULLTIME",
    "departmentName": "技术部",
    "fullDepartmentName": "总公司/技术部/研发组",
    "positionName": "高级开发工程师",
    "enrollInDate": "2024-03-01",
    "probationStatus": "PASSED",
    "isProbation": false,
    "probationEndDate": "2024-05-31",
    "probationLength": 3,
    "positiveDate": "2024-06-01",
    "contractType": "LABOR",
    "contractBeginDate": "2024-03-01",
    "contractEndDate": "2027-02-28",
```

## 接口 #3：获取员工信息详情（含直属领导）

与 #2 的区别在于额外返回 `superiorsInfo` 数组，包含员工的直属领导信息。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/staffs/{staffId}/superiors/detail
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Path）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `staffId` | String | 是 | 员工 UUID |

### 响应字段

除包含 #2 的所有字段外，额外返回：

| 字段 | 类型 | 说明 |
|------|------|------|
| `superiorsInfo` | Array | 直属领导信息列表 |
| `superiorsInfo[].staffName` | String | 上级姓名 |
| `superiorsInfo[].staffId` | String | 上级员工 UUID |
| `superiorsInfo[].superiorStaffNo` | String | 上级工号 |
| `superiorsInfo[].departmentName` | String | 上级所在部门 |
| `superiorsInfo[].positionName` | String | 上级岗位 |
| `superiorsInfo[].reportToType` | String | 汇报类型：`Enum.Administration`（行政）、`Enum.Business`（业务）、`Enum.Finance`（财务） |

### 与 #2 的对比

| 对比项 | #2 | #3 |
|--------|----|----|
| 端点 | `/staffs/{staffId}/detail` | `/staffs/{staffId}/superiors/detail` |
| 基础字段 | 所有员工基本信息 | 所有员工基本信息 |
| 直属领导信息 | 不返回 | 返回 `superiorsInfo[]` |
| 使用场景 | 仅需员工本人信息 | 需要同时了解上级汇报关系 |

## 接口 #26：获取删除员工清单

获取指定时间范围内被删除的员工记录。

> ⚠️ **日期跨度限制**：`startDate` 到 `endDate` 的跨度不得超过 **3 个月**。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/staffs/deleted
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `startDate` | String | 是 | 开始日期，格式 `yyyy-MM-dd` |
| `endDate` | String | 是 | 结束日期，格式 `yyyy-MM-dd`。与 startDate 跨度 ≤3 个月 |

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `staffName` | String | 员工姓名 |
| `idCardType` | String | 证件类型：`IDENTITY_CARD`（身份证）、`CHINA_PASSPORT`（中国护照）、`FOREIGN_PASSPORT`（外国护照）、`MTP`（港澳通行证）、`MTPFHKAMR`（港澳居民来往内地通行证）、`OTHER`（其他） |
| `idCardNo` | String | 证件号码（脱敏显示） |
| `mobileNo` | String | 手机号（脱敏显示） |
| `enrollInDate` | String | 入职日期，格式 `yyyy-MM-dd` |
| `departmentName` | String | 部门名称 |
| `operator` | String | 操作人姓名 |
| `deleteTime` | String | 删除时间，格式 `yyyy-MM-dd HH:mm:ss` |
| `deleteReason` | String | 删除原因 |

### 示例请求

```bash
curl -X GET "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v1/staffs/deleted?startDate=2025-01-01&endDate=2025-03-31" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

### 示例响应

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "staffName": "赵六",
      "idCardType": "IDENTITY_CARD",
      "idCardNo": "320***********1234",
      "mobileNo": "139****5678",
      "enrollInDate": "2023-06-15",
      "departmentName": "市场部",
      "operator": "管理员",
      "deleteTime": "2025-02-20 14:30:00",
      "deleteReason": "员工主动离职删除"
    }
  ]
}
```

## 接口 #27：获取复职员工ID清单

获取指定日期之后复职的员工 UUID 清单。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/staffs/reinstatedAdditions
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `date` | String | 是 | 截止日期，格式 `yyyy-MM-dd`，返回该日期之后复职的员工 |

### 响应说明

`dataList` 直接返回 String 数组（员工 UUID），不包含分页信息。

### 示例请求

```bash
curl -X GET "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v1/staffs/reinstatedAdditions?date=2025-01-01" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

### 示例响应

```json
{
  "code": 200,
  "message": "success",
  "data": [
    "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "b2c3d4e5-f6a7-8901-bcde-f12345678901",
    "c3d4e5f6-a7b8-9012-cdef-123456789012"
  ]
}
```

## 接口（官方新增，无 # 序号）：根据手机号获取员工ID

> **2026-08-14 用户提供，官方 OpenAPI 文档收录（新增于 2020-08-09）**——**手机号 → staffId 精确反查**，弥补"只知道手机号"的员工定位缺口（比 #1 全量 + #2 匹配更直接）。

### 端点

`GET /openapi/thirdparty/api/staff/v1/staffs/getStaffIdByMobileNo`

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `mobileNo` | String | 是 | 员工手机号 |

### 响应参数

| 参数 | 类型 | 父节点 | 说明 |
|------|------|--------|------|
| `code` | int | Response Body | 0 = 成功 |
| `message` | String | Response Body | SUCCESS |
| `data` | JSONObject | Response Body | 数据 |
| `data.staffId` | String | data | **员工 ID（UUID）** |
| `errorResult` | Boolean | Response Body | 是否错误 |

### 示例请求

```bash
curl -X GET "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v1/staffs/getStaffIdByMobileNo?mobileNo=13800000000" \
  -H "Authorization: Bearer {accessToken}"
```

### 示例响应

```json
{
    "code": 0,
    "message": "SUCCESS",
    "data": {
        "staffId": "02178796-cd8f-40d1-ae73-7cb4edac6018"
    },
    "errorResult": false
}
```

> **使用场景**：客户提供手机号（而非姓名/工号）时直接反查 staffId → 再调 #2 详情。员工定位途径新增：**手机号直查（本接口）**。
