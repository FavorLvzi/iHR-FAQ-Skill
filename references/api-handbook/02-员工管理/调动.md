# 调动

包含接口：#44, #45, #46

## 接口 #44：获取待调动清单

获取当前待处理的调动申请清单，支持分页。

> ⚠️ **嵌套结构**：返回数据包含 `transferDetailList[]`（变更前→变更后对比链）和 `transferReasonDetails[]`（调动原因）。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/transferForms
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `pageNo` | Integer | 是 | 页码，从 1 开始 |

### 响应结构（TransferFormVO）

```
data
├── pageInfo           -- 分页信息
└── dataList[]         -- 调动清单
    ├── staffName               -- 员工姓名
    ├── staffNo                 -- 员工工号
    ├── departmentName          -- 部门名称
    ├── positionName            -- 职位名称
    ├── transferMode            -- 调动方式
    ├── entryApplicationStatus  -- 调动申请状态
    ├── positiveStatus          -- 调动流程状态
    ├── salary                  -- 薪资
    ├── effectiveAt             -- 生效日期
    ├── datasourceType          -- 数据来源类型
    ├── transferDetailList[]    -- **变更详情链（before→after）**
    │   ├── transferType        -- 调动类型（已弃用）
    │   ├── fieldId             -- 字段ID
    │   ├── metaDataCode        -- 元数据编码
    │   ├── beforeId            -- 变更前ID
    │   ├── beforeName          -- 变更前名称
    │   ├── afterId             -- 变更后ID
    │   └── afterName           -- 变更后名称
    └── transferReasonDetails[] -- **调动原因详情**
        ├── codeValue           -- 原因编码
        ├── displayName         -- 原因展示名称
        └── optionsCode         -- 选项编码
```

### 响应参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `pageInfo` | Object | 分页信息 |
| `pageInfo.pageNo` | Integer | 当前页码 |
| `pageInfo.pageSize` | Integer | 每页条数 |
| `pageInfo.totalCount` | Integer | 总记录数 |
| `pageInfo.totalPages` | Integer | 总页数 |
| `dataList` | Array | 调动清单 |
| `dataList[].staffName` | String | 员工姓名 |
| `dataList[].staffNo` | String | 员工工号 |
| `dataList[].departmentName` | String | 部门名称 |
| `dataList[].positionName` | String | 职位名称 |
| `dataList[].transferMode` | String | 调动方式：`ADJUST`（调整）、`PROMOTION`（晋升）、`DOWNGRADE`（降级） |
| `dataList[].entryApplicationStatus` | String | 调动申请状态 |
| `dataList[].positiveStatus` | String | 调动流程状态 |
| `dataList[].salary` | BigDecimal | 薪资 |
| `dataList[].effectiveAt` | String | 生效日期，格式 `yyyy-MM-dd` |
| `dataList[].datasourceType` | String | 数据来源类型：`APPLICATION_ARCHIVE`（申请归档）、`IMPORT`（导入）、`OPEN_API`（OpenAPI） |
| `dataList[].transferDetailList` | Array | **变更详情链**，每项描述一个字段的变更 |
| `transferDetailList[].transferType` | String | **已弃用** |
| `transferDetailList[].fieldId` | String | 字段 ID |
| `transferDetailList[].metaDataCode` | String | 元数据编码 |
| `transferDetailList[].beforeId` | String | 变更前 ID |
| `transferDetailList[].beforeName` | String | 变更前名称 |
| `transferDetailList[].afterId` | String | 变更后 ID |
| `transferDetailList[].afterName` | String | 变更后名称 |
| `dataList[].transferReasonDetails` | Array | 调动原因详情 |
| `transferReasonDetails[].codeValue` | String | 原因编码：`RESTRUCTURING`（组织调整）、`APPLICATIONS`（业务发展）、`ARRANGEMENT`（人员安排） |
| `transferReasonDetails[].displayName` | String | 原因展示名称 |
| `transferReasonDetails[].optionsCode` | String | 选项编码 |

### 示例请求

```bash
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

## 接口 #45：获取时间段内调动清单

获取指定时间范围内**已完成**的调动记录。

> ⚠️ **日期跨度限制**：`startDate` 到 `endDate` 的跨度不得超过 **3 个月**。
> ⚠️ 本接口返回的是**已完成的调动记录**（历史数据），与 #44 待处理清单用途不同。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/transferWithinInterval
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `startDate` | String | 是 | 开始日期，格式 `yyyy-MM-dd` |
| `endDate` | String | 是 | 结束日期，格式 `yyyy-MM-dd`。与 startDate 跨度 ≤3 个月 |
| `pageNo` | Integer | 否 | 页码，默认 1 |
| `isByOperatingTime` | Boolean | 否 | 是否按操作时间查询。`true` 按操作时间、`false` 按生效时间（默认） |

### 响应参数

返回 TransferFormVO 数组，结构与 #44 完全一致。

| 字段 | 类型 | 说明 |
|------|------|------|
| `pageInfo` | Object | 分页信息 |
| `dataList` | Array | TransferFormVO 数组 |
| `dataList[].staffName` | String | 员工姓名 |
| `dataList[].staffNo` | String | 员工工号 |
| `dataList[].departmentName` | String | 部门名称 |
| `dataList[].positionName` | String | 职位名称 |
| `dataList[].transferMode` | String | 调动方式 |
| `dataList[].entryApplicationStatus` | String | 调动申请状态 |
| `dataList[].positiveStatus` | String | 调动流程状态 |
| `dataList[].salary` | BigDecimal | 薪资 |
| `dataList[].effectiveAt` | String | 生效日期 |
| `dataList[].datasourceType` | String | 数据来源类型 |
| `dataList[].transferDetailList` | Array | 变更详情链（before→after） |
| `dataList[].transferReasonDetails` | Array | 调动原因详情 |

### 与 #44 的对比

| 对比项 | #44（待处理） | #45（时间段） |
|--------|-------------|-------------|
| 端点 | `/api/staff/v1/transferForms` | `/api/staff/v1/transferWithinInterval` |
| 请求参数 | `pageNo` | `startDate`, `endDate`, `pageNo`, `isByOperatingTime` |
| 数据范围 | 当前待处理的调动申请 | 指定时间段内已完成的调动记录 |
| 日期跨度限制 | 无 | ≤3 个月 |
| 返回结构 | TransferFormVO[] | TransferFormVO[]（完全一致） |
| 使用场景 | 待审批/待处理 | 历史已完成记录查询 |

### 示例请求

```bash
curl -X GET "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v1/transferWithinInterval?startDate=2025-01-01&endDate=2025-03-31&pageNo=1" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

## 接口 #46：获取调动设置

获取系统中可调动的字段配置及开关设置。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/transferForms/setting
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数

无（无需 Query/Path 参数）

### 响应参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `salaryEnable` | Boolean | 是否启用薪资调动 |
| `withholdingAgentEnable` | Boolean | 是否启用代扣代缴 |
| `limitDateEnable` | Boolean | 是否启用日期限制 |
| `fixedDay` | Integer | 固定日期值 |
| `fieldList` | Array | 可调动字段列表 |
| `fieldList[].fieldName` | String | 字段名称/标识 |
| `fieldList[].displayName` | String | 字段展示名称 |
| `fieldList[].fieldType` | String | 字段类型：`REPORT`（汇报类型）、`JOBCATEGORY`（职务分类）等 |
| `fieldList[].required` | Boolean | 是否必填 |
| `fieldList[].sort` | Integer | 排序值 |

### 可调动字段说明（fieldList）

| fieldName | 说明 |
|-----------|------|
| `departmentId` | 部门 |
| `positionId` | 职位 |
| `jobTitleId` | 职务 |
| `positionLevelId` | 职级 |
| `staffType` | 员工类型 |
| `corporationId` | 法律实体 |
| `companySiteId` | 工作地点 |
| `costCenterId` | 成本中心 |
| `reportToType` | 汇报类型（fieldType=REPORT） |
| `jobCategory` | 职务分类（fieldType=JOBCATEGORY） |
| `salary` | 薪资 |
| `contractType` | 合同类型 |
| `contractBeginDate` | 合同开始日期 |
| `contractEndDate` | 合同结束日期 |

### 示例请求

```bash
curl -X GET "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v1/transferForms/setting" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```
