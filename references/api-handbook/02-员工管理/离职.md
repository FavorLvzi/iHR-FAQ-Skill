# 离职

包含接口：#47, #48, #49

---

## 接口 #47：获取待离职清单

获取当前待处理的离职申请清单，支持分页。

> ⚠️ **`lastWorkDay`**：代表司龄截止日（实际最后工作日），与 `expectQuitDate`（期望离职日）和 `confirmQuitDate`（确认离职日）含义不同。
> ⚠️ 离职原因类型（`quitReasonType`）包含 **14 种**枚举值。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/quitForms
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `pageNo` | Integer | 是 | 页码，从 1 开始 |

### 响应结构（QuitFormVO）

```
data
├── pageInfo           -- 分页信息
└── dataList[]         -- 离职清单
    ├── staffName                -- 员工姓名
    ├── departmentName           -- 部门名称
    ├── positionName             -- 职位名称
    ├── enrollInDate             -- 入职日期
    ├── applyDate                -- 申请日期
    ├── expectQuitDate           -- 期望离职日
    ├── confirmQuitDate          -- 确认离职日
    ├── lastWorkDay              -- 最后工作日（⚠️ 司龄截止日）
    ├── salarySettlement         -- 薪资结算日
    ├── houseFundEndMonth        -- 公积金缴纳截止月
    ├── socialInsureEndMonth     -- 社保缴纳截止月
    ├── quitApplicationStatus    -- 离职申请状态
    ├── handoverStatus           -- 交接状态
    ├── quitStatus               -- 离职流程状态
    ├── quitType                 -- 离职类型
    ├── quitReasonType           -- 离职原因类型（14种）
    ├── systemTuningDepartment   -- 系统调优部门
    ├── systemTuningSubordinate  -- 系统调优下属
    └── systemTuningAppliaction  -- 系统调优应用
```

### 响应参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `pageInfo` | Object | 分页信息 |
| `pageInfo.pageNo` | Integer | 当前页码 |
| `pageInfo.pageSize` | Integer | 每页条数 |
| `pageInfo.totalCount` | Integer | 总记录数 |
| `pageInfo.totalPages` | Integer | 总页数 |
| `dataList` | Array | 离职清单 |
| `dataList[].staffName` | String | 员工姓名 |
| `dataList[].departmentName` | String | 部门名称 |
| `dataList[].positionName` | String | 职位名称 |
| `dataList[].enrollInDate` | String | 入职日期，格式 `yyyy-MM-dd` |
| `dataList[].applyDate` | String | 申请日期，格式 `yyyy-MM-dd` |
| `dataList[].expectQuitDate` | String | 期望离职日期，格式 `yyyy-MM-dd` |
| `dataList[].confirmQuitDate` | String | 确认离职日期，格式 `yyyy-MM-dd` |
| `dataList[].lastWorkDay` | String | **最后工作日**（司龄截止日），格式 `yyyy-MM-dd` |
| `dataList[].salarySettlement` | String | 薪资结算日 |
| `dataList[].houseFundEndMonth` | String | 公积金缴纳截止月，格式 `yyyy-MM` |
| `dataList[].socialInsureEndMonth` | String | 社保缴纳截止月，格式 `yyyy-MM` |
| `dataList[].quitApplicationStatus` | String | 离职申请状态 |
| `dataList[].handoverStatus` | String | 交接状态：`UN_START`（未开始）、`WAITING_HR_APPROVAL`（待HR审批）、`COUNTERSIGN`（会签中）、`PASSED`（已通过）、`ABANDON`（已放弃） |
| `dataList[].quitStatus` | String | 离职流程状态 |
| `dataList[].quitType` | String | 离职类型：`ACTIVE`（主动离职）、`PASSIVE`（被动离职）、`RETIRE`（退休） |
| `dataList[].quitReasonType` | String | 离职原因类型（见下方枚举） |
| `dataList[].systemTuningDepartment` | Object | 系统调优-部门 |
| `dataList[].systemTuningSubordinate` | Object | 系统调优-下属 |
| `dataList[].systemTuningAppliaction` | Object | 系统调优-应用 |

### quitReasonType 枚举（14 种）

| 枚举值 | 说明 |
|--------|------|
| `COMPENSATION` | 薪酬福利 |
| `WORK_ENVIRONMENT` | 工作环境 |
| `WORK_TIME` | 工作时间 |
| `HEALTHY` | 身体原因 |
| `PROMOTION` | 晋升发展 |
| `FAMILY` | 家庭原因 |
| `TO_MUCH_OVERTIME` | 加班过多 |
| `SELF_STARTUP` | 自主创业 |
| `LACK_OF_TRAINING` | 缺乏培训 |
| `PURSUE_NEW_CAREER` | 追求新职业 |
| `PASSIVE` | 被动离职 |
| `PROBATION` | 试用期离职 |
| `RETIRE` | 退休 |
| `OTHER` | 其他 |

### 示例请求

```bash
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

## 接口 #48：获取当日离职清单

获取当天已离职（已归档完善）的员工清单。

> ⚠️ **与 #47 的对比**：#47 返回待处理清单；#48 返回**已归档（COMPLETED）**的离职记录。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/quitForms/quited
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `date` | String | 是 | 离职日期，格式 `yyyy-MM-dd` |

### 响应参数

返回 QuitFormVO 数组，字段结构与 #47 完全一致。

| 字段 | 类型 | 说明 |
|------|------|------|
| `data` | Array | QuitFormVO 数组 |
| `data[].staffName` | String | 员工姓名 |
| `data[].departmentName` | String | 部门名称 |
| `data[].positionName` | String | 职位名称 |
| `data[].enrollInDate` | String | 入职日期 |
| `data[].applyDate` | String | 申请日期 |
| `data[].expectQuitDate` | String | 期望离职日期 |
| `data[].confirmQuitDate` | String | 确认离职日期 |
| `data[].lastWorkDay` | String | 最后工作日 |
| `data[].salarySettlement` | String | 薪资结算日 |
| `data[].houseFundEndMonth` | String | 公积金截止月 |
| `data[].socialInsureEndMonth` | String | 社保截止月 |
| `data[].quitApplicationStatus` | String | 离职申请状态 |
| `data[].handoverStatus` | String | 交接状态 |
| `data[].quitStatus` | String | 离职流程状态 |
| `data[].quitType` | String | 离职类型 |
| `data[].quitReasonType` | String | 离职原因类型（14 种） |

### 与 #47 的对比

| 对比项 | #47（待离职清单） | #48（当日已离职） |
|--------|-----------------|-----------------|
| 端点 | `/api/staff/v1/quitForms` | `/api/staff/v1/quitForms/quited` |
| 请求参数 | `pageNo`（分页） | `date`（指定日期） |
| 数据范围 | 当前待处理的离职申请 | 指定日期已归档（COMPLETED）的离职记录 |
| 分页 | 是（pageInfo） | 无分页（data 直出数组） |
| 返回结构 | QuitFormVO[]（带 pageInfo） | QuitFormVO[]（纯数组） |
| 用途 | 待审批/待处理 | 已离职完成的历史查询 |

### 示例请求

```bash
curl -X GET "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v1/quitForms/quited?date=2025-07-01" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

### 示例响应

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "staffName": "张三",
      "departmentName": "技术部",
      "positionName": "高级开发工程师",
      "enrollInDate": "2020-03-01",
      "applyDate": "2025-06-15",
      "expectQuitDate": "2025-07-15",
      "confirmQuitDate": "2025-07-01",
      "lastWorkDay": "2025-07-15",
      "salarySettlement": "2025-07-15",
      "houseFundEndMonth": "2025-07",
      "socialInsureEndMonth": "2025-07",
      "quitApplicationStatus": "COMPLETED",
      "handoverStatus": "PASSED",
      "quitStatus": "COMPLETED",

      "quitReasonType": "FAMILY"
    }
```

## 接口 #49：获取时间段内离职清单

获取指定时间范围内已离职的员工清单。

> ⚠️ **日期跨度限制**：`startDate` 到 `endDate` 的跨度不得超过 **3 个月**。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/quitForms/quitedWithinInterval
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `startDate` | String | 是 | 开始日期，格式 `yyyy-MM-dd` |
| `endDate` | String | 是 | 结束日期，格式 `yyyy-MM-dd`。与 startDate 跨度 ≤3 个月 |

### 响应参数

返回 QuitFormVO 数组，字段结构与 #47/#48 完全一致。

| 字段 | 类型 | 说明 |
|------|------|------|
| `data` | Array | QuitFormVO 数组 |
| `data[].staffName` | String | 员工姓名 |
| `data[].departmentName` | String | 部门名称 |
| `data[].positionName` | String | 职位名称 |
| `data[].enrollInDate` | String | 入职日期 |
| `data[].applyDate` | String | 申请日期 |
| `data[].expectQuitDate` | String | 期望离职日期 |
| `data[].confirmQuitDate` | String | 确认离职日期 |
| `data[].lastWorkDay` | String | 最后工作日 |
| `data[].salarySettlement` | String | 薪资结算日 |
| `data[].houseFundEndMonth` | String | 公积金截止月 |
| `data[].socialInsureEndMonth` | String | 社保截止月 |
| `data[].quitApplicationStatus` | String | 离职申请状态 |
| `data[].handoverStatus` | String | 交接状态 |
| `data[].quitStatus` | String | 离职流程状态 |
| `data[].quitType` | String | 离职类型 |
| `data[].quitReasonType` | String | 离职原因类型（14 种） |

### 三个离职接口对比

| 对比项 | #47（待处理） | #48（当日） | #49（时间段） |
|--------|-------------|------------|-------------|
| 端点 | `/api/staff/v1/quitForms` | `/api/staff/v1/quitForms/quited` | `/api/staff/v1/quitForms/quitedWithinInterval` |
| 请求参数 | `pageNo` | `date` | `startDate`, `endDate` |
| 数据范围 | 待处理离职申请 | 指定日期已归档（COMPLETED） | 时间段内已离职记录 |
| 日期跨度限制 | 无 | 单日 | ≤3 个月 |
| 分页 | 是（pageInfo） | 否（直出数组） | 否（直出数组） |
| 返回结构 | QuitFormVO + pageInfo | QuitFormVO[] | QuitFormVO[] |
| 用途 | 待审批/待处理查询 | 离职完成日查询 | 离职历史统计 |

### 示例请求

```bash
curl -X GET "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v1/quitForms/quitedWithinInterval?startDate=2025-01-01&endDate=2025-03-31" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```
