# 入职

包含接口：#38, #39, #40

## 接口 #38：获取入职字段定义

获取入职表单的字段定义（元数据），了解各字段的名称、类型、必填状态等信息。

> ⚠️ **与 #37（子集元数据定义）结构类似但字段名不同**：
> - `subsetId` vs `metaCode`
> - `flexFieldVOS` vs `fieldList`
> - `fieldName` vs `columnName`
> - `fieldType` 枚举值比 #37 更多（详见下方说明）

### 端点

```
GET /openapi/thirdparty/api/staff/v1/entrys/fields
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数

无（无需 Query/Path 参数）

### 响应结构

```
data
├── subsetList[]
│   ├── subsetId          -- 子集ID（对应 #37 的 metaCode）
│   ├── subsetName        -- 子集名称
│   ├── subsetCode        -- 子集编码
│   ├── flexFieldVOS[]    -- 字段列表（对应 #37 的 fieldList）
│   │   ├── fieldName     -- 字段标识（对应 #37 的 columnName）
│   │   ├── displayName   -- 字段展示名称
│   │   ├── fieldType     -- 字段类型
│   │   ├── isRequired    -- 是否必填
│   │   ├── codeTypeId    -- 码表类型ID（关联枚举值）
│   │   ├── sort          -- 排序
│   │   ├── maxLength     -- 最大长度
│   │   └── ...
```

### 响应参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `subsetList` | Array | 子集列表 |
| `subsetList[].subsetId` | String | 子集 ID |
| `subsetList[].subsetName` | String | 子集名称 |
| `subsetList[].subsetCode` | String | 子集编码 |
| `subsetList[].flexFieldVOS` | Array | 字段定义列表 |
| `flexFieldVOS[].fieldName` | String | 字段标识（作为 key 传入详情接口） |
| `flexFieldVOS[].displayName` | String | 字段展示名称 |
| `flexFieldVOS[].fieldType` | String | 字段类型（见下方枚举） |
| `flexFieldVOS[].isRequired` | Boolean | 是否必填 |
| `flexFieldVOS[].codeTypeId` | String | 码表类型 ID（下拉/单选等字段的枚举值来源） |
| `flexFieldVOS[].sort` | Integer | 排序值 |
| `flexFieldVOS[].maxLength` | Integer | 最大字符长度 |
| `flexFieldVOS[].placeholder` | String | 占位提示文本 |
| `flexFieldVOS[].requiredFlag` | Integer | 必填标记（0=非必填, 1=必填） |

### fieldType 枚举值

> 相比 #37 的字段类型，入职字段扩展了以下类型：
> `DEPARTMENT`、`CORPORATION`、`COMPANY_POSITION`、`SI_BENEFIT`、`HF_BENEFIT`、`BANK`、`TAX_DIVISION_CODE`、`TAX_ROLE`

| 类型 | 说明 |
|------|------|
| `TEXT` | 单行文本 |
| `TEXTAREA` | 多行文本 |
| `NUMBER` | 数字 |
| `DATE` | 日期（yyyy-MM-dd） |
| `DATETIME` | 日期时间 |
| `BOOLEAN` | 布尔 |
| `RADIO` | 单选 |
| `CHECKBOX` | 多选 |
| `SELECT` | 下拉选择 |
| `MULTI_SELECT` | 多选下拉 |
| `INPUT` | 输入框 |
| `PHONE` | 电话 |
| `EMAIL` | 邮箱 |
| `ID_CARD` | 身份证号 |
| `ATTACHMENT` | 附件 |
| `AREA` | 地区选择 |
| `DEPARTMENT` | 部门选择 |
| `CORPORATION` | 法律实体选择 |
| `COMPANY_POSITION` | 公司职位选择 |
| `SI_BENEFIT` | 社保方案 |
| `HF_BENEFIT` | 公积金方案 |
| `BANK` | 银行 |
| `TAX_DIVISION_CODE` | 税务区域代码 |
| `TAX_ROLE` | 税务角色 |

### 与 #37 结构对比

| 对比项 | #37（子集元数据） | #38（入职字段定义） |
|--------|------------------|-------------------|
| 子集标识 | `metaCode` | `subsetId` |
| 字段列表 | `fieldList[]` | `flexFieldVOS[]` |
| 字段标识 | `columnName` | `fieldName` |
| 字段类型枚举 | 基础类型 | 基础类型 + 8 种扩展（DEPARTMENT/CORPORATION 等） |
| 用途 | 自定义子集字段元数据 | 入职表单字段元数据 |

## 接口 #39：获取待入职清单

获取待入职员工的清单列表，支持分页。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/entryForms
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `pageNo` | Integer | 是 | 页码，从 1 开始 |

### 响应结构

```
data
├── pageInfo           -- 分页信息（pageNo/pageSize/totalCount/totalPages）
└── dataList[]         -- 待入职清单
    ├── entryFormId              -- 入职表单ID（关键ID，用于 #40 获取详情）
    ├── staffName                -- 员工姓名
    ├── departmentName           -- 部门名称
    ├── positionName             -- 职位名称
    ├── realityEntryDate         -- 实际入职日期
    ├── confirmEntryDate         -- 确认入职日期
    ├── mobile                   -- 手机号
    ├── idCardNo                 -- 身份证号
    ├── registrationStatus       -- 登记状态
    ├── entryApplicationStatus   -- 入职申请状态
    ├── entryStatus              -- 入职状态
    ├── entryStaffInfo           -- 是否已创建员工信息
    ├── source                   -- 来源
    ├── staffType                -- 员工类型
    ├── contractType             -- 合同类型
    └── idCardType               -- 证件类型
```

### 响应参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `pageInfo` | Object | 分页信息 |
| `pageInfo.pageNo` | Integer | 当前页码 |
| `pageInfo.pageSize` | Integer | 每页条数 |
| `pageInfo.totalCount` | Integer | 总记录数 |
| `pageInfo.totalPages` | Integer | 总页数 |
| `dataList` | Array | 待入职清单 |
| `dataList[].entryFormId` | String | **入职表单 ID**（用于 #40 获取详情） |
| `dataList[].staffName` | String | 员工姓名 |
| `dataList[].departmentName` | String | 部门名称 |
| `dataList[].positionName` | String | 职位名称 |
| `dataList[].realityEntryDate` | String | 实际入职日期，格式 `yyyy-MM-dd` |
| `dataList[].confirmEntryDate` | String | 确认入职日期，格式 `yyyy-MM-dd` |
| `dataList[].mobile` | String | 手机号 |
| `dataList[].idCardNo` | String | 身份证号（脱敏显示） |
| `dataList[].registrationStatus` | String | 登记状态：`UN_SENT`（未发送）、`WAIT_COMMIT`（待提交）、`CONFIRM`（待确认）、`PASSED`（已通过）、`REJECTED`（已拒绝）、`RECHECK`（待复核）、`CLOSED`（已关闭）、`ABANDON`（已放弃） |
| `dataList[].entryApplicationStatus` | String | 入职申请状态：`UN_START`（未开始）、`PROCESSING`（审批中）、`WAITING_HR_APPROVAL`（待HR审批）、`ARCHIVE`（已归档）、`PASSED`（已通过）、`REJECTED`（已拒绝）、`ABANDON`（已放弃）、`AUDIT`（待审核） |
| `dataList[].entryStatus` | Integer | 入职状态：`1`（待确认）、`2`（已确定） |
| `dataList[].entryStaffInfo` | Integer | 是否已创建员工信息：`0`（未创建）、`1`（已创建） |
| `dataList[].source` | Integer | 来源：`1`（新增）、`2`（导入）、`3`（招聘）、`4`（第三方） |
| `dataList[].staffType` | String | 员工类型 |
| `dataList[].contractType` | String | 合同类型 |
| `dataList[].idCardType` | String | 证件类型 |

### 示例请求

```bash
curl -X GET "https://openapi.ihr360.com/openapi/thirdparty/api/staff/v1/entryForms?pageNo=1" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

## 接口 #40：获取待入职详情

根据入职表单 ID 获取待入职员工的完整详细信息，包含 **100+ 字段**，是 HR 系统中最丰富的数据接口之一。

> ⚠️ **使用链路**：先通过 #39 获取 `entryFormId`，再传入本接口获取完整详情。
> ⚠️ 返回数据包含 **8 个嵌套子集**（教育经历/工作经历/证照/家庭成员/附件/汇报上级/成本中心/自定义字段）。

### 端点

```
GET /openapi/thirdparty/api/staff/v1/entryForms/{entryFormId}/entryInfo
```

### 鉴权方式

| 方式 | 说明 |
|------|------|
| Headers | `Authorization: Bearer {accessToken}` |

### 请求参数（Path）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `entryFormId` | String | 是 | 入职表单 ID（来自 #39 返回的 `entryFormId`） |

### 响应字段说明

#### 基本信息（~15 个字段）

| 字段 | 类型 | 说明 |
|------|------|------|
| `staffName` | String | 员工姓名 |
| `staffNo` | String | 工号 |
| `staffType` | String | 员工类型 |
| `mobile` | String | 手机号 |
| `email` | String | 邮箱 |
| `idCardType` | String | 证件类型 |
| `idCardNo` | String | 证件号码 |
| `gender` | String | 性别 |
| `birthday` | String | 出生日期，`yyyy-MM-dd` |
| `nation` | String | 民族 |
| `maritalStatus` | String | 婚姻状况 |
| `nationality` | String | 国籍 |
| `nativePlace` | String | 籍贯 |
| `address` | String | 现住址 |
| `photo` | String | 照片 URL |

#### 个人信息（~10 个字段）

| 字段 | 类型 | 说明 |
|------|------|------|
| `politicalStatus` | String | 政治面貌 |
| `healthStatus` | String | 健康状况 |
| `height` | String | 身高 |
| `weight` | String | 体重 |
| `bloodType` | String | 血型 |
| `censusRegister` | String | 户口类型 |
| `censusAddress` | String | 户口所在地 |
| `emergencyContact` | String | 紧急联系人 |
| `emergencyPhone` | String | 紧急联系电话 |
| `personalEmail` | String | 个人邮箱 |

#### 家庭信息 / 紧急联系人（~5 个字段）

| 字段 | 类型 | 说明 |
|------|------|------|
| `familyAddress` | String | 家庭地址 |
| `familyPhone` | String | 家庭电话 |
| `householdType` | String | 户籍类型 |
| `householdAddress` | String | 户籍地址 |
| `mailingAddress` | String | 通讯地址 |

#### 组织架构（~15 个字段）

| 字段 | 类型 | 说明 |
|------|------|------|
| `departmentId` | String | 部门 ID |
| `departmentName` | String | 部门名称 |
| `fullDepartmentName` | String | 完整部门路径 |
| `positionId` | String | 职位 ID |
| `positionName` | String | 职位名称 |
| `jobTitleId` | String | 职务 ID |
| `jobTitleName` | String | 职务名称 |

| `positionLevelName` | String | 职级名称 |
| `corporationId` | String | 法律实体 ID |
| `corporationName` | String | 法律实体名称 |
| `companySiteId` | String | 工作地点 ID |
| `companySiteName` | String | 工作地点名称 |
| `costCenterId` | String | 成本中心 ID |
| `costCenterName` | String | 成本中心名称 |

#### 入职配置（~10 个字段）

| 字段 | 类型 | 说明 |
|------|------|------|
| `enrollInDate` | String | 入职日期，`yyyy-MM-dd` |
| `confirmEntryDate` | String | 确认入职日期 |
| `realityEntryDate` | String | 实际入职日期 |
| `probationLength` | Integer | 试用期时长（月） |
| `probationEndDate` | String | 试用期结束日期 |
| `contractType` | String | 合同类型 |
| `contractBeginDate` | String | 合同开始日期 |
| `contractEndDate` | String | 合同结束日期 |
| `contractPeriod` | String | 合同期限 |
| `entrySource` | String | 入职来源 |

#### 银行卡信息（~12 个字段）

| 字段 | 类型 | 说明 |
|------|------|------|
| `bankName` | String | 开户行名称 |
| `bankCode` | String | 银行编码 |
| `bankAccount` | String | 银行账号 |
| `bankAccountName` | String | 银行户名 |
| `bankBranchName` | String | 支行名称 |
| `bankBranchCode` | String | 支行编码 |
| `bankProvince` | String | 银行所在省 |
| `bankCity` | String | 银行所在市 |
| `unionPayCode` | String | 银联号 |
| `bankAccountType` | String | 账户类型 |
| `bankCardType` | String | 银行卡类型 |
| `isSalaryCard` | Boolean | 是否工资卡 |

#### 工龄信息（~3 个字段）

| 字段 | 类型 | 说明 |
|------|------|------|
| `totalWorkYears` | BigDecimal | 累计工龄（年） |
| `socialSecurityYears` | BigDecimal | 社保工龄（年） |
| `calServiceAge` | BigDecimal | 司龄 |

### 嵌套子集（8 个）

| 子集字段 | 类型 | 说明 |
|---------|------|------|
| `entryEducations` | Array | 教育经历 |
| `entryWorkExperiences` | Array | 工作经历 |
| `entryCertificateVOS` | Array | 证照信息 |
| `entryFamilyVOS` | Array | 家庭成员 |
| `entryAttachments` | Array | 附件 |
| `entryReportToVoList` | Array | 汇报上级 |
| `entryStaffBreakInfoVOList` | Array | **成本中心分摊** |
| `flexAttributes` | Object | **自定义字段**（key-value 结构） |

> `entryStaffBreakInfoVOList` 为成本中心分摊信息，包含多个成本中心分配比例。
> `flexAttributes` 以 Map 形式存储所有自定义字段的值。

```bash

  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```
