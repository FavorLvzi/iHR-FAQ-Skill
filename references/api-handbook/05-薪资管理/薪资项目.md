# 系统薪资项目列表

> 接口编号：#68  
> 端点：`GET /openapi/thirdparty/api/payroll/v1/sysSalaryField/list`  
> 鉴权：Bearer access_token

---

## 描述

获取系统内置的所有薪资项目列表。**无参数，全量返回**。可用于查询每个薪资项目的 code、名称和数据类型。

---

## 与 #56 的区别

| 对比维度 | #56 方案详情 | #68 系统薪资项目 |
|---------|------------|---------------|
| 范围 | **指定方案下**的字段 | **全系统**的所有薪资项目 |
| 类型字段 | ❌ 无 | ✅ `type`（NUMBER/DATE 等） |
| 是否需要 planId | ✅ 是 | ❌ 否（全局） |

---

## 请求参数

无

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Array | 系统薪资项目列表 |

### data[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| code | String | 薪资项目 code（如 `basesalary`） |
| name | String | 薪资项目名称（如"基本工资"） |
| type | String | **数据类型**（见下方枚举） |

### type 枚举

| 值 | 含义 |
|----|------|
| `NUMBER` | 数字 |
| `DATE` | 日期 |
| `TIME` | 时间 |
| `DATETIME` | 日期时间 |
| `TEXT` | 文本 |
| `ARRAY` | 数组 |

---

## 响应示例

```json
{
    "data": [
        { "code": "basesalary", "name": "基本工资", "type": "NUMBER" },
        { "code": "positionsalary", "name": "岗位工资", "type": "NUMBER" },
        { "code": "mealallowance", "name": "餐费补贴", "type": "NUMBER" },
        { "code": "xxx", "name": "事假扣款", "type": "NUMBER" },
        { "code": "xxx", "name": "事假时长", "type": "NUMBER" }
    ],
    "code": 0,
    "message": "SUCCESS",
    "errorResult": false
}
```

---

# 获取应用于员工薪资档案的薪资项目

> 接口编号：#70  
> 端点：`GET /openapi/thirdparty/api/payroll/v1/companySalaryField/getUseInStaffSalaryFieldList`  
> 鉴权：Bearer access_token

---

## 描述

获取公司实际配置的、应用于员工薪资档案的薪资项目列表。**与 #68 的区别**——#68 返回全系统所有内置项目，而此接口仅返回**公司已启用**的薪资项目。

---

## 与 #68 的对比

| 对比维度 | #68 系统薪资项目 | #70 公司档案项目 |
|---------|---------------|----------------|
| 范围 | **全系统内置**所有项目 | **公司已启用**用于薪资档案的项目 |
| type 字段 | ✅ 有 | ❌ 无 |
| 用途 | 全局查询可用项目 | 查询员工薪资档案中实际会出现的字段 |

---

## 请求参数

无

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Array | 薪资项目列表 |

### data[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| code | String | 薪资项目 code（如 `basesalary`） |
| name | String | 薪资项目名称（如"基本工资"） |

---

## 响应示例

```json
{
    "data": [
        { "code": "basesalary", "name": "基本工资" },
        { "code": "test", "name": "测试字段" }
    ],
    "code": 0,
    "message": null,
    "errorResult": false
}
```

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。
