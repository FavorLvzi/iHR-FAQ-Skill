# 根据薪资项目获取员工月度薪资结果

> 接口编号：#69  
> 端点：`POST /openapi/thirdparty/api/payroll/v1/salaryResult/list`  
> 鉴权：Bearer access_token

---

## 描述

按薪资项目 code 列表分页查询员工的月度薪资结果。**不依赖方案 ID**，按具体的薪资项目 code 查询，可跨所有方案检索。

---

## 与 #65~#67 的区别

| 对比维度 | #65~#67 按方案查 | #69 按项目查 |
|---------|---------------|------------|
| 筛选条件 | `planId` + 部门/手机号/员工ID | **`fieldCodes`**（薪资项目 code） |
| 返回结构 | `summaryData` Map | **`salaryData`** Map |
| 分页结构 | 无分页 | Spring Data 风格分页 |
| 需要 planId | ✅ 是 | ❌ 否 |

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| fieldCodes | body | List\<String\> | **是** | 薪资项目 code 列表（从 #68 获取） |
| staffIds | body | List\<String\> | 否 | 员工 ID 列表（不填=全公司） |
| departmentId | body | long | 否 | 部门 ID（不填=全公司） |
| year | body | int | **是** | 年份 |
| month | body | int | **是** | 月份 |
| page | body | int | **是** | 页码（**从 1 开始**，每页 200 条） |

---

## 请求示例

```json
{
  "fieldCodes": ["basesalary", "positionsalary"],
  "staffIds": ["fake_data"],
  "departmentId": 111,
  "year": 2022,
  "month": 1,
  "page": 1
}
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Object | Spring Data 分页对象 |

### data.content[] 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| staffId | String | 员工 ID |
| staffName | String | 员工姓名 |
| departmentId | long | 部门 ID |
| departmentName | String | 部门名称 |
| corporationId | String | 法律实体 ID |
| corporationName | String | 法律实体名称 |
| salaryData | Map\<String, Object\> | **薪资月结果**——key=薪资项目 code, value=对应值 |

### data 分页字段

| 字段 | 类型 | 说明 |
|------|------|------|
| totalPages | int | 总页数 |
| totalElements | int | 总记录数 |
| pageable.pageNumber | int | 当前页（**从 0 开始**） |
| pageable.pageSize | int | 每页条数（200） |
| last | Boolean | 是否最后一页 |
| first | Boolean | 是否第一页 |

---

    "content": [

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。

---

## 注意事项

1. `page` 参数**从 1 开始**，但响应中 `pageable.pageNumber` 从 0 开始（Spring Data 规范）
2. 每页固定 200 条，不支持自定义 pageSize
3. `fieldCodes` 中的 code 需从 #68 系统薪资项目列表获取

# 获取员工薪资档案调整记录

> 接口编号：#60  
> 端点：`POST /openapi/thirdparty/api/payroll/v1/salaryProfile/queryWithStaffId`  
> 鉴权：Bearer access_token

---

## 描述

按员工 ID 列表批量查询薪资档案调整记录。**嵌套结构丰富**——含个税扣缴义务人信息、调整原因、以及每个薪资字段调整前后的值。

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| staffIds | body | Array\<String\> | **是** | 员工 UUID 列表（纯数组，≤100 条） |

---

## 请求示例

```json
[
    "c1e6c794-5ae7-429b-8906-c6260737e3ff",
    "44ad38fe-0345-437c-a8ff-a608b64ea3ec"
]
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Array | 调整记录列表 |

### data[]. 结构（三层嵌套）

| 字段 | 类型 | 说明 |
|------|------|------|
| staffId | String | 员工 ID |
| salaryCorporation | Object | **个税扣缴义务人信息** |
| ↳ effectiveAt | Date | 生效日期 |
| ↳ corporationId | String | 扣缴义务人 ID |
| ↳ corporationName | String | 扣缴义务人名称 |
| salaryItem | Object | **薪资调整项** |
| ↳ effectiveAt | Date | 薪资项生效日期 |
| ↳ reason | Object | **调整原因**（{id, title}） |
| ↳ salaryFields | Array | **调整的薪资字段列表** |
|  ↳ code | String | 字段 code（如 `basesalary`） |
|  ↳ name | String | 字段名称（如"基本工资"） |
|  ↳ updateBefore | String | **调整前值** |
|  ↳ updateAfter | String | **调整后值** |

---

## 调整原因枚举 (reason.id)

| 值 | 含义 |
|----|------|
| `POSITION_OR_SALARY_ADJUSTMENT` | 调岗调薪 |
| `PROBATION_REVIEW` | 转正 |
| `ONBOARD` | 入职 |
| `DIMISSION` | 离职 |
| `SALARY_ADJUSTMENT` | 调薪 |
| `OTHER` | 其他 |
| `INIT` | 初始化 |
| `PROMOTION` | 晋升调薪 |
| `DEMOTION` | 降级调薪 |

---

## 响应示例

```json
{
    "data": [
        {
            "staffId": "员工Id",
            "salaryCorporation": {
                "effectiveAt": "义务扣缴人生效日期",
                "corporationId": "义务扣缴人Id",
                "corporationName": "义务扣缴人名称"
            },
            "salaryItem": {
                "effectiveAt": "薪资项目生效日期",
                "reason": {
                    "id": "SALARY_ADJUSTMENT",
                    "title": "调薪"
                },
                "salaryFields": [
                    { "code": "basesalary", "name": "基本工资", "updateBefore": "调整前", "updateAfter": "调整后" },
                    { "code": "positionsalary", "name": "岗位工资", "updateBefore": "调整前", "updateAfter": "调整后" },
                    { "code": "transportationallowance", "name": "交通补贴", "updateBefore": "调整前", "updateAfter": "调整后" }
                ]
            }
        }
    ]
}
```

```

                         {"basesalary": 50000}
                          ↓

                        {"code": "basesalary",
                         "updateBefore": "45000",
                         "updateAfter": "50000"}
```
