# 获取公司薪资方案列表

> 接口编号：#55  
> 端点：`GET /openapi/thirdparty/api/payroll/v1/queryAllSalaryPlan`  
> 鉴权：Bearer access_token

---

## 描述

获取公司下所有薪资方案列表。**这是 #53 和 #54 的核心前置接口**——需要先调用此接口获取 `planId`，才能导入考勤数据或查询动态表头。

---

## 请求参数

无

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| message | String | 状态消息 |
| data | Array | 薪资方案列表 |
| ↳ planId | Long | 薪资方案 ID |
| ↳ planName | String | 薪资方案名称 |
| errorResult | Boolean | 错误时=true |

---

## 响应示例

```json
{
    "code": 0,
    "message": "SUCCESS",
    "data": [
        { "planId": 11111, "planName": "测试" },
        { "planId": 2222, "planName": "测试222" }
    ],
    "errorResult": false
}
```

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。

---

## 调用链路

```
#55 GET 薪资方案列表 → 得 planId
     ├── #54 GET 查动态表头 ?planId=xxx
     └── #53 POST 导入考勤数据 → attendanceInfoList[].staffId + fixedPart + flexPart
```

# 获取公司薪资方案详情

> 接口编号：#56  
> 端点：`POST /openapi/thirdparty/api/payroll/v1/queryAttendanceSalaryPlan`  
> 鉴权：Bearer access_token

---

## 描述

按 planId 列表批量查询薪资方案详情。比 #55 更丰富——除了方案基本信息外，还返回该方案下的**员工名单**和**薪资字段定义**。

---

## 与 #55 的区别

| 对比维度 | #55 方案列表 | #56 方案详情 |
|---------|-------------|-------------|
| 请求方式 | GET（无参） | **POST + 数组** |
| 筛选 | 全公司 | **按 planId 列表** |
| 员工信息 | ❌ | ✅ `planStaffList[]` |
| 字段信息 | ❌ | ✅ `salaryFieldList[]` |
| 用途 | 拿 planId 列表 | 查方案下的人和字段 |

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| planIdList | body | Array\<Long\> | **是** | 薪资方案 ID 列表（纯数组） |

---

## 请求示例

```json
[112, 323]
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| message | String | 状态消息 |
| data | Array | 方案详情列表 |

### data[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| planId | Long | 薪资方案 ID |
| planName | String | 薪资方案名称 |
| planStaffList | Array | **方案内员工列表** |
| ↳ staffId | String | 员工 ID |
| ↳ staffName | String | 员工姓名 |
| ↳ mobileNo | String | 手机号 |
| ↳ departmentId | Long | 部门 ID |
| ↳ departmentName | String | 部门名称 |
| salaryFieldList | Array | **方案薪资字段定义** |
| ↳ code | String | 字段 code（如 `salary`） |
| ↳ name | String | 字段名称（如"薪资"） |

---

## 响应示例

```json
{
    "code": 0,
    "message": "SUCCESS",
    "data": [
        {
            "planId": 11111,
            "planName": "测试",
            "planStaffList": [
                {
                    "staffId": "11111",
                    "staffName": "测试人员",
                    "departmentId": 11111,
                    "departmentName": "测试部门",
                    "mobileNo": "131311131313"
                }
            ],
            "salaryFieldList": [
                { "code": "salary", "name": "薪资" }
            ]
        }
    ],
    "errorResult": false
}
```

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。

---

## 调用链路

```
#55 GET 方案列表 → {planId, planName}[]
                    ↓
#56 POST 方案详情 → 传 [planId1, planId2, ...]
                    ↓ 返回
               planStaffList[] → 方案下员工
               salaryFieldList[] → 薪资字段定义
```

# 获取公司所有薪资项目

> 接口编号：#71  
> 端点：`GET /openapi/thirdparty/api/payroll/v1/getAllSalaryProfile`  
> 鉴权：Bearer access_token

---

## 描述

获取公司所有薪资项目列表。

---

## 三个薪资项目接口对比

| 接口 | 范围 | 字段 | 说明 |
|------|------|------|------|
| **#68** 系统薪资项目列表 | **全系统内置** | code + name + **type** | 所有内置项目，含数据类型 |
| **#70** 应用于薪资档案的项目 | **公司已启用**（档案） | code + name | 薪资档案中实际使用的字段 |
| **#71** 公司所有薪资项目 | **公司所有** | code + name | 公司所有的薪资项目 |

---

## 请求参数

无

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Array | 薪资项目列表 |

data[]. 结构：

| 字段 | 类型 | 说明 |
|------|------|------|
| code | String | 薪资项目 code |
| name | String | 薪资项目名称 |

---

## 响应示例

```json
{
    "data": [
        { "code": "basesalary", "name": "基本工资" },
        { "code": "test", "name": "测试字段" }
    ],
    "code": 0,
    "message": null,
    "errorResult": false
}
```

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。
