# 员工薪资调整

> 接口编号：#59  
> 端点：`PUT /openapi/thirdparty/api/payroll/v1/staffSalaryProfiles/{staffId}`  
> 鉴权：Bearer access_token  
> 方式：**PUT**（已归档接口中首个使用 PUT 方法的接口）

---

## 描述

第三方系统发起员工薪资调整归档后，更新员工薪资档案中对应员工的相关薪资。**写入接口**，通过 `adjustmentValue` Map 指定要调整的薪资字段和值。

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| staffId | Path | String | **是** | 员工 UUID |
| effectiveAt | body | String | **是** | 生效时间，格式 yyyy-MM-dd（不传默认当前时间） |
| changeType | body | String | 否 | 调整类型，通过 `Enum.SalaryProfileChangeType` 枚举查询选项值（默认"调岗调薪"） |
| adjustmentValue | body | Map\<String, Object\> | **是** | 调整值 `{"字段code": 调整后值}` |

---

## 请求示例

```json
{
    "effectiveAt": "2019-11-20",
    "changeType": "POSITION_OR_SALARY_ADJUSTMENT",
    "adjustmentValue": {
        "basesalary": 50000
    }
}
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| message | String | 状态消息 |
| data | String | 调整结果 |
| errorResult | Boolean | 错误时=true |

---

## 响应示例

```json
{
    "code": 0,
    "message": null,
    "data": null,
    "errorResult": false
}
```

## 注意事项

1. **PUT 方法**：这是已归档 59 个接口中唯一使用 PUT 的，调用时注意请求方式
2. `adjustmentValue` 的 key 对应薪资档案中的字段 code，具体含义需通过薪资字段定义接口查询
3. `changeType` 默认为"调岗调薪"（`POSITION_OR_SALARY_ADJUSTMENT`），可通过选项类型接口获取完整枚举
4. 适用于审批流程归档后自动更新薪资的场景，可与 flow-export 插件配合使用
