# 薪资结果定义列表

> 接口编号：#63  
> 端点：`GET /openapi/thirdparty/api/payroll/v1/queryReportDefinedList`  
> 鉴权：Bearer access_token

---

## 描述

获取薪资结果定义列表——即哪些年月有哪些薪资方案有已核算的月度结果。**这是薪资月度结果查询的入口接口**，用于定位哪些年月有数据可查。

---

## 请求参数

无

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Array | 薪资结果列表 |

### data[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| year | int | 薪资所属年份 |
| month | int | 薪资所属月份 |
| salaryPlanList | Array | 该年月下有结果的薪资方案列表 |
| ↳ planId | Long | 薪资方案 ID |
| ↳ planName | String | 薪资方案名称 |

---

## 响应示例

```json
{
    "data": [
        {
            "year": 2018,
            "month": 5,
            "salaryPlanList": [
                { "planId": 256, "planName": "1112-copy-个税报表" }
            ]
        }
    ],
    "code": 0,
    "message": "SUCCESS",
    "errorResult": false
}
```

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。

---

## 调用链路

```
#63 GET 薪资结果定义列表 → year + month + planId
                              ↓
                     后续查询月度结果明细的接口
```

# 薪资结果定义详情

> 接口编号：#64  
> 端点：`GET /openapi/thirdparty/api/payroll/v1/queryReportDefinedDetail`  
> 鉴权：Bearer access_token

---

## 描述

按方案 ID + 年/月查询薪资结果定义详情。比 #63 更详细——返回该方案下的**员工列表**和**薪资字段定义**。

**与 #63 的区别**：

| 对比维度 | #63 定义列表 | #64 定义详情 |
|---------|------------|------------|
| 参数 | 无 | `planId` + `year` + `month` |
| 响应 | 所有年月的方案列表 | **单年月单方案的员工+字段** |
| 员工信息 | ❌ | ✅ `planStaffList[]` |
| 字段信息 | ❌ | ✅ `salaryFieldList[]` |

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| planId | Query | Long | **是** | 薪资方案 ID（从 #63 或 #55 获取） |
| year | Query | int | **是** | 薪资所属年份 |
| month | Query | int | **是** | 薪资所属月份 |

---

## 请求示例

```
GET /payroll/v1/queryReportDefinedDetail?planId=3695&year=2025&month=6
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Object | 详情对象 |

### data 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| year | int | 薪资所属年 |
| month | int | 薪资所属月 |
| salaryPlanList | Array | 方案详情列表 |
| ↳ planId | Long | 方案 ID |
| ↳ planName | String | 方案名称 |
| ↳ planStaffList | Array | **方案内员工列表** |
|  ↳ staffId | String | 员工 ID |
|  ↳ staffName | String | 员工姓名 |
|  ↳ mobileNo | String | 手机号 |
|  ↳ departmentId | Long | 部门 ID |
|  ↳ departmentName | String | 部门名称 |
| ↳ salaryFieldList | Array | **薪资字段定义列表** |
|  ↳ code | String | 字段 code（如 `basesalary`） |
|  ↳ name | String | 字段名称（如"基本工资"） |

---

## 响应示例

```json
{
    "data": {
        "year": 2019,
        "month": 4,
        "salaryPlanList": [
            {
                "planId": 554,
                "planName": "基准合并计税模板",
                "planStaffList": [
                    {
                        "staffId": "0a27cd1e-465f-4a05-811e-9fc37e95c845",
                        "staffName": "池碧君",
                        "mobileNo": "13800000000",
                        "departmentId": 37,
                        "departmentName": "财务部门"
                    }
                ],
                "salaryFieldList": [
                    { "code": "basesalary", "name": "基本工资" },
                    { "code": "phasedsalaryadjustment", "name": "调薪调整" },
                    { "code": "paiddays", "name": "月计薪天数" }
                ]
            }
        ]
    }
}
```

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。

---

## 调用链路

```
#63 定义列表 → 拿 {year, month, planId}
                  ↓
#64 定义详情 → 拿 planStaffList[] + salaryFieldList[]
                  ↓
          后续按月查询薪资结果明细的接口
```
