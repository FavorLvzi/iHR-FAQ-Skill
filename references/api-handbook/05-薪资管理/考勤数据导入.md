# 查询考勤数据导入动态表头

> 接口编号：#54  
> 端点：`GET /openapi/thirdparty/api/payroll/v1/attendance/queryAttendanceFlexPart`  
> 鉴权：Bearer access_token

---

## 描述

查询指定薪资方案的考勤数据导入动态字段表头（flexPart 的字段定义）。**这是 #53 的前置接口**——先查此接口获取 flexPart 中每个 UUID 对应的字段含义，再按这些键在 #53 的 `flexPart` 中填充值。

---

## 与 #53 的配合流程

```
#54 查询 flexPart 表头 → 得到 { "UUID" : "字段名" } 映射
     ↓
#53 导入考勤数据 → 按表头中的 UUID 键在 flexPart 中填入对应值
```

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| planId | Query | long | **是** | 薪资方案 ID |
| companyId | Query | String | 否 | ⚠️ 文档参数表提到但示例 URL 未体现，按需传入 |

> **⚠️ 文档矛盾说明**：官方文档写 `companyId` 为 path 参数、`planId` 为 body 参数。但 **GET 请求不应带 body**。示例 URL 中没有任何参数。建议以实际调用时 `?planId=xxx` 的 Query 方式传参。

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| message | String | 状态消息 |
| data | Map\<String, String\> | **动态表头数据**，key=字段 UUID（或固定字段名），value=字段中文名 |
| errorResult | Boolean | 错误时=true |

## 注意事项

1. **#54 是 #53 的前置接口**——必须先用此接口查出 flexPart 的字段映射
2. UUID 类的 key 因公司而异，不可硬编码
3. 固定字段名（如 `nightWorkTime`、`appealCount`）可硬编码
4. ⚠️ 文档中参数表与示例不一致（GET 请求带 body 不合理），建议传 `?planId=xxx` 做 Query 参数

# 考勤数据导入

> 接口编号：#53  
> 端点：`POST /openapi/thirdparty/api/payroll/v1/importAttendance`  
> 鉴权：Bearer access_token

---

## 描述

向指定薪资方案（planId）按月导入员工考勤数据。**写入接口**，需先获取 `planId`（调用"获取公司薪资方案列表"接口）。

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| year | body | int | **是** | 年份 |
| month | body | int | **是** | 月份 |
| planId | body | Long | **是** | 薪资方案 ID（需从"获取公司薪资方案列表"接口获取） |
| creatorRemark | body | String | 否 | 备注 |
| attendanceInfoList | body | Array | **是** | 员工考勤信息数组 |

### attendanceInfoList[].fixedPart 固定部分字段

所有固定部分字段均为 `double` 类型，**全部必填**。

| 字段 | 说明 |
|------|------|
| workingdays | 实际出勤天数（工作天数） |
| supposedworkingdays | 应出勤天数（不包含节假日） |
| paiddays | 月计薪天数（含节假日） |
| absencefromdutydays | 缺勤天数 |
| nonWorkingDays | 非在职计薪天数 |
| othours150 | 平日加班小时-标准 |
| othours200 | 周末加班小时-标准 |
| othours300 | 节假日加班小时-标准 |
| workingdayovertimecal | 工作日加班累计（小时） |
| restdayovertimecal | 休息日加班累计（小时） |
| holidayovertimecal | 节假日加班累计（小时） |
| sickleavecnt | 扣薪病假时长 |
| unpaidleavecnt | 事假时长 |
| maternitycnt | 产假时长 |
| syntheticaladjust | 工时调整-综合 |
| syntheticalothours300 | 节假日加班小时-综合 |
| syntheticalworkhourmonth | 月工作日工时-综合 |
| syntheticalworkhourquarter | 季工作日工时-综合 |
| syntheticalworkhouryear | 年工作日工时-综合 |
| annualleavetime | 年假时长 |
| resthours | 调休时长 |
| latearrivals | 迟到次数 |
| returnearly | 早退次数 |
| signinmiss | 签到遗漏次数 |
| signoutmiss | 签退遗漏次数 |
| lateminutes | 累计迟到分钟数 |
| earlyminutes | 累计早退分钟数 |
| absencefromduty | 缺勤次数 |
| nightWorkTime | 深夜工时 |
| supposedWorkingHours | 应出勤小时数 |
| workingHours | 实出勤小时数 |

### attendanceInfoList[].flexPart 动态数据部分

| 参数 | 位置 | 类型 | 说明 |
|------|------|------|------|
| flexPart | body | Map | 动态数据（可选），对应薪资方案中自定义的考勤字段 |

## 注意事项

1. **写入接口**，调用前需确认 planId 对应的薪资方案处于可导入状态
2. `fixedPart` 中所有字段均为必填，即使值为 0 也需要传入
3. `flexPart` 可选，用于薪资方案中自定义的动态考勤字段
4. 依赖接口：「获取公司薪资方案列表」→ 获取 `planId`
