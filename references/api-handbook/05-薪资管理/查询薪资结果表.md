# 基于人员ID列表和月份查询薪资结果表

> 接口编号：#67  
> 端点：`POST /openapi/thirdparty/api/payroll/v1/querySalaryWithStaffId`  
> 鉴权：Bearer access_token

---

## 描述

按方案+年月+员工 ID 列表查询员工月度薪资结果。与 #65（按部门）、#66（按手机号）构成**三个维度的月度结果查询体系**。

---

## 三个维度对比

| 接口 | 筛选参数 | 场景 |
|------|---------|------|
| #65 按部门 | `departmentIdList` | 按部门批量查 |
| #66 按手机号 | `mobileNoList` | 按手机号精确查 |
| **#67 按员工ID** | **`staffIdList`** | **按员工UUID精确查** |

三者返回结构完全一致（`summaryData` + `phasedData`）。

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| year | body | int | **是** | 薪资所属年份 |
| month | body | int | **是** | 薪资所属月份 |
| planId | body | Long | **是** | 历史薪资方案 ID |
| staffIdList | body | List\<String\> | **是** | 员工 ID 列表 |

---

## 请求示例

```json
{
    "year": 2019,
    "month": 10,
    "planId": 1550,
    "staffIdList": ["11233323", "22232313"]
}
```

---

## 响应参数

同 #65/#66。data[] 结构：

| 字段 | 类型 | 说明 |
|------|------|------|
| staffId | String | 员工 ID |
| staffName | String | 员工姓名 |
| mobileNo | String | 手机号 |
| departmentId | Long | 部门 ID |
| departmentName | String | 部门名称 |
| summaryData | Map | 结果汇总数据 |
| phasedData | List\<Map\> | 分段数据 |

> **★ summaryData 内嵌方案名与所属月（2026-08-06 实测确认）**：
> - `salaryPlanName` = 薪资方案名称（如 "2025年总部CEO薪资方案"）
> - `salarymonth` = 薪资所属月（如 "2025-08"）
> - 另有 `taxMonth`（税款所属期）/ `taxMonthJanuary`（累计起始月）等辅助字段
> - **回答"这是哪个方案、哪个月的数据"直接读这两个字段**，无需再调 #63 反查。
> - 导航用 #63（按年月列出方案 planId+planName）→ 选 planId → #67 查询。

---

## 响应示例

```json
{
    "data": [
        {
            "staffId": "1212255555454",
            "staffName": "小董",
            "mobileNo": "151515511",
            "departmentName": "测试部门",
            "departmentId": 121,
            "summaryData": { "salary": 123.6 },
            "phasedData": [ { "salary": 155.58 } ]
        }
    ],
    "code": 0,
    "message": "SUCCESS",
    "errorResult": false
}
```

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。

# 基于人员MobileNo列表和月份查询薪资结果表

> 接口编号：#66  
> 端点：`POST /openapi/thirdparty/api/payroll/v1/querySalaryWithMobileNo`  
> 鉴权：Bearer access_token

---

## 描述

按方案+年月+手机号列表查询员工月度薪资结果。**与 #65 功能一致，但筛选方式不同**——按手机号（而非部门ID）。

---

## 与 #65 的对比

| 对比维度 | #65 按部门查 | #66 按手机号查 |
|---------|------------|--------------|
| 筛选参数 | `departmentIdList` | `mobileNoList` |
| 适用场景 | 按组织架构批量查看 | 按员工手机号精确查询 |
| 返回结构 | 完全一致 | 完全一致 |

**三个月度结果查询接口**：

| 接口 | 筛选维度 | 场景 |
|------|---------|------|
| #65 | 部门 | 按部门查薪资 |
| #66 | 手机号 | 按手机号查薪资 |
| (后续接口) | 人员ID | 按员工ID查薪资 |

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| year | body | int | **是** | 薪资所属年份 |
| month | body | int | **是** | 薪资所属月份 |
| planId | body | Long | **是** | 历史薪资方案 ID |
| mobileNoList | body | List\<String\> | **是** | 员工手机号列表 |

---

## 请求示例

```json
{
    "year": 2019,
    "month": 10,
    "planId": 1550,
```

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Array | 员工月度薪资结果列表 |

data[]. 结构（同 #65）：

|------|------|------|
| staffId | String | 员工 ID |
| staffName | String | 员工姓名 |
| mobileNo | String | 手机号 |
| departmentId | Long | 部门 ID |
| departmentName | String | 部门名称 |
| summaryData | Map | **结果汇总数据** |
| phasedData | List\<Map\> | **分段数据** |

---

## 响应示例

```json
{
    "data": [
        {
            "staffId": "1212255555454",
            "staffName": "小董",
            "mobileNo": "151515511",
            "departmentName": "测试部门",
```

# 基于部门ID和月份查询薪资结果表

> 接口编号：#65  
> 端点：`POST /openapi/thirdparty/api/payroll/v1/querySalaryWithDepartment`  
> 鉴权：Bearer access_token

---

## 描述

按方案+年月+部门 ID 列表查询员工月度薪资结果。返回每位员工的薪资明细（含汇总数据 + 分段数据）。

---

## 与 #56 的区别

| 对比维度 | #56 方案详情 | #65 月度结果 |
|---------|------------|------------|
| 查询范围 | 方案下所有人和字段定义 | **特定年月+部门的核算结果** |
| 数据内容 | 字段定义（code/name） | **实际值（summaryData/phasedData）** |
| 部门筛选 | ❌ | ✅ `departmentIdList` |
| 用途 | 查配置 | **查实发薪资** |

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| year | body | int | **是** | 薪资所属年份 |
| month | body | int | **是** | 薪资所属月份 |
| planId | body | Long | **是** | 历史薪资方案 ID（从 #63 获取） |
| departmentIdList | body | List\<Long\> | **是** | 部门 ID 列表 |

---

## 请求示例

```json
{
    "year": 2019,
    "month": 10,
    "planId": 1550,
    "departmentIdList": [112, 323]
}
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Array | 员工月度薪资结果列表 |

### data[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| staffId | String | 员工 ID |
| staffName | String | 员工姓名 |
| mobileNo | String | 手机号 |
| departmentId | Long | 部门 ID |
| departmentName | String | 部门名称 |
| summaryData | Map\<String, Object\> | **结果汇总数据**（key=字段code, value=值） |
| phasedData | List\<Map\<String, Object\>\> | **分段数据**（如多笔薪资分段发放） |

> `summaryData` 中的 code 含义可通过 #64 的 `salaryFieldList` 查询

---

## 响应示例

```json
{
    "data": [
        {
            "staffId": "1212255555454",
            "staffName": "小董",
            "mobileNo": "151515511",
            "departmentName": "测试部门",
            "departmentId": 121,
            "summaryData": { "salary": 123.6 },
            "phasedData": [ { "salary": 155.58 } ]
        }
    ],
    "code": 0,
    "message": "SUCCESS",
    "errorResult": false
}
```

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。

---

## 调用链路

```
#63 定义列表 → {year, month, planId}
#64 定义详情 → {salaryFieldList: code→name}
                  ↓
#65 月度结果 → year + month + planId + departmentIdList
                  ↓
           data[].summaryData = { "basesalary": "8000", "salary": 123.6 }
           data[].phasedData = [{ "salary": 155.58 }]
```
