# 获取员工个税扣缴义务人集合

> 接口编号：#61  
> 端点：`GET /openapi/thirdparty/api/payroll/v1/salaryStaffCorporation/query`  
> 鉴权：Bearer access_token

---

## 描述

查询单个员工的个税扣缴义务人信息列表（含历史记录）。**GET + Query 方式查询**。

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| staffId | Query | String | **是** | 员工 ID（⚠️ 文档写 path 实际为 Query） |

---

## 请求示例

```
GET /payroll/v1/salaryStaffCorporation/query?staffId=123456
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| message | String | 状态消息 |
| data | Array | 个税扣缴义务人记录列表 |
| ↳ id | Long | 记录 ID |
| ↳ corporationId | String | 扣缴义务人 ID |
| ↳ corporationName | String | 扣缴义务人名称 |
| ↳ effectiveAt | String | **生效时间** (yyyy-MM-dd) |
| ↳ inValidAt | String | **失效时间** (yyyy-MM-dd) |
| ↳ staffId | String | 员工 ID |
| ↳ changeType | String | 变动类型（如"入职"） |

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。

---

## 与 #60 的关联

#60 的响应中 `salaryCorporation` 即当前生效的个税扣缴义务人，此接口可查询完整的历史记录（含生效/失效时间）。

# 获取员工所有个税扣缴义务人和薪资档案

> 接口编号：#62  
> 端点：`POST /openapi/thirdparty/api/payroll/v1/salaryProfile/queryAllWithStaffId`  
> 鉴权：Bearer access_token

---

## 描述

**一步到位**查询员工的所有个税扣缴义务人信息 + 薪资档案值。将 #60（调整记录）和 #61（个税义务人）合并到一次调用。

**与 #60/#61 的区别**：

| 对比维度 | #60 调整记录 | #61 个税义务人 | #62 合并查询 |
|---------|------------|-------------|------------|
| 查个税义务人 | 仅 `salaryCorporation`(当前) | ✅ 全部历史 | ✅ **全部历史** |
| 薪资字段 | `updateBefore`/`updateAfter`(变更) | ❌ | **`value`(当前值)** |
| 请求方式 | POST 批量 | GET 单员工 | **POST 批量** |
| 一次调用 | ❌ | ❌ | ✅ **一步到位** |

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| staffIds | body | Array\<String\> | **是** | 员工 UUID 列表（纯数组，≤100 条） |

---

## 请求示例

```json
[
    "c1e6c794-5ae7-429b-8906-c6260737e3ff",
    "44ad38fe-0345-437c-a8ff-a608b64ea3ec"
]
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Array | 合并数据列表 |

### data[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| staffId | String | 员工 ID |
| salaryCorporationList | Array | **个税扣缴义务人列表**（全部历史） |
| ↳ effectiveAt | Date | 生效时间 |
| ↳ corporationId | String | 扣缴义务人 ID |
| ↳ corporationName | String | 扣缴义务人名称 |
| salaryProfileList | Array | **薪资档案记录列表** |
| ↳ effectiveAt | Date | 生效时间 |
| ↳ reason | Object | 原因（`{id, title}`，枚举同 #60） |
| ↳ salaryFields | Array | **薪资字段当前值** |
|  ↳ code | String | 字段 code |
|  ↳ name | String | 字段名称 |
|  ↳ value | String | **当前值**（区别于 #60 的 updateBefore/After） |
