# 根据考勤周期id获取员工设置

| 属性 | 值 |
|------|-----|
| **编号** | #98 |
| **接口地址** | `POST https://openapi.ihr360.com/openapi/thirdparty/api/tm/v1/attendance/periods/staff/settings/searchBySettingId` |
| **请求方式** | POST |
| **认证方式** | Bearer Token |
| **创建人** | Jerry Xiao |
| **创建时间** | 2022-02-24 |

## 功能描述

根据考勤周期设置ID获取对应的员工设置，返回每个周期及其绑定的员工列表。

与 #97 获取员工考勤周期设置 是**互为反向查询**的关系：
- #97：传入员工ID → 查他们使用的考勤周期
- #98：传入考勤周期设置ID → 查使用该周期的员工

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 限制 | 备注 |
|------|------|------|------|------|------|
| periodSettingIdList | body | List\<String\> | 是 | 最多100条 | 考勤周期设置ID集合 |

请求体为 **JSON 数组**（非对象），直接传入周期ID列表：

```json
["beb90c58-b973-4965-ae7c-420b39276243","db20ae02-df53-4386-b8d8-db279eb5e9f4"]
```

## 响应参数

| 参数 | 类型 | 父节点 | 备注 |
|------|------|--------|------|
| code | int | Response Body | 返回码 |
| message | String | Response Body | 错误消息 |
| data | JSONArray | Response Body | 数据 |
| errorResult | boolean | Response Body | 是否正确返回 |
| id | String | data | 考勤周期设置ID |
| periodName | String | data | 周期名称 |
| periodStartMonth | String | data | 考勤周期开始月份：THIS_MONTH / LAST_MONTH / NEXT_MONTH |
| periodStartDay | String | data | 考勤周期开始日期（日数字或"月底"） |
| periodEndMonth | String | data | 考勤周期结束月份：THIS_MONTH / LAST_MONTH / NEXT_MONTH |
| periodEndDay | String | data | 考勤周期结束日期（日数字或"月底"） |
| defaultPeriod | Boolean | data | 是否默认考勤周期 |
| enabled | Boolean | data | 是否启用 |
| staffIdList | List\<String\> | data | 使用当前周期的员工集合 |

# 获取考勤周期实例

| 属性 | 值 |
|------|-----|
| **编号** | #99 |
| **接口地址** | `POST https://openapi.ihr360.com/openapi/thirdparty/api/tm/v1/attendance/periods/instance/search` |
| **请求方式** | POST |
| **认证方式** | Bearer Token |
| **创建人** | Jerry Xiao |
| **创建时间** | 2022-02-24 |

## 功能描述

根据考勤周期实例ID获取周期实例的运行时状态，包括开始/结束日期、所属月份、锁定状态等。

**与 #95/#97/#98 的关系**：
- #95/97/98 操作的是"周期设置"（模板层），定义了周期的规则
- #99 操作的是"周期实例"（运行时层），是周期设置在具体月份上的实例化

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 限制 | 备注 |
|------|------|------|------|------|------|
| periodInstanceIdList | body | List\<String\> | 是 | 最多100条 | 考勤周期实例ID集合 |

请求体为 **JSON 数组**（非对象）：

```json
["d4843836-8c4a-46eb-875b-aabef3ecb0cc","db20ae02-df53-4386-b8d8-db279eb5e9f4"]
```

## 响应参数

| 参数 | 类型 | 父节点 | 备注 |
|------|------|--------|------|
| code | int | Response Body | 返回码 |
| message | String | Response Body | - |
| data | JSONArray | Response Body | - |
| errorResult | Boolean | Response Body | - |
| id | String | data | 周期实例ID |
| title | String | data | 周期实例标题（如"默认考勤周期-202202（20220201-20220228）"） |
| startDate | Date | data | 周期开始时间（时间戳） |
| endDate | Date | data | 周期结束时间（时间戳） |
| month | Date | data | 周期所属月份（时间戳） |
| periodSettingId | String | data | 对应的考勤周期设置ID |
| isLock | Boolean | data | 是否已锁定 |
| lockDate | Date | data | 锁定时间（null 表示未锁定） |
| staffIdList | List\<String\> | data | 使用当前周期的员工集合 |

## 响应示例

```json
{
  "code": 0,
  "message": "OK",
  "data": [
    {
      "id": "d4843836-8c4a-46eb-875b-aabef3ecb0cc",
      "title": "默认考勤周期-202202（20220201-20220228）",
      "startDate": 1702656000000,
      "endDate": 1705334399000,
      "month": 1704067200000,
      "periodSettingId": "beb90c58-b973-4965-ae7c-420b39276243",
      "isLock": false,
      "lockDate": null,
      "staffIdList": [
        "d4843836-8c4a-46eb-875b-aabef3ecb0cc",
        "db20ae02-df53-4386-b8d8-db279eb5e9f4"
      ]
    }
  ],
  "errorResult": false
}
```

## 关键字段说明

| 字段 | 说明 |
|------|------|
| title | 人类可读标题，格式：`{周期名称}-{月份}（{起}-{止}）` |
| startDate/endDate/month | **时间戳**（毫秒），需前端自行格式化 |
| periodSettingId | 关联 #95 考勤周期设置 |
| isLock/lockDate | 锁定后禁止修改该月考勤数据 |

## 考勤周期三层模型

```
考勤周期设置（#95）
  ↓ periodSettingId
周期实例（#99）—— 设置 + 具体月份 → 实例化
  ↓ staffIdList
员工归属（#97/#98）
```

## 关联接口

| 关联 | 接口 | 说明 |
|------|------|------|
| 前置 | #95 获取考勤周期设置 | 提供周期规则（模板） |
| 前置 | #97 获取员工考勤周期设置 | 按员工查周期归属 |
| 前置 | #98 根据考勤周期id获取员工设置 | 按周期查员工归属 |

## 枚举值

### periodMonth（考勤月份）

| 值 | 含义 |
|----|------|
| THIS_MONTH | 本月 |
| LAST_MONTH | 上月 |
| NEXT_MONTH | 次月 |

## 注意事项

- **前置接口**：该接口是 #94 获取月报V3 的前置依赖（提供 `periodSettingId`）
- **周期示例**：开始=上月13日 + 结束=本月12日 → 跨月周期，如 1月13日~2月12日 记为"2月"考勤
- **periodStartDay/periodEndDay**：值可能为具体日期（如"13"）或"月底"
- **staffIdList**：文档标注"通用返回类字段，实际未返回"，恒为 null
