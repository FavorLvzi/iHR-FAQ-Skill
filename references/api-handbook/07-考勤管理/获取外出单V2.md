# 获取外出单V2

> 接口编号：#87  
> 端点：`POST /openapi/thirdparty/api/tm/v2/fieldwork/orders/search`  
> 鉴权：Bearer access_token

---

## 描述

查询公司已生效/作废的外出单列表。支持按**创建时间**或**作废时间**筛选（至少选其一）。

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| createStartTime | body | String | ⚠️ | 创建开始时间，与 createEndTime 成对使用 (yyyy-MM-dd) |
| createEndTime | body | String | ⚠️ | 创建结束时间 |
| invalidStartTime | body | String | ⚠️ | 作废开始时间，与 invalidEndTime 成对使用 |
| invalidEndTime | body | String | ⚠️ | 作废结束时间 |
| staffId | body | String | 否 | 员工 ID |
| page | body | int | 否 | 页码（从 0 开始，默认 0） |
| size | body | int | 否 | 每页条数（默认 1000，最大 1000） |

> **⚠️ 至少选择创建时间与作废时间中的一个作为过滤条件**，且成对使用时两个参数都要传。

---

## 请求示例

```json
{
    "createStartTime": "2025-08-01",
    "createEndTime": "2025-08-31",
    "staffId": "4f9975fd-..."
}
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| data.content | Array | 外出单列表 |

### content[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 外出单 ID |
| staffId | String | 员工 ID |
| startTime | String | 开始时间 (yyyy-MM-dd HH:mm) |
| endTime | String | 结束时间 |
| duration | Double | 时长 |
| unit | String | 单位：`DAY`=天, `HOUR`=小时 |
| address | String | 地址（如"税务局"） |
| remarks | String | 备注 |
| processId | String | **流程 ID** |
| createTime | String | 创建时间 |

---

```json
{
    "data": {

```
