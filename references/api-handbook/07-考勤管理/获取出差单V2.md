# 获取出差单V2

> 接口编号：#88  
> 端点：`POST /openapi/thirdparty/api/tm/v2/businesstravel/orders/search`  
> 鉴权：Bearer access_token

---

## 描述

查询公司已生效/作废的出差单列表。**与 #87 外出单类似**，但多了起止时间段（上午/下午）和流程编码。

---

## 与 #87 的对比

| 字段 | #87 外出单 | #88 出差单 |
|-----|-----------|-----------|
| startPeriod/endPeriod | ❌ | ✅ `MORNING`/`AFTERNOON` |
| processCode | ❌ | ✅ 流程编码 |
| 其他字段 | 同 | 同 |

---

## 请求参数

同 #87：创建时间/作废时间（至少选一，成对使用）+ staffId + page + size。

---

## 请求示例

```json
{
    "createStartTime": "2025-08-01",
    "createEndTime": "2025-08-31",
    "staffId": "4f9975fd-..."
}
```

> **⚠️ 参数名实测修正（2026-08-07）**：创建时间字段名是 `createStartTime`/`createEndTime`（**不是** createTimeStart/createTimeEnd）——传错会报"至少选择创建时间与作废时间中的一个作为过滤条件"。

---

## 响应参数

### content[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 出差单 ID |
| staffId | String | 员工 ID |
| startTime | String | 开始时间 |
| endTime | String | 结束时间 |
| startPeriod | String | **开始时间段**：`MORNING`(上午)/`AFTERNOON`(下午)/null(精确时间) |
| endPeriod | String | **结束时间段** |
| duration | Double | 时长 |
| unit | String | 单位：`DAY`/`HOUR` |
| address | String | 地点（如"南京"） |
| remarks | String | 备注 |
| processId | String | 流程 ID |
| processCode | String | **流程编码**（如"2023101100001"） |
| createTime | String | 创建时间 |
