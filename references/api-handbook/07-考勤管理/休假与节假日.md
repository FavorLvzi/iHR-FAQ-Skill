# 获取休假单

> 接口编号：#77  
> 端点：`POST /openapi/thirdparty/api/tm/v1/vacations/orders/search`  
> 鉴权：Bearer access_token

---

## 描述

分页查询公司员工的休假单列表。是考勤管理模块的入口接口之一。

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| startTime | body | String | **是** | 开始日期 (yyyy-MM-dd)，申请单的开始时间≥该值 |
| endTime | body | String | **是** | 结束日期 (yyyy-MM-dd)，申请单的开始时间≤该值 |
| positionIds | body | String | 否 | 职位 ID 集合（**英文逗号**分隔） |
| departmentIds | body | String | 否 | 部门 ID 集合（**英文逗号**分隔） |
| vacationOrderStatus | body | String | 否 | 休假单状态：`IN_FORCE`=已生效(默认), `NOT_EFFECTIVE`=未生效, `INVALID`=已作废 |
| page | body | int | 否 | 页码（**从 0 开始**，默认 0） |
| size | body | int | 否 | 每页条数（默认 1000） |

---

## 请求示例

```json
{
    "startTime": "2020-08-01",
    "endTime": "2020-08-31",
    "positionIds": "uuid1,uuid2",
    "departmentIds": "1,2",
    "vacationOrderStatus": "IN_FORCE",
    "page": 0,
    "size": 100
}
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Object | 分页对象 |
| data.totalPages | long | 总页数 |
| data.totalElements | long | 总记录数 |
| data.content | Array | 休假单列表 |

### content[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 假单 ID |
| staffId | String | 员工 ID |
| staffName | String | 员工姓名 |
| staffNo | String | 工号 |
| departmentName | String | 部门名称 |
| positionName | String | 职位名称 |
| vacationName | String | **假期名称**（如"事假"、"年假"） |
| startTime | String | 开始时间 (yyyy-MM-dd HH:mm 或 yyyy-MM-dd 上午/下午) |
| endTime | String | 结束时间 |
| duration | Double | **休假时长** |
| unit | String | 休假单位：`天` 或 `小时` |
| remarks | String | 事由 |
| processId | String | 关联流程 ID |

## 对 flow-export 插件的价值

每个休假单记录都带 `processId`（关联流程 ID），可以配合流程台账导出插件获取对应审批流程的详细信息和附件。

# 获取法定节假日

> 接口编号：#81  
> 端点：`GET /openapi/thirdparty/api/tm/v1/vacations/statutoryHoliday/search`  
> 鉴权：Bearer access_token

---

## 描述

查询指定日期范围内的法定节假日。**仅返回放假日期和补班日期**，普通工作日/休息日不返回。

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| startDate | Query | String | **是** | 开始日期 (yyyy-MM-dd) |
| endDate | Query | String | **是** | 结束日期 (yyyy-MM-dd) |

---

## 请求示例

```
GET /tm/v1/vacations/statutoryHoliday/search?startDate=2021-01-01&endDate=2021-12-31
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Array | 节假日/补班日期列表 |

### data[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| isStatutoryHoliday | Boolean | 是否是法定节假日 |
| vacationDate | Date | **日期（时间戳）** |
| isWordDay | Boolean | 是否工作日：`true`=补班，`false`=休息 |
| holidayName | String | 法定节假日名称（如"中秋节"） |

---

## 响应示例

```json
{
    "data": [
        { "isStatutoryHoliday": false, "vacationDate": 1631923200000, "isWordDay": true, "holidayName": "" },
        { "isStatutoryHoliday": false, "vacationDate": 1632009600000, "isWordDay": false, "holidayName": "" },
        { "isStatutoryHoliday": true, "vacationDate": 1632182400000, "isWordDay": false, "holidayName": "中秋节" }
    ],
    "code": 0,
    "message": "OK",
    "errorResult": false
}
```

### 数据解读

| isStatutoryHoliday | isWordDay | 含义 |
|:------------------:|:---------:|------|
| `true` | `false` | **法定节假日休息**（如中秋节、国庆节） |
| `false` | `true` | **补班日**（周末调休上班） |
| `false` | `false` | 普通休息日 / 调休日 |

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。
