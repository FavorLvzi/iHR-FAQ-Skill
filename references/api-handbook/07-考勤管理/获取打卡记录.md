# 获取打卡记录（#91）

## 基本信息

| 项目 | 内容 |
|------|------|
| 接口编号 | #91 |
| 接口名称 | 获取打卡记录列表 |
| 接口地址 | `POST /openapi/thirdparty/api/tm/v2/signs/records/search` |
| 请求方式 | POST |
| 鉴权方式 | Bearer Token |
| 创建时间 | 2021-09-23 |
| 创建人 | Jerry Xiao |
| 最近更新 | 2025-06-17（source 枚举补充） |

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 限制 | 备注 |
|------|------|------|------|------|------|
| startTime | body | Date | 是 | yyyy-MM-dd 或时间戳 | 开始时间 |
| endTime | body | Date | 是 | yyyy-MM-dd 或时间戳 | 结束时间，跨度 ≤ 31 天 |
| staffIdList | body | List\<String\> | 否 | - | 员工 ID 集合 |
| page | body | int | 否 | 非负数 | 页码，从 0 开始，默认 0 |
| size | body | int | 否 | 正整数，最大 1000 | 每页数据条数，默认 1000 |

## 请求示例

```json
POST /openapi/thirdparty/api/tm/v2/signs/records/search
Content-Type: application/json;charset=UTF-8
Authorization: Bearer access_token

{
  "startTime": 1609462800000,
  "endTime": 1612087200000,
  "staffIdList": [
    "d4843836-8c4a-46eb-875b-aabef3ecb0cc",
    "db20ae02-df53-4386-b8d8-db279eb5e9f4"
  ],
  "page": 0,
  "size": 10
}
```

---

## 响应数据

| 参数 | 类型 | 父节点 | 备注 |
|------|------|--------|------|
| code | int | Response Body | 状态码，0=成功 |
| message | String | Response Body | 提示信息 |
| data | JSONObject | Response Body | 分页数据 |
| errorResult | Boolean | Response Body | 错误标识 |
| totalPages | long | data | 总页数 |
| totalElements | long | data | 总记录数 |
| content | JSONArray | data | 打卡记录列表 |
| staffId | String | content | 员工标识 |
| signTime | Date | content | 打卡时间（时间戳） |
| signAddress | String | content | 打卡地点 |
| source | String | content | 来源类型（见枚举值） |
| sourceDescription | String | content | 来源描述文本 |
| isActived | Boolean | content | 是否有效 |

## 响应示例

```json
{
    "code": 0,
    "message": "OK",
    "data": {
        "totalPages": 1,
        "totalElements": 2,
        "content": [
            {
                "staffId": "037e4cc4-f4de-4b36-a080-be830d15cfb5",
                "signTime": 1567867591000,
                "signAddress": "上海市中兴路1500号",
                "source": "OUT_SIGN",
                "sourceDescription": "APP",
                "isActived": true
            }
        ]
    },
    "errorResult": false
}
```
