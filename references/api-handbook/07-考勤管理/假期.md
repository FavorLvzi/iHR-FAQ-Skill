# 获取一个员工假期余额

> 接口编号：#80  
> 端点：`POST /openapi/thirdparty/api/tm/v1/vacations/limit/search`  
> 鉴权：Bearer access_token

---

## 描述

按员工 ID + 假期类型 ID 列表查询员工的假期可用余额。

**配合流程**：
```
#79 获取所有假期类型 → 得 vacationId (如 46ed3891-... 事假)
                         ↓
#80 查询假期余额 → staffId + vacationIdList → availableLimit
```

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| staffId | body | String | **是** | 员工 ID |
| vacationIdList | body | Array\<String\> | **是** | 假期类型 ID 列表（从 #78/#79 获取） |

---

## 请求示例

```json
{
    "staffId": "1acbece9-2f10-4535-8d08-e330c0f142b6",
    "vacationIdList": ["46ed3891-68af-4d44-ba1e-576036d26f77"]
}
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Array | 假期余额列表 |

### data[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| vacationId | String | 假期类型 ID（对应 #78/#79 的 leaveTypeId/id） |
| availableLimit | Double | 假期可用余额 |

---

## 响应示例

```json
{
    "data": [
        { "vacationId": "abb6c0dc-...", "availableLimit": 1.0 },
        { "vacationId": "46ed3891-...", "availableLimit": 1.0 }
    ],
    "code": 0,
    "message": "OK",
    "errorResult": false
}
```

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。

# 获取年假余额

> 接口编号：#82  
> 端点：`POST /openapi/thirdparty/api/tm/v1/vacations/annual/limit/search`  
> 鉴权：Bearer access_token

---

## 描述

按员工 ID 查询**法定年假**和**福利年假**的余额。比 #80（通用假期余额）更专精——专门针对年假，区分当年额度、当前剩余、结转额度。

---

## 与 #80 的区别

| 对比维度 | #80 通用假期余额 | #82 年假余额 |
|---------|---------------|------------|
| 查询范围 | 任意假期类型 | **仅年假** |
| 返回字段 | `availableLimit`（单一值） | **6 个字段**（当年/当前/结转） |
| 区分法定/福利 | ❌ | ✅ |

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| staffId | body | String | **是** | 员工 ID |

---

## 请求示例

```json
{
    "staffId": "afdb485f-0a93-4d2d-8e33-582f77f10ee8"
}
```

---

## 响应参数

### data 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| annualAvailableLimit | Double | **当年法定年假**（总配额） |
| annualAvailableIssueLimit | Double | **当前法定年假**（剩余） |
| annualCarryAvailableLimit | Double | **法定结转年假**（上年度结转） |
| welfareAvailableLimit | Double | **当年福利年假**（总配额） |
| welfareAvailableIssueLimit | Double | **当前福利年假**（剩余） |
| welfareCarryAvailableLimit | Double | **福利结转年假**（上年度结转） |

---

## 响应示例

```json
{
  "data": {
    "annualAvailableLimit": 28.5,
    "annualAvailableIssueLimit": 8.5,
    "annualCarryAvailableLimit": 0.0,
    "welfareAvailableLimit": 0.0,
    "welfareAvailableIssueLimit": 0.0,
    "welfareCarryAvailableLimit": 0.0
  },
  "code": 0,
  "message": null,
  "errorResult": false
}
```

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。

# 获取所有假期类型 (v2)

> 接口编号：#79  
> 端点：`GET /openapi/thirdparty/api/tm/v2/vacations/types/search`  
> 鉴权：Bearer access_token

---

## 描述

获取公司所有假期类型详情（v2）。比 #78 v1 版本字段更丰富，含假期类型枚举、额度规则、性别范围、显示规则等。

---

## 与 #78 的对比

| 对比维度 | #78 v1 | #79 v2 |
|---------|--------|--------|
| 路径 | `/tm/v1/` | **`/tm/v2/`** |
| 返回结构 | `data.leaveTypeList[]` | **`data[]`**（直出数组） |
| 字段数 | 6 个基础字段 | 20+ 字段（含配置项） |
| vacationType 枚举 | ❌ | ✅ 11 种 |
| 额度规则 | ❌ | ✅ showLimitType / limitApartShowType |
| 性别范围 | ❌ | ✅ sexScope |

---

## 请求参数

无

---

## 响应参数

### data[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 假期类型 ID（UUID） |
| companyId | String | 公司 ID |
| leaveName | String | 假期类型名称 |
| englishLeaveName | String | 英文名称 |
| vacationType | String | **假期类型枚举**（见下方） |
| standardUnit | String | 申请单位：`DAY`/`HOUR` |
| calculationUnit | String | 计算单位：`DAY`/`HOUR` |
| calculationHours | Double | 天折算小时数（如 8.0） |
| smallestUnit | Double | 最小申请时长（如 30.0 分钟） |
| stepUnit | Double | 请假步长 |
| maximumUnit | Double | 最大申请时长 |
| subType | String | 子类型：`ANNUAL_LEAVE`(法定年假)/`ANNUAL_WELFARE_LEAVE`(福利年假)/`FULL_PAY_SICK_LEAVE`(全薪病假)/`SICK_LEAVE`(普通病假) |
| isUsing | Boolean | 是否启用 |
| isDeleted | Boolean | 是否删除 |
| displayAtClient | Boolean | 额度是否客户端可见 |
| sexScope | String | 性别范围：`UNLIMITED`/`MALE`/`FEMALE` |
| showLimitType | String | 额度显示规则（见下方） |
| limitApartShowType | String | 额度分配详情显示：`APART`/`NO_APART` |

### vacationType 枚举

| 值 | 含义 |
|----|------|
| `AFFAIR_LEAVE` | 事假 |
| `ANNUAL_LEAVE` | 年假 |
| `SICK_LEAVE` | 病假 |
| `MARITAL_LEAVE` | 婚假 |
| `MATERNITY_LEAVE` | 产假 |
| `HOME_LEAVE` | 探亲假 |
| `PRENATAL_CHECK_UP` | 产检假 |
| `PATERNITY_LEAVE` | 陪产假 |
| `LACTATION_LEAVE` | 哺乳假 |
| `ADJUST_REST` | 调休 |
| `FUNERAL_LEAVE` | 丧假 |
| `OTHER_VACATION` | 其他假期 |
| `USER_DEFINED_VACATION` | 自定义假期 |

### showLimitType 枚举

| 值 | 含义 |
|----|------|
| `LIMIT_DETAIL` | 显示可用额度及分配详情 |
| `AVAILABLE_LIMIT` | 仅显示可用额度 |
| `AVAILABLE_AND_USED` | 显示可用和已休 |
| `CUSTOMIZED` | 自定义 |
| `NONE` | 不显示 |

---

## 响应示例

```json
{
  "data": [
    {
      "id": "2e7b4b92-...",
      "leaveName": "年假",
      "vacationType": "ANNUAL_LEAVE",
      "standardUnit": "HOUR",
      "calculationUnit": "HOUR",
      "calculationHours": 8.0,
      "smallestUnit": 30.0,
      "stepUnit": 30.0,
      "isUsing": true,
      "displayAtClient": true,
      "showLimitType": "LIMIT_DETAIL",
      "limitApartShowType": "NO_APART"
    }
  ],
  "code": 0,
  "message": "OK",
  "errorResult": false
}
```

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。

# 获取假期类型 (v1)

> 接口编号：#78  
> 端点：`GET /openapi/thirdparty/api/tm/v1/vacations/types/search`  
> 鉴权：Bearer access_token

---

## 描述

获取公司所有假期类型列表（v1）。返回基础信息。**v2 版本 (#79) 字段更丰富**。

---

## 请求参数

无

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data.leaveTypeList | Array | 假期类型列表 |

### leaveTypeList[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| leaveTypeId | String | 假期类型唯一标识（UUID） |
| leaveName | String | 假期类型名称（如"事假"、"调休"） |
| leaveUnit | String | 申请单位：`DAY`/`HOUR`/`YEAR` |
| calculationUnit | String | 计算单位：`DAY`/`HOUR`/`YEAR` |
| dayHourConversion | Double | 假期时长折算比率（如 8.0=1天折8小时） |
| smallestUnitValue | Float | 最小请假时长 |

---

## 响应示例

```json
{
  "data": {
    "leaveTypeList": [
      { "leaveTypeId": "abb6c0dc-...", "leaveName": "调休", "leaveUnit": "HOUR", "calculationUnit": "HOUR", "smallestUnitValue": 1 },
      { "leaveTypeId": "46ed3891-...", "leaveName": "事假", "leaveUnit": "HOUR", "calculationUnit": "HOUR", "dayHourConversion": 8.0, "smallestUnitValue": 1 }
    ]
  },
  "code": 0,
  "message": "OK",
  "errorResult": false
}
```

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。
