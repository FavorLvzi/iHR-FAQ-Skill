# 获取补卡原因（#89）

## 基本信息

| 项目 | 内容 |
|------|------|
| 接口编号 | #89 |
| 接口名称 | 获取某人补卡原因列表 |
| 接口地址 | `GET /openapi/thirdparty/api/tm/v1/appealReason/getReasonByStaffId` |
| 请求方式 | GET |
| 鉴权方式 | Bearer Token |
| 创建时间 | 2024-12-24 |
| 创建人 | Robert Lin |

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 限制 | 备注 |
|------|------|------|------|------|------|
| staffId | query | String | 是 | - | 员工ID |

## 请求示例

```
GET /openapi/thirdparty/api/tm/v1/appealReason/getReasonByStaffId?staffId=1acbece9-2f10-4535-8d08-e330c0f142b6
```

---

## 响应数据

| 参数 | 类型 | 父节点 | 备注 |
|------|------|--------|------|
| code | int | Response Body | 状态码，0=成功 |
| message | String | Response Body | 提示信息 |
| data | JSONArray | Response Body | 补卡原因列表 |
| errorResult | Boolean | Response Body | 错误标识 |
| dataId | String | data | 补卡原因ID |
| dataName | String | data | 补卡原因名称（如"迟到"） |
| enabled | Boolean | data | 是否启用 |

## 响应示例

```json
{
  "code": 0,
  "message": null,
  "url": null,
  "data": [
    {
      "dataId": "33e7ec27-39f1-4618-9840-44558d71dbb7",
      "dataName": "迟到",
      "enabled": true
    }
  ],
  "showType": 0,
  "errorResult": false
}
```

---

## 枚举值

无固定枚举值。`dataName` 由公司自定义配置，常见值如"迟到"、"早退"、"忘记打卡"等。
