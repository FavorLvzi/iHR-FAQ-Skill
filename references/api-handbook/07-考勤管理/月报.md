# 获取月报V3（#94）

## 基本信息

| 项目 | 内容 |
|------|------|
| 接口编号 | #94 |
| 接口名称 | 获取多人某月的月报数据列表V3 |
| 接口地址 | `POST /openapi/thirdparty/api/tm/v3/period/monthly/reports/search` |
| 请求方式 | POST |
| 鉴权方式 | Bearer Token |
| 创建时间 | 2024-03-08 |
| 创建人 | Jiabao Lu |
| 更新记录 | 2025-06-24 Xueyang Dong 新增 isLock/isLockName |

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 限制 | 备注 |
|------|------|------|------|------|------|
| staffIds | body | List\<String\> | 否 | 最多 100 人 | 不传默认查询所有员工 |
| periodSettingId | body | String | 是 | - | 考勤周期设置 ID（来自获取考勤周期设置接口） |
| periodMonth | body | Date | 是 | yyyy-MM | 考勤周期所属月份 |
| page | body | int | 否 | 非负数 | 页码，从 0 开始，默认 0 |
| size | body | int | 否 | 正整数，最大 100 | 每页数据条数，默认 100 |

## 请求示例

```json
POST /openapi/thirdparty/api/tm/v3/period/monthly/reports/search
Content-Type: application/json;charset=UTF-8
Authorization: Bearer access_token

{
  "staffIds": [
    "00037f28-a4d8-4e78-9ef9-bfe5fda820f7",
    "63b98d1f-83bb-4101-b4c0-3b7e194ebc82"
  ],
  "periodSettingId": "a7807fec-654c-4336-a2fa-fb346f28488",
  "periodMonth": "2024-02",
  "page": 0,
  "size": 100
}
```

## 与日报V4（#93）对比

| 维度 | 日报V4 (#93) | 月报V3 (#94) |
|------|-------------|-------------|
| 路径 | `tm/v4/daily/reports/search` | `tm/v3/period/monthly/reports/search` |
| 时间参数 | startDate/endDate（日期范围） | periodSettingId + periodMonth（考勤月度） |
| 人员参数 | staffId（单人） | staffIds[]（多人，≤100） |
| 天数统计 | 无 | supposedAttendanceDays/actualAttendanceDays/restDays |
| 加班拆分 | 仅总时长 | Total + ToRest + ToSalary（9个字段） |
| 签到详情 | signBlockList[1~5] | 无 |
| 自定义字段 | dailyCustomField | periodCustomField + periodCustomFieldInfo |
| 分页上限 | 1000 | 100 |

---

## 注意事项

- **前置依赖**：`periodSettingId` 需从 `获取考勤周期设置` 接口获取
- **假期单位**：对应 `获取假期类型` 接口的 `calculationUnit`
- **加班三列**：月报将加班按补偿方式拆分为总量 / 转调休 / 转薪资三类，可分别统计
- **两套自定义字段**：`periodCustomField`（日报汇总）和 `periodCustomFieldInfo`（月报专属）

# 获取月报出勤班次

| 属性 | 值 |
|------|-----|
| **编号** | #101 |
| **接口地址** | `POST https://openapi.ihr360.com/openapi/thirdparty/api/tm/v1/period/monthly/shift/search` |
| **请求方式** | POST |
| **认证方式** | Bearer Token |
| **创建人** | Li Song |
| **创建时间** | 2022-11-11 |

## 功能描述

获取某考勤周期下员工各**班次出勤次数汇总**。适用于统计员工在一个月内每种班次（如"固"、"晚2"、"小时工"等）各上几天班。

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 限制 | 备注 |
|------|------|------|------|------|------|
| periodSettingId | body | String | 是 | - | 考勤周期设置ID（来自 #95） |
| periodMonth | body | String | 是 | yyyy-MM | 考勤周期所属月份 |
| page | body | int | 否 | ≥0 | 页码，从0开始，默认0 |
| size | body | int | 否 | 1~100 | 每页条数，默认100，最大100 |

## 响应参数

| 参数 | 类型 | 父节点 | 备注 |
|------|------|--------|------|
| code | int | Response Body | 返回码 |
| message | String | Response Body | - |
| data | JSONObject | Response Body | 分页结构 |
| errorResult | Boolean | Response Body | - |
| totalPages | long | data | 总页数 |
| totalElements | long | data | 总个数 |
| content | JSONArray | data | 数据内容 |
| staffId | String | content | 员工ID |
| departmentId | Long | content | 部门ID |
| departmentName | String | content | 部门名称 |
| shiftAbbrMap | Map\<String,Integer\> | content | key=班次简称，value=该班次出勤次数 |

## 响应示例

```json
{
  "code": 0,
  "message": "OK",
  "data": {
    "totalPages": 1,
    "totalElements": 2,
    "content": [
      {
        "staffId": "906ebc44-bc88-4b00-9fd3-d33f3f8ac92a",
        "departmentId": 2,
        "departmentName": "部门1",
        "shiftAbbrMap": {
          "小时工": 12,
          "固": 3
        }
      },
      {
        "staffId": "f8ab170c-dca8-49e0-9593-c225a4c815a0",
        "departmentId": 2,
        "departmentName": "部门1",
        "shiftAbbrMap": {
          "晚2": 10,
          "固": 2
        }
      }
    ]
  },
  "errorResult": false
}
```

## 数据结构解读

| 特点 | 说明 |
|------|------|
| Map 聚合 | `shiftAbbrMap` 的 key 为班次简称（对应 #92 获取排班V4 的 `shiftAbbr`） |
| 计次规则 | value 是该月内该班次出现的天数（非小时） |
| 部门信息 | 附带 `departmentId/departmentName`，方便按部门汇总 |
| 无总数限制 | 该接口未限制周期跨度（不同于日报/打卡的 31 天限制） |

## 关联接口

| 关联 | 接口 | 说明 |
|------|------|------|
| 前置 | #95 获取考勤周期设置 | 提供 periodSettingId |
| 班次来源 | #92 获取排班V4 | 排班数据中提供 shiftAbbr |
| 月报主数据 | #94 获取月报V3 | 月报核心出勤/加班/假期数据 |

# 获取月报自定义字段

| 属性 | 值 |
|------|-----|
| **编号** | #102 |
| **接口地址** | `GET https://openapi.ihr360.com/openapi/thirdparty/api/tm/v1/period/custom/field/list/search` |
| **请求方式** | GET |
| **认证方式** | Bearer Token |
| **创建人** | Jerry Xiao |
| **创建时间** | 2021-06-17 |
| **更新** | 2024-01-02（新增数字类响应字段 by Jiabao Lu） |

## 功能描述

获取公司所有**月报自定义字段**的定义（元数据）。与 #94 月报V3 的 `periodCustomFieldInfo` 配合使用，形成 "字段定义 → 字段值" 链路。

## 请求参数

无

## 响应参数

| 参数 | 类型 | 父节点 | 备注 |
|------|------|--------|------|
| code | String | Response Body | 返回码 |
| message | String | Response Body | 错误消息 |
| data | JSONArray | Response Body | 数据 |
| errorResult | Boolean | Response Body | - |
| id | String | data | 自定义字段ID |
| companyId | String | data | 公司ID |
| name | String | data | 字段名称 |
| valueType | String | data | 字段类型：NUMBER / TEXT |
| unit | String | data | 字段单位 |
| roundingMode | String | data | 圆整方式（8种，见下） |
| roundingNumber | Double | data | 圆整基数 |
| numberSetting | String | data | 数字设置：GREATER_OR_EQUAL / LESS_OR_EQUAL / BETWEEN |
| greaterOrEqualNumber | Double | data | 大于等于的数字 |
| lessOrEqualNumber | Double | data | 小于等于的数字 |
| isRawData | Boolean | data | 引用时使用原始数据 |
| effectiveDate | String | data | 统计生效日期（实际未返回） |
| month | String | data | **统计生效月份**（yyyy-MM，月报特有） |
| enabled | Boolean | data | 是否启用 |
| remark | String | data | 字段说明 |
| formula | String | data | 自定义公式 |

## 与 #96（日报自定义字段）的差异

| 维度 | #96 日报自定义字段 | #102 月报自定义字段 |
|------|-------------------|---------------------|
| 接口路径 | `.../custom/field/list/search` | `.../period/custom/field/list/search` |
| 生效维度 | `effectiveDate`（日期） | `month`（月份，yyyy-MM） |
| statisticsMonthlyReport | 有值 | 恒为 null |
| effectiveDate | 有值 | 恒为 null |
| 其他字段 | 完全一致 | 完全一致 |
| 公式变量 | 引用日报变量（如出勤$班段1签到时间） | 引用月报变量（`ATT_PERIOD_BASIC$` 前缀） |

## 枚举值速查

同 #96，roundingMode 8种、valueType 2种、numberSetting 3种。

## 关联接口

| 关联 | 接口 | 说明 |
|------|------|------|
| 值读取 | #94 获取月报V3 | `periodCustomFieldInfo` 的 key 对应该接口的 `id` |
| 日报对标 | #96 获取日报自定义字段 | 同结构、不同生效维度 |
