# 获取日报V4（#93）

## 基本信息

| 项目 | 内容 |
|------|------|
| 接口编号 | #93 |
| 接口名称 | 获取某段时间内的日报数据列表V4 |
| 接口地址 | `POST /openapi/thirdparty/api/tm/v4/daily/reports/search` |
| 请求方式 | POST |
| 鉴权方式 | Bearer Token |
| 创建时间 | 2024-05-30 |
| 创建人 | Jiabao Lu |
| 更新记录 | 2025-04-16 Robert Lin 新增响应字段；2025-06-24 Xueyang Dong 新增 isLock/isLockName |

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 限制 | 备注 |
|------|------|------|------|------|------|
| staffId | body | String | 否 | - | 员工 ID |
| startDate | body | Date | 是 | yyyy-MM-dd | 开始日期 |
| endDate | body | Date | 是 | yyyy-MM-dd | 结束日期 |
| page | body | int | 否 | 非负数 | 页码，从 0 开始，默认 0 |
| size | body | int | 否 | 正整数，最大 1000 | 每页数据条数，默认 100 |

## 请求示例

```json
POST /openapi/thirdparty/api/tm/v4/daily/reports/search
Content-Type: application/json;charset=UTF-8
Authorization: Bearer access_token

{
  "staffId": "d8a27711-503d-471f-9d7b-b73d6fa79236",
  "startDate": "2024-05-27",
  "endDate": "2024-05-29",
  "page": 0,
  "size": 10
}
```

## 注意事项

- **假期单位**：假期的 Double 值单位对应 `获取假期类型` 接口的 `calculationUnit`
- **customizedLeave**：key 为自定义假期设置的 `leaveTypeId`，配合 #79 获取假期类型v2 解析
- **dailyCustomField**：key 为自定义字段 ID，配合 `获取日报自定义字段` 接口解析
- **signBlockList**：最多 5 个班段（blockNo=1~5），当 `signType="异常"` 时签退/签到信息可能为空
- **数据量**：时间跨度大的查询建议分页（默认 size=100）

| #93 获取日报V4 | `dailyCustomField` 的 key 对应本接口的 `id` |

## 注意事项

- **前置接口**：该接口为 #93/#94 的前置依赖，提供自定义字段 ID → 名称/公式的映射
- **formula 格式**：类 Excel 公式，如 `=IF(hour(出勤$班段1签到时间)>=11,1,0)` 或 `=员工基本信息$姓名`
- **statisticsMonthlyReport**：控制该字段是否被汇总到月报的 `periodCustomField`
- **圆整配置**：数值型字段的 `roundingMode` + `roundingNumber` 决定计算后如何取整

# 获取日报自定义字段值

| 属性 | 值 |
|------|-----|
| **编号** | #100 |
| **接口地址** | `POST https://openapi.ihr360.com/openapi/thirdparty/api/tm/v1/daily/custom/search` |
| **请求方式** | POST |
| **认证方式** | Bearer Token |
| **创建人** | Jerry Xiao |
| **创建时间** | 2022-03-04 |

## 功能描述

获取某段时间内某些员工的日报自定义字段**实际值**。与 #96（获取自定义字段定义/元数据）配合使用，形成 "字段定义 → 字段值" 的数据链路。

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 限制 | 备注 |
|------|------|------|------|------|------|
| staffIdIdList | body | List\<String\> | 是 | 最多100条 | 员工ID集合 |
| startDate | body | String | 是 | yyyy-MM-dd | 开始日期 |
| endDate | body | String | 是 | yyyy-MM-dd | 结束日期，与开始相差 ≤31 天 |

## 响应参数

| 参数 | 类型 | 父节点 | 备注 |
|------|------|--------|------|
| code | int | Response Body | 返回码 |
| message | String | Response Body | - |
| data | JSONArray | Response Body | 按人+日期平铺 |
| errorResult | Boolean | Response Body | - |
| staffId | String | data | 员工ID |
| signDate | Date | data | 日期 |
| dailyCustomField | Map\<String,String\> | data | key=自定义字段设置ID（对应#96的id），value=字段值 |

## 响应示例

```json
{
  "code": 0,
  "message": "OK",
  "data": [
    {
      "staffId": "63b98d1f-83bb-4101-b4c0-3b7e194ebc82",
      "signDate": "2021-01-11",
      "dailyCustomField": {
        "a0de0fa3-448b-497b-b2c2-a88e6413ed46": null,
        "7742a447-4fe1-4904-afa9-e27dfa4bc23b": "0",
        "061c370c-d33b-424c-abf8-fff6257ed276": "17.5"
      }
    }
  ],
  "errorResult": false
}
```

## 数据结构特点

| 特点 | 说明 |
|------|------|
| 平铺数组 | 非分页结构，每条=一个员工+一个日期的记录 |
| Map 结构 | `dailyCustomField` 的 key 为 UUID（对应 #96 的 `id`），value 为字符串（NUMBER 亦为字符串） |
| null 值 | 未填写的字段值为 `null` |
| 无 totalPages | 数据量由人数×天数决定，上限 100人×31天=3100条 |

## 关联接口

| 关联 | 接口 | 说明 |
|------|------|------|
| 前置 | #96 获取日报自定义字段 | 提供字段元数据（id→name/valueType/unit 映射） |
| 相关 | #93 获取日报V4 | 日报主数据（出勤/加班/假期），也含 dailyCustomField |

## 使用流程

```
#96 获取日报自定义字段 → 拿到字段id/name/valueType
    ↓
#100 获取日报自定义字段值 → 拿到每个员工每天的实际值
    ↓
前端解析：用 #96 的 id 匹配 #100 的 dailyCustomField key
```
