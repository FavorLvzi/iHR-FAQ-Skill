# 获取加班单v2

> 接口编号：#83  
> 端点：`POST /openapi/thirdparty/api/tm/v2/overtimes/orders/search`  
> 鉴权：Bearer access_token

---

## 描述

查询公司已生效（含已使用和部分使用）的加班单列表。**v2 版本**，支持分页、按员工筛选、拆分查询。

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| startTime | body | String | **是** | 开始日期 (yyyy-MM-dd) |
| endTime | body | String | **是** | 结束日期 (yyyy-MM-dd) |
| staffId | body | String | 否 | 员工 ID |
| isSplited | body | Boolean | 否 | 是否拆分，默认 `false`（拆分后展示各段加班） |
| page | body | int | 否 | 页码（**从 0 开始**，默认 0） |
| size | body | int | 否 | 每页条数（默认 1000，最大 1000） |

---

## 请求示例

```json
{
    "startTime": "2020-09-01",
    "endTime": "2020-09-31",
    "staffId": "afdb485f-0a93-4d2d-8e33-582f77f10ee8"
}
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Object | 分页对象 |
| data.totalPages | long | 总页数 |
| data.totalElements | long | 总记录数 |
| data.content | Array | 加班单列表 |

### content[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 加班单 ID |
| staffId | String | 员工 ID |
| overtimeType | String | **加班类型**：`NORMAL`(工作日)/`WEEKEND`(休息日)/`STATUTORY`(节假日) |
| startTime | String | 开始时间 (yyyy-MM-dd HH:mm) |
| endTime | String | 结束时间 |
| applyOvertimeHours | Double | **申请加班小时数**（当 isSplited=false 时返回） |
| overtimeHours | Double | **实际加班小时数** |
| overtimeEffectiveStatus | String | 有效状态：`IN_FORCE`/`USED`/`PART_USED` |
| remarks | String | 加班事由 |
| formSource | String | **来源**（8 种，见下方） |
| formSourceDescription | String | 来源描述（流程时为审批流水号） |
| processId | String | **流程 ID**（当来源为流程且 isSplited=false 时返回） |

### overtimeType 枚举

| 值 | 含义 |
|----|------|
| `NORMAL` | 工作日加班 |
| `WEEKEND` | 休息日加班 |
| `STATUTORY` | 节假日加班 |

### formSource 枚举

| 值 | 含义 |
|----|------|
| `APPLY` | 流程 |
| `IMPORT` | 导入 |
| `OPEN_API` | OpenAPI |
| `HISTORY` | 历史数据 |
| `CREATE` | HR 新增 |
| `IMPORT_INIT` | 初始化导入 |
| `HR_AMENDMENT_LIMIT` | HR 通过调休表调整 |
| `REGULAR_OVERTIME` | 固定加班 |

---

    "totalPages": 1,

      {

# 获取加班设置

> 接口编号：#84  
> 端点：`GET /openapi/thirdparty/api/tm/v1/overtimes/setting/query`  
> 鉴权：Bearer access_token

---

## 描述

查询员工的加班配置规则。**字段极其丰富**——包含月/周时长限制、时长判定方式、加班归属日规则，以及工作日/休息日/节假日的独立设置（步长、圆整、补偿方式、扣休息等）。

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| staffId | Query | String | **是** | 员工 ID |

---

## 请求示例

```
GET /tm/v1/overtimes/setting/query?staffId=abb6c0dc-...
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| data | Array | 加班设置列表 |

### data[]. 顶层字段

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 加班设置 ID |
| companyId | String | 公司 ID |
| staffMonthOvertime | Boolean | 是否控制月加班时长 |
| overtimeDuration | Double | 月加班时长上限 |
| staffWeekOvertime | Boolean | 是否控制周加班时长 |
| overtimeDurationWeek | Double | 周加班时长上限 |
| allowStaffRepairOvertime | Boolean | 允许补请加班单 |
| showHistoryHours | Boolean | 申请单上显示当月加班时长 |
| overtimeDurationType | String | **时长判定方式** |
| signScope | Integer | 加班取卡范围（分钟） |
| overlapSign | Boolean | 重叠时段打卡 |
| applyOvertimeOwnerDayType | String | **申请加班时长归属日** |
| regularOvertimeOwnerDayType | String | **固定加班时长归属日** |
| overtimeTypeJudge | String | **加班类型判定** |
| workdayDayoffSetting | Object | **工作日加班设置** |
| dayoffOvertimeSetting | Object | **休息日加班设置** |
| holidayOvertimeSetting | Object | **节假日加班设置** |

### 时间段设置（workday/dayoff/holiday OvertimeSetting）

| 字段 | 类型 | 说明 |
|------|------|------|
| enabled | Boolean | 是否启用 |
| applyMinTime | Double | 加班最小时长 |
| stepSize | Double | 加班步长 |
| stepRoundingModeType | String | **圆整方式** |
| applyMaxTime | Double | 加班最大时长 |
| cutRestType | String | **扣除休息时长方式** |
| cutRestPeriodIn | Boolean | 扣除班段内休息 |
| cutRestPeriodOut | Boolean | 扣除班段外休息 |
| overtimeCompensate | String | **补偿方式** |
| overtimeCompensation | Double | **补偿比例**（如休息日2倍） |
| carryoverTimeType | String | **生效时间** |
| limitPeriodList | Array | **按固定时长扣除设置**（当 cutRestType=BYDURATION 时） |
| ↳ conditionFrom | Double | 满足的小时数 |
| ↳ cutLimit | Double | 扣除额度 |

---

## 枚举值汇总

### overtimeDurationType

| 值 | 含义 |
|----|------|
| `APPLICATION_OVERTIME_DURATION` | 按加班单审批时长 |
| `APPLICATION_SIGN_INTERSECTION` | 取加班单与实际打卡时间交集 |
| `APPLICATION_SIGN_MIN` | 取加班单与实际打卡最小值 |
| `ACTUAL_SIGN` | 按实际打卡时间计算 |

### applyOvertimeOwnerDayType

| 值 | 含义 |
|----|------|
| `NATURAL` | 加班自然日拆分 |
| `START` | 加班开始日 |
| `END` | 加班结束日 |
| `OTHER` | 归属到就近2小时排班日 |

### regularOvertimeOwnerDayType

| 值 | 含义 |
|----|------|
| `NATURAL` | 加班自然日拆分 |
| `SCHEDULE` | 排班日 |

### overtimeTypeJudge

| 值 | 含义 |
|----|------|
| `EMPLOYEE_DISCRETION` | 员工自主判定 |
| `SCHEDULE` | 排班日历 |
| `WORK` | 工作日历 |

### stepRoundingModeType

| 值 | 含义 |
|----|------|
| `ROUND_UP` | 向上圆整 |
| `ROUND_DOWN` | 向下圆整 |
| `HALF_UP` | 保留两位小数 |

### cutRestType

| 值 | 含义 |
|----|------|
| `BYTIME` | 按时间段扣除 |
| `BYDURATION` | 按固定时长扣除 |

### overtimeCompensate

| 值 | 含义 |
|----|------|
| `TRANSFER_TO_SALARY` | 转薪资 |
| `TRANSFER_TO_REST` | 转调休 |
| `ALL` | HR 判定 |
| `EMPLOYEE_DISCRETION` | 员工自主决定 |

### carryoverTimeType

| 值 | 含义 |
|----|------|
| `UPDATE_DATE` | 更新日期 |
| `OVERTIME_OWNER_DATE` | 加班时长归属日 |
| `OVERTIME_EFFECT_DATE` | 加班时长生效日 |
| `OVERTIME_START_DATE` | 加班申请开始日 |

---

# 加班单时长试算

> 接口编号：#85  
> 端点：`POST /openapi/thirdparty/api/tm/v1/overtimes/duration/calc`  
> 鉴权：Bearer access_token

---

## 描述

试算加班单时长。根据 #84 加班设置中的规则（扣除休息、圆整方式、补偿方式等），计算申请时长和实际时长。

**配合 #84**：试算结果受 #84 中 `cutRestType`、`stepRoundingModeType`、班段内/外扣除等配置影响。

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| staffId | body | String | **是** | 员工 ID |
| startTime | body | String | **是** | 开始时间 (yyyy-MM-dd HH:mm) |
| endTime | body | String | **是** | 结束时间 (yyyy-MM-dd HH:mm) |
| overtimeHourage | body | Double | **是** | 申请加班小时数 |
| overtimeType | body | String | 否 | 加班类型：`NORMAL`(日常)/`WEEKEND`(周末)/`STATUTORY`(法定)（当加班设置中判定方式=员工自主判定时必传） |

---

## 请求示例

```json
{
    "staffId": "1acbece9-2f10-4535-8d08-e330c0f142b6",
    "startTime": "2020-08-01 10:10",
    "endTime": "2020-08-01 11:10",
    "overtimeHourage": 5.0,
    "overtimeType": "NORMAL"
}
```

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| applyOvertimeHours | Double | **申请加班时长**（已扣除班段内/外休息时间） |
| overtimeHours | Double | **实际加班时长** |

---

## 响应示例

```json
{
  "data": {
    "applyOvertimeHours": 4.0,
    "overtimeHours": 3.0
  },
  "code": 0,
  "message": null,
  "errorResult": false
}
```

---

## 测试结果

**2026-06-17**：端点可达，无 token 返回 401（符合预期）。

# 根据结转日期获取加班单

> 接口编号：#86  
> 端点：`POST /openapi/thirdparty/api/tm/v1/overtimes/orders/carryTime/search`  
> 鉴权：Bearer access_token

---

## 描述

按结转日期（转调休/转薪资时间）查询已生效加班单。比 #83 更**丰富**——含打卡时间、归属日、调休/薪资使用明细、补偿比例等字段。

---

## 与 #83 的区别

| 对比维度 | #83 获取加班单v2 | #86 结转日期查 |
|---------|----------------|--------------|
| 时间筛选 | 按**申请时间** | 按**结转/转薪资时间** |
| 必填额外参数 | ❌ | `overtimeCompensateType` |
| 结转字段 | ❌ | ✅ carryoverTime / salaryCarryoverTime |
| 打卡时间 | ❌ | ✅ signStartTime / signEndTime |
| 调休/薪资明细 | ❌ | ✅ adjustRestHour / salaryHour / surplusHour |

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| overtimeCompensateType | body | String | **是** | 补偿方式：`TRANSFER_TO_REST`(转调休)/`TRANSFER_TO_SALARY`(转薪资) |
| startTime | body | String | **是** | 开始日期 (yyyy-MM-dd)，根据补偿方式含义不同 |
| endTime | body | String | **是** | 结束日期 (yyyy-MM-dd) |
| staffId | body | String | 否 | 员工 ID |
| page | body | int | 否 | 页码（从 0 开始，默认 0） |
| size | body | int | 否 | 每页条数（默认 1000，最大 1000） |

> **startTime/endTime 含义**：补偿方式=转调休时，筛选范围是转调休时间；=转薪资时，筛选范围是转薪资时间。

---

## 请求示例

```json
{
    "overtimeCompensateType": "TRANSFER_TO_REST",
    "startTime": "2020-09-01",
    "endTime": "2020-09-31",
    "staffId": "afdb485f-0a93-4d2d-8e33-582f77f10ee8"
}
```

---

## 响应参数

### content[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 加班单 ID |
| staffId | String | 员工 ID |
| overtimeType | String | 加班类型：`NORMAL`/`WEEKEND`/`STATUTORY` |
| startTime | Date | 开始时间 |
| endTime | Date | 结束时间 |
| signStartTime | Date | **最早打卡时间** |
| signEndTime | Date | **最晚打卡时间** |
| carryoverTime | Date | **转调休时间** |
| salaryCarryoverTime | Date | **转薪资时间** |
| ownerDay | Date | **加班归属日** |
| applyOvertimeHour | Double | 申请加班小时数 |
| updateOvertimeHour | Double | **修正有效加班小时** |
| adjustRestHour | Double | **转调休小时数** |
| compensation | Double | 调休补偿比例 |
| adjustRestUsedOvertimeHour | Double | **调休已使用小时数** |
| salaryHour | Double | **转薪资小时数** |
| salaryUsedOvertimeHour | Double | **薪资已使用小时数** |
| surplusHour | Double | **HR 判定小时数**（未转调休/薪资的数据） |
| overtimeEffectiveStatus | String | 有效状态：`IN_FORCE`/`USED`/`PART_USED` |
| formSource | String | 来源（8 种，同 #83） |
| remarks | String | 加班事由 |
| processId | String | 流程 ID |
