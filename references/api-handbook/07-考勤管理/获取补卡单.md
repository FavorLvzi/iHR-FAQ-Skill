# 获取补卡单（#90）

## 基本信息

| 项目 | 内容 |
|------|------|
| 接口编号 | #90 |
| 接口名称 | 获取补卡单列表 |
| 接口地址 | `POST /openapi/thirdparty/api/tm/v1/reissues/orders/search` |
| 请求方式 | POST |
| 鉴权方式 | Bearer Token |
| 创建时间 | 2020-11-27 |
| 创建人 | Time Ma |

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 限制 | 备注 |
|------|------|------|------|------|------|
| startTime | body | Date | 是 | 格式：yyyy-MM-dd | 申请单开始时间 ≥ 该值 |
| endTime | body | Date | 是 | 格式：yyyy-MM-dd | 申请单开始时间 ≤ 该值 |
| staffId | body | String | 否 | - | 员工ID |
| page | body | int | 否 | 非负数 | 页码，从0开始，默认0 |
| size | body | int | 否 | 正整数，最大1000 | 每页数据条数，默认1000 |

## 请求示例

```json
POST /openapi/thirdparty/api/tm/v1/reissues/orders/search
Content-Type: application/json;charset=UTF-8
Authorization: Bearer access_token

{
    "startTime": "2020-08-01",
    "endTime": "2020-08-31",
    "staffId": "afdb485f-0a93-4d2d-8e33-582f77f10ee8"
}
```

---

## 响应数据

| 参数 | 类型 | 父节点 | 备注 |
|------|------|--------|------|
| code | int | Response Body | 状态码，0=成功 |
| message | String | Response Body | 提示信息 |
| data | JSONObject | Response Body | 分页数据 |
| errorResult | Boolean | Response Body | 错误标识 |
| totalPages | long | data | 总页数 |
| totalElements | long | data | 总记录数 |
| content | JSONArray | data | 补卡单列表 |
| id | String | content | 补卡单ID |
| staffId | String | content | 员工ID |
| reissueTime | Date | content | 补卡时间，格式：yyyy-MM-dd HH:mm:ss |
| processId | String | content | 审批流程ID |

## 响应示例

```json
{
    "data": {
        "totalPages": 1,
        "totalElements": 1,
        "content": [
            {
                "id": "8e464425-66e0-449d-a936-ef239fa9c898",
```

## 枚举值

无固定枚举值。
