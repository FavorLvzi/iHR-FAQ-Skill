# 获取排班V4（#92）

## 基本信息

| 项目 | 内容 |
|------|------|
| 接口编号 | #92 |
| 接口名称 | 批量获取所有排班班次列表 |
| 接口地址 | `POST /openapi/thirdparty/api/tm/v4/schedules/actual/all` |
| 请求方式 | POST |
| 鉴权方式 | Bearer Token |
| 创建时间 | 2022-03-14 |
| 创建人 | Jerry |

---

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 限制 | 备注 |
|------|------|------|------|------|------|
| startTime | body | Date | 是 | yyyy-MM-dd | 排班日期开始时间 |
| endTime | body | Date | 是 | yyyy-MM-dd | 排班日期结束时间，跨度 ≤ 31 天 |
| staffIdList | body | List\<String\> | 否 | 最多 100 人 | 员工 ID 集合 |

## 请求示例

```json
POST /openapi/thirdparty/api/tm/v4/schedules/actual/all
Content-Type: application/json;charset=UTF-8
Authorization: Bearer access_token

{
  "startTime": "2021-01-01",
  "endTime": "2021-01-31",
  "staffIdList": [
    "d4843836-8c4a-46eb-875b-aabef3ecb0cc",
    "db20ae02-df53-4386-b8d8-db279eb5e9f4"
  ]
}
```

---

## 响应数据

| 参数 | 类型 | 父节点 | 备注 |
|------|------|--------|------|
| code | int | Response Body | 状态码，0=成功 |
| message | String | Response Body | 提示信息 |
| data | JSONArray | Response Body | 排班列表（非分页） |
| errorResult | Boolean | Response Body | 错误标识 |
| staffId | String | data | 员工 ID |
| shiftId | String | data | 班次 ID（"0"=休息日） |
| shiftAbbr | String | data | 班次简称（如"休"、"白"、"晚"） |
| planDate | Date | data | 排班日期 |
| isWorkingDay | Boolean | data | 是否是工作日 |

## 响应示例

```json
{
  "code": 0,
  "message": "OK",
  "data": [
    {
      "staffId": "d4843836-8c4a-46eb-875b-aabef3ecb0cc",
      "shiftId": "0",
      "shiftAbbr": "休",
      "planDate": "2021-09-01",
      "isWorkingDay": false
    },
    {
      "staffId": "db20ae02-df53-4386-b8d8-db279eb5e9f4",
      "shiftId": "0",
      "shiftAbbr": "休",
      "planDate": "2021-09-02",
      "isWorkingDay": false
    }
  ],

```

---

## 注意事项

- **v4 版本**：路径含 `/v4/`，是最新的批量排班查询接口
- **非分页**：`data` 为平铺数组，无 `totalPages/totalElements`，载荷量取决于时间范围 × 人数
- **无参数时**：不传 `staffIdList` 时返回全公司在时间范围内的所有排班（注意数据量）
- **休息日**：`shiftId = "0"`、`shiftAbbr = "休"`、`isWorkingDay = false`

## 枚举值

| 字段 | 说明 |
|------|------|
| shiftAbbr | 由公司排班规则定义（如"白班"/"晚班"/"休"/"行政班"等），非固定枚举 |
| isWorkingDay | `true`=工作日，`false`=休息日 |
