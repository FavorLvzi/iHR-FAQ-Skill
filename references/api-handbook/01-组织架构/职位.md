# 职位

> 包含接口：#15（获取公司职位清单V2）、#16（获取部门下的职位清单）、#17（根据职位id获取职位清单）、#18（根据职位id获取适用职级）

---

## 接口 #15：获取公司职位清单V2

```
POST https://openapi.ihr360.com/openapi/thirdparty/api/org/v1/organizations/positions/search
```

**描述**：分页查询公司下所有职位清单，支持按字段筛选。与 #9 部门搜索的请求结构相同。

**鉴权**：Bearer token

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| page | body | int | 否 | 0=第一页 |
| size | body | int | 否 | 每页条数 |
| flexSearchItems | body | Array | 否 | 字段查询条件数组 |
| ↳ searchKey | String | 否 | 搜索字段名（如 `positionCode`, `positionName`） |
| ↳ searchParam | String | 否 | 搜索值 |
| ↳ searchType | String | 否 | `EQUAL`/`LIKE`/`IN` |

### 请求示例

```json
{
    "page": 0,
    "size": 1,
    "flexSearchItems": [
        {
            "searchKey": "positionCode",
            "searchParam": "1212",
            "searchType": "EQUAL"
        }
    ]
}
```

### 响应字段

`data.content[]` 内每个对象：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 职位 ID（UUID） |
| companyId | String | 公司 ID |
| positionName | String | 职位名称（≤100） |
| abbreviation | String | 简称（≤100） |
| positionCode | String | 职位编号（≤50） |
| appliedRange | String | 应用范围：`CURRENT_DEPARTMENT`/`CURRENT_DEPARTMENT_AND_CHILDREN`/`ALL_DEPARTMENT` |
| capacity | Integer | 当前编制人数 |
| effectiveDate | String | 生效日期 |
| departmentId | Long | 所属部门 ID |
| departmentName | String | 所属部门名称（≤128） |
| positionScope | List | 应用范围部门 ID 列表 |
| description | String | 职位描述（≤255） |
| jobTitleId | String | 对应职务 ID |
| jobTitleName | String | 对应职务名称 |
| positionGradeId | String | 对应职级 ID |
| positionGradeName | String | 对应职级名称 |
| qualifications | String | 任职资格 |
| parentId | String | 父级编号 |
| isPositionGroup | Boolean | 是否为职位组 |
| positionState | String | 职位状态：`1`=启用，`0`=停用 |
| positionStateString | String | 职位状态（字符串） |
| updatedDate | String | 更新时间 |
| createdDate | String | 创建时间 |

### 响应示例

## 接口 #16：获取部门下的职位清单

```
GET https://openapi.ihr360.com/openapi/thirdparty/api/org/v1/organizations/positions?departmentId={deptId}
```

**描述**：获取指定部门下的职位清单。部门被删除也可以查询到职位数据。响应为直出数组（无分页）。

**鉴权**：Bearer token

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| departmentId | Query | Long | 否 | 部门 ID（不传可能返回全公司，文档未明确） |

### 响应字段

`data[]` 直出数组（无分页）。字段与 #15 基本一致，差异点见下方对比表格。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 职位 ID（UUID） |
| companyId | String | 公司 ID |
| positionName | String | 职位名称（≤100） |
| abbreviation | String | 简称（≤100） |
| positionCode | String | 职位编号（≤50） |
| appliedRange | String | 应用范围：`CURRENT_DEPARTMENT`/`CURRENT_DEPARTMENT_AND_CHILDREN`/`ALL_DEPARTMENT` |
| capacity | Integer | 当前编制人数 |
| effectiveDate | String | 生效日期 |
| departmentId | Long | 所属部门 ID |
| departmentName | String | 所属部门名称（≤128） |
| positionScope | List | 应用范围部门 ID 列表 |
| description | String | 职位描述（≤255） |
| jobTitleId | String | 对应职务 ID |
| jobTitleName | String | 对应职务名称 |
| positionGradeId | String | 对应职级 ID |
| positionGradeName | String | 对应职级名称 |
| qualifications | String | 任职资格 |
| parentId | String | 父级编号 |
| isPositionGroup | Boolean | 是否为职位组 |
| positionState | String | ⚠️ `ENABLE`=启用, `DISABLE`=停用（与 #15 的 `1`/`0` 不同） |
| positionStateString | String | 职位状态（字符串） |
| updatedDate | String | 更新时间 |
| createdDate | String | 创建时间 |

### 响应示例

```json
{

        {
            "id": "140d90aa-19cf-48a9-a29a-453b4276b64f",
            "companyId": "753e2789-2520-44d5-8467-54540398395a",
            "positionName": "aaaa",
            "abbreviation": "aaaa",
            "positionCode": "347",
            "appliedRange": "CURRENT_DEPARTMENT",
            "departmentId": 1,
            "positionScope": [0, 1],
            "description": "12",
            "departmentName": "DD",
            "capacity": 5,
            "effectiveDate": "2024-04-04",
            "jobTitleId": "12231332-5741-49ed-9ed4-1058731eab19",
            "jobTitleName": "宣传总监",
            "positionGradeId": null,
            "positionGradeName": null,
            "qualifications": "11",
            "parentId": null,
            "isPositionGroup": false,
            "scopeList": null,
            "positionState": "ENABLE",
            "updatedDate": "2023-12-19 11:30:53",

    ],
    "code": 0,

```

> ⚠️ **positionState 枚举差异**：此接口返回 `ENABLE`/`DISABLE`（字符串），而 #15 接口返回 `1`/`0`（字符串数字）。开发时需根据接口分别处理。

## 接口 #17：根据职位id获取职位清单

```
POST https://openapi.ihr360.com/openapi/thirdparty/api/org/v1/organizations/positionIds
```

**描述**：根据职位 ID 数组批量获取职位详情（请求体为 UUID 字符串数组）。响应 data[] 直出（无分页）。

**鉴权**：Bearer token

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| positionIds | body | Array\<String\> | **是** | 职位 UUID 数组 |

### 请求示例

```json
[
    "205b12be-7289-4491-b08a-0a065cbe4187",
    "b4c7ee35-6740-42c0-b64f-dc1aabad971f"
]
```

### 响应字段

`data[]` 直出数组。字段与 #16 一致（positionState 也为 `ENABLE`/`DISABLE`）。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 职位 ID（UUID） |
| companyId | String | 公司 ID |
| positionName | String | 职位名称（≤100） |
| abbreviation | String | 简称（≤100） |
| positionCode | String | 职位编号（≤50） |
| appliedRange | String | 应用范围 |
| capacity | Integer | 编制人数 |
| effectiveDate | String | 生效日期 |
| departmentId | Long | 所属部门 ID |
| departmentName | String | 所属部门名称 |
| positionScope | List | 应用范围部门 ID |
| description | String | 职位描述 |
| jobTitleId | String | 职务 ID |
| jobTitleName | String | 职务名称 |
| positionGradeId | String | 职级 ID |
| positionGradeName | String | 职级名称 |
| qualifications | String | 任职资格 |
| parentId | String | 父级编号 |
| isPositionGroup | Boolean | 是否职位组 |
| positionState | String | `ENABLE`/`DISABLE` |
| updatedDate | String | 更新时间 |
| createdDate | String | 创建时间 |

## 三个职位接口对比

| 维度 | #15 公司职位清单V2 | #16 部门下职位清单 | #17 按ID查职位 |
|------|------------------|------------------|--------------|
| 端点尾缀 | `/positions/search` | `/positions` | `/positionIds` |
| 请求方式 | POST | GET + Query | POST |
| 筛选方式 | flexSearchItems | departmentId | positionIds 数组 |
| 分页 | ✅ | ❌ | ❌ |
| 返回结构 | `data.content[]` 分页包裹 | `data[]` 直出 | `data[]` 直出 |
| positionState | `1`/`0` | `ENABLE`/`DISABLE` | `ENABLE`/`DISABLE` |
| 用途 | 搜索/浏览 | 部门下全量 | 已知ID精准查询 |

## 接口 #18：根据职位id获取适用职级

```
POST https://openapi.ihr360.com/openapi/thirdparty/api/org/v1/organizations/positions/getPositionGrade
```

**描述**：根据职位 ID 列表查询每个职位所适用的职级。

**鉴权**：Bearer token

> ⚠️ **响应结构特殊**：`data` 是 `Map<positionId, positionGrade[]>`，不是普通数组。

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| positionIds | body | Array\<String\> | **是** | 职位 UUID 数组 |

### 请求示例

```json
[
  "5dc6c775-7ee9-4be4-aabc-f195fd362ce8",
  "596fd812-fa5a-410d-883d-2d4866403dda"
]
```

### 响应字段

`data` 是 Map，key=职位ID，value=职级对象数组：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 职级 ID |
| createdDate | Long | 创建时间（Unix 毫秒时间戳） |
| companyId | String | 公司 ID |
| positionGradeNum | Integer | 职级级别 |
| positionGradeName | String | 职级名称 |
| jobCategoryId | String | 职务分类 ID |
| jobCategoryName | String | 职务分类名称 |
| gradeGroupId | Integer/Long | 职级分组 ID |
| gradeGroupName | String | 职级分组名称 |

### 响应示例

⚠️ 注意 `data` 为 **JSON Object（Map）** 结构，key 为职位 UUID，value 为该职位适用的职级数组：

