# 法律实体 · 工作地点 · 职务分类

> 包含接口：#22（获取法律实体清单v3）、#23（获取工作地点清单）、#24（获取职务分类清单）

---

## 接口 #22：获取法律实体清单v3

```
POST https://openapi.ihr360.com/openapi/thirdparty/api/org/v1/corporations/search
```

**描述**：分页搜索法律实体，支持按 flexSearchItems 筛选（含名称 LIKE 模糊、ID IN 批量查询等）。请求结构与 #9 部门搜索类似，但参数名略有差异。

**鉴权**：Bearer token

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| page | body | int | 否 | 0=第一页 |
| pageSize | body | int | 否 | ⚠️ 每页条数（注意这里是 `pageSize`，不是 `size`） |
| flexSearchItems | body | Array | 否 | 字段查询条件数组 |
| ↳ searchKey | String | 否 | 搜索字段名（如 `id`, `companyName`） |
| ↳ searchParam | String | 否 | 搜索值（IN 查询可传逗号分隔的多个 UUID） |
| ↳ searchType | String | 否 | `EQUAL`/`LIKE`/`IN` |

> ⚠️ **参数名差异**：#9 部门搜索用 `size`，此接口用 `pageSize`。其他结构一致。

### 请求示例（IN 查询多个法律实体 ID）

```json
{
    "page": 0,
    "pageSize": 5,
    "flexSearchItems": [
        {
            "searchKey": "id",
            "searchParam": "5088d106-...,010a0f98-...",
            "searchType": "IN"
        }
    ]
}
```

### 响应字段

`data.content[]` 内每个对象：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 法律实体 ID |
| companyName | String | 法律实体名称（≤100） |
| taxNo | String | **社会信用代码** |
| taxArea | String | 报税区域 |
| status | String | 企业报税登记状态：`NOT_VERIFIED`/`VERIFY_SUCCESS`/`VERIFY_FAILURE` |
| address | String | 地址 |
| phone | String | 电话 |
| bankName | String | 开户银行 |
| bankAccount | String | 银行账号 |
| companyCode | String | 公司代码 |
| companyAbbreviation | String | 公司简称 |
| establishmentDate | String | 成立时间 |
| acquisitionDate | String | 收购时间 |
| companyType | String | 公司类型：`DirectManagement`/`Trusteeship` |
| personnelScopeCode | String | 人事范围代码 |
| personnelScope | String | 人事范围 |
| salaryRangeCode | String | 工资范围代码 |
| salaryRange | String | 工资范围 |
| bankTransferCode | String | 银行传盘代码 |
| bankTransferName | String | 银行传盘名称 |
| legalPerson | String | 法人 |
| remarks | String | 备注 |
| isDeleted | int | 0=未删除, 1=已删除 |
| staffIds | String | 适用对象员工 ID 列表 |
| departmentIds | String | 适用对象部门 ID 列表 |

### 响应示例

```json
{
  "data": {
    "totalPages": 1,
    "totalElements": 1,
    "content": [
      {
        "id": "9ccfc1a6-9a69-4317-a95a-9d909a6f8a28",
        "companyName": "3333325",
        "taxNo": "/2352352//",
        "taxArea": "110000",

        "departmentIds": [5547]
      }
    ],
    "end": true

  "code": 0,
  "message": "OK",
  "errorResult": false
}
```

## 接口 #23：获取工作地点清单

```
GET https://openapi.ihr360.com/openapi/thirdparty/api/org/v1/companysites
```

**描述**：获取全公司工作地点清单。GET 请求，无入参，返回全量数据（无分页）。  
**关联**：#10/#11 创建/更新部门接口中的 `companySiteId` 即关联此接口的 `id`。

**鉴权**：Bearer token

### 请求参数

无。

### 响应字段

`data[]` 内每个对象：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 工作地点 ID（UUID） |
| createdDate | Date | 创建时间 |
| isDeleted | Boolean | 是否删除 |
| companyId | String | 公司 ID |
| siteName | String | 地址名称（≤100，如"北京"、"上海"） |
| country | String | 国家/地区（如 `CN`） |
| province | String | 省（代码格式，如 `110000`=北京, `310000`=上海） |
| city | String | 城市（代码格式，如 `110100`=北京市, `310100`=上海市） |
| address | String | 详细地址（≤255） |
| siteType | String | 地点类型：`Register`=注册地址, `Headquarters`=总部地址, `Branch`=分支办公地址 |
| status | Boolean | 状态 |
| longitude | Double | 经度 |
| latitude | Double | 纬度 |
| remark | String | 描述 |

## 接口 #24：获取职务分类清单

```
GET https://openapi.ihr360.com/openapi/thirdparty/api/org/v1/jobCategory/get
```

**描述**：获取全公司所有职务分类清单。GET 请求，无入参，返回全量数据（无分页）。  
**关联**：#19 职务清单中的 `jobCategoryId`/`jobCategoryName`/`jobCategoryCode` 即关联此接口。

**鉴权**：Bearer token

### 请求参数

无。

### 响应字段

`data[]` 内每个对象（仅 3 个字段）：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 职务分类 ID |
| jobCategoryName | String | 职务分类名称（如"专业类"、"商务类"） |
| jobCategoryCode | String | 职务分类编码（如 "Professional class"、"Business"） |

> ⚠️ **响应结构差异**：此接口响应中有额外的顶层字段 `result`(Boolean)、`errorCode`、`errorMessage`，与常规格式略有不同，但 `data`、`code`、`message` 仍在正常位置，兼容处理即可。

### 响应示例

注意顶层包含 `result`/`errorCode`/`errorMessage` 字段：

```json
{
    "result": true,
    "errorCode": null,
    "errorMessage": null,
    "data": [
        {
            "id": "e4502983-4152-4c9e-9b9f-481b4c521ce8",
            "jobCategoryName": "专业类",
            "jobCategoryCode": "Professional class"
        },
        {
            "id": "83d54c42-46b3-4def-a620-26f5da99f8e8",
            "jobCategoryName": "商务类",
            "jobCategoryCode": "Business"
        }
    ],
    "code": 0,
    "message": null
}
```

## 三接口摘要对比

| 维度 | #22 法律实体清单v3 | #23 工作地点清单 | #24 职务分类清单 |
|------|-------------------|----------------|----------------|
| 端点 | `/corporations/search` | `/companysites` | `/jobCategory/get` |
| 请求方式 | POST | GET | GET |
| 分页参数 | `page` + `pageSize` | 无分页 | 无分页 |
| 字段数量 | 20+ | 12 | 3 |
| 特殊注意 | `pageSize` 而非 `size` | province/city 为代码格式 | 含 `result`/`errorCode` 顶层字段 |

---

**测试结果**（2026-06-17）：三个接口端点均可达，无 token 返回 `401 Access Denied`（符合预期）。
