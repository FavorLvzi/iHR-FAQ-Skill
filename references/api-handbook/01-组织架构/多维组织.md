# 多维组织

> 包含接口：#25（查询多维组织）

---

## 接口 #25：查询多维组织

```
GET https://openapi.ihr360.com/openapi/thirdparty/api/dimensionOrganization/v1/dimension/organizations?dimensionId={id}&departmentStatus=ENABLE
```

**描述**：按维度 ID 查询多维组织的部门清单。多维组织是 iHR360 较新的组织管理功能，路径在 `dimensionOrganization/v1/` 下，与标准组织架构接口不同。部门被删除后也可查询到。

**鉴权**：Bearer token

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| dimensionId | Query | String | **是** | 维度 ID |
| departmentStatus | Query | String | 否 | 部门状态（默认 `ENABLE`） |

### 响应字段

`data[]` 内每个对象：

| 字段 | 类型 | 说明 |
|------|------|------|
| departmentId | Long | 部门 ID |
| departmentName | String | 部门名称（≤128） |
| parentDepartmentId | Long | 上级部门 ID（-1=无） |
| organizationChartNodeType | String | 部门类型：`COMPANY`/`DEPARTMENT`/`STORE` |
| departmentStatus | String | `ENABLE`/`DISABLE` |
| departmentDesc | String | 组织描述 |
| departmentProperty | String | 组织属性 |
| sequence | String | 顺序 |
| abbreviation | String | 简称 |
| establishDate | String | 设立日期 |
| effectiveDate | String | 生效日期 |
| remark | String | 备注 |

## 与 #9 标准部门搜索的对比

| 维度 | #9 标准部门搜索 | #25 多维组织查询 |
|------|---------------|----------------|
| 基础路径 | `/org/v1/organizations/search` | `/dimensionOrganization/v1/dimension/organizations` |
| 请求方式 | POST | GET + Query |
| 必填参数 | 无（page/size 可选） | **dimensionId 必填** |
| 分页 | ✅ `data.content[]` 分页包裹 | ❌ `data[]` 直出 |
| 部门 ID 字段 | `uuid`(String) + `id`(Long) | `departmentId`(Long) |
| 上级部门 ID 字段 | `parentId`(Long) | `parentDepartmentId`(Long) |
| 部门类型字段 | `type`(String) | `organizationChartNodeType`(String) |
| departmentStatus 筛选 | flexSearchItems 传 | 直接 query 参数 `?departmentStatus=ENABLE` |
| 特有字段 | `name`, `departmentCode`, `storeNumber`, `principalStaffId`, `customField01~10` 等 | 无特有字段，字段列表为 #9 子集 |
| 自定义字段 | ✅ customField01~10 | ❌ 无 |
