# 职务 · 职级 · 体系表

> 包含接口：#19（获取职务清单）、#20（获取职级清单）、#21（获取体系表清单）

---

## 组织关系

```
职务分类(jobCategory) → 职务(jobTitle) → 职位(position) → 职级(positionGrade)
                                                              ↓
                                                        职级分组(gradeGroup)
                                                              ↓
                                                        体系表: 序列 → 子序列 → 职层 → 职级
```

---

## 接口 #19：获取职务清单

```
GET https://openapi.ihr360.com/openapi/thirdparty/api/org/v1/organizations/jobTitles
```

**描述**：获取公司下所有职务清单。GET 请求，无入参，返回全量数据（无分页）。

**鉴权**：Bearer token

### 请求参数

无。GET 请求，无需请求体。

### 响应字段

`data[]` 内每个对象：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 职务 ID |
| companyId | String | 公司 ID |
| createdDate | Date | 创建时间 |
| jobTitleName | String | 职务名称（≤40） |
| abbreviation | String | 简称（≤30） |
| jobTitleCode | String | 职务编码（≤40） |
| jobCategoryId | String | **职务分类 ID** |
| jobCategoryName | String | **职务分类名称**（≤40，如"专业类"） |
| jobCategoryCode | String | 职务分类编码（≤40） |
| maxPositionGradeId | String | **职级上限 ID** |
| maxPositionGradeName | String | 职级上限名称（≤40） |
| minPositionGradeId | String | **职级下限 ID** |
| minPositionGradeName | String | 职级下限名称（≤40） |
| effectiveDate | Date | 生效日期 |
| positionSalaryGrade | String | 职务薪级 |
| description | String | 描述 |
| positonGradeList | Array | ⚠️ **拼写错误**，官方字段名为 `positonGradeList`（少一个 'i'），按实际返回名使用 |
| ↳ positionGradeNum | Integer | 职级级别 |
| ↳ positionGradeName | String | 职级名称 |
| ↳ jobCategoryId | String | 职务分类 ID |
| ↳ jobCategoryName | String | 职务分类名称 |
| updateDate | Date | 更新时间 |

## 接口 #20：获取职级清单

```
GET https://openapi.ihr360.com/openapi/thirdparty/api/org/v1/organizations/positiongrades
```

**描述**：获取公司下所有职级清单。GET 请求，无入参，返回全量数据（无分页）。

**鉴权**：Bearer token

### 请求参数

无。

### 响应字段

`data[]` 内每个对象：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 职级 ID |
| createdDate | Date | 创建日期 |
| companyId | String | 公司 ID |
| positionGradeNum | Integer | **职级级别**（数字，如 1, 2, 3...） |
| positionGradeName | String | **职级名称**（≤40，如 "p1", "p2", "m2"） |
| jobCategoryId | String | ⚠️ **已废弃** 旧职务分类 ID，请使用 gradeGroupId |
| jobCategoryName | String | ⚠️ **已废弃** 旧职务分类名称，请使用 gradeGroupName |
| gradeGroupId | String | **职级分组 ID**（≤40，推荐使用） |
| gradeGroupName | String | **职级分组名称**（推荐使用） |

```json
            "jobCategoryName": "专业类",

        {
            "positionGradeNum": 1,
            "positionGradeName": "m2",
            "jobCategoryName": "管理类",
            "gradeGroupId": ""
        },
        {
            "positionGradeNum": 2,
            "positionGradeName": "p2",
            "jobCategoryName": "专业类",
            "gradeGroupId": ""
        }
    ],
    "code": 0,

```

> ⚠️ 文档明确标注 `jobCategoryId` 和 `jobCategoryName` 已废弃，建议使用 `gradeGroupId` 和 `gradeGroupName`。但当前示例中 `gradeGroupId` 返回空字符串，说明数据迁移可能尚未完成。

## 接口 #21：获取体系表清单

```
GET https://openapi.ihr360.com/openapi/thirdparty/api/org/v1/gradesystem/all
```

**描述**：获取公司下职级体系表清单。更高层级的组织归类视图——将职级按 **序列 → 子序列 → 职层 → 职级** 进行归类。

**鉴权**：Bearer token

### 请求参数

无。

### 响应字段

`data[]` 内每个对象：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 职级体系 ID |
| companyId | String | 公司 ID |
| sequenceId | String | **序列 ID**（最顶层归类，如"技术类"） |
| sequenceName | String | 序列名称 |
| sequenceChildId | String | **子序列 ID** |
| sequenceChildName | String | 子序列名称 |
| gradeLevelId | String | **职层 ID**（高一层级归类） |
| gradeLevelName | String | 职层名称 |
| positionGradeId | String | **关联职级 ID**（对应 #20 的职级） |
| positionGradeName | String | 职级名称（如 "P5"） |
| status | Boolean | 状态：true=有效，false=无效 |
| applyRanges | List | 适用岗位、职务列表 |
| applyRange | String | 适用职位、职务 |

### ⚠️ 字段名差异

参数表描述中写的是 `createdDate`（创建时间），但实际返回的是 `createdAt`/`updatedAt`。开发时建议以实际返回为准，注意兼容处理。

### 体系表层级结构

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  序列     │ →  │ 子序列    │ →  │  职层     │ →  │  职级     │
│(sequence) │    │(sChild)  │    │(gLevel)  │    │(pGrade)  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
    技术类           15            (null)           P5
    管理类           12            高级              M3
```

### 响应示例

⚠️ 实际返回字段为 `createdAt`/`updatedAt`（而非文档中的 `createdDate`）：

## 三接口关键注意点

| 注意项 | #19 职务清单 | #20 职级清单 | #21 体系表清单 |
|--------|------------|------------|--------------|
| 请求方式 | GET | GET | GET |
| 分页 | 无 | 无 | 无 |
| 字段问题 | `positonGradeList` 拼写错误 | `jobCategoryId/Name` 已废弃 | `createdAt` vs `createdDate` 差异 |
| 特有结构 | 含上下职级范围 + 职级列表 | 含职级分组信息 | 四层树形归类 |
