# 部门

> 包含接口：#9（获取部门清单v3）、#13（部门详情-批量）、#14（获取部门字段设置信息）

## 接口 #9：获取部门清单v3

```
POST https://openapi.ihr360.com/openapi/thirdparty/api/org/v1/organizations/search
```

**描述**：获取公司部门清单，支持分页查询，支持通过部门状态、部门编码、部门名称筛选。

**鉴权**：Bearer token

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| page | body | int | 否 | 0=第一页，以此类推 |
| size | body | int | 否 | 每页条数 |
| flexSearchItems | body | Array | 否 | 字段查询条件数组 |
| ↳ searchKey | String | 否 | 搜索字段名（如 `departmentName`, `departmentCode`, `departmentStatus`） |
| ↳ searchParam | String | 否 | 搜索值 |
| ↳ searchType | String | 否 | `EQUAL`=等于, `LIKE`=模糊, `IN`=包含 |

### 请求示例

```json
{
  "page": 0,
  "size": 10,
  "flexSearchItems": [
    {
      "searchKey": "departmentName",
      "searchParam": "DD11",
      "searchType": "EQUAL"
    }
  ]
}
```

### 响应字段

**响应元数据**：

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| message | String | 状态消息 |
| errorResult | Boolean | 错误标记 |
| data.totalPages | long | 总页数 |
| data.totalElements | long | 总元素数 |
| data.end | Boolean | 是否最后一页 |
| data.content | Array | 部门列表 |

**content[] 字段清单**：

| 字段 | 类型 | 说明 |
|------|------|------|
| uuid | String | 部门主键 UUID |
| id | Long | 部门 ID |
| name | String | 部门名称（最大 128 字符） |
| parentId | Long | 上级部门 ID（-1=无上级） |
| type | String | 部门类型：`COMPANY`/`DEPARTMENT`/`STORE` |
| departmentCode | String | 部门编码 |
| storeNumber | String | 门店编号 |
| principalStaffId | String | 部门负责人 ID |
| parentDepartmentCode | String | 上级部门编码 |
| parentDepartmentName | String | 上级部门名称 |
| virtual | Boolean | 是否虚拟节点 |
| departmentStatus | String | 部门状态：`ENABLE`/`DISABLE` |
| departmentDesc | String | 组织描述 |
| departmentProperty | String | 组织属性（codeTypeId=Enum.DepartmentProperty） |
| lastUpdate | String | 最后更新时间 |
| createdDate | Date | 创建时间（Unix 毫秒时间戳） |
| abbreviation | String | 简称 |
| establishDate | String | 设立日期 |
| effectiveDate | String | 生效日期 |
| remark | String | 备注 |
| sequence | Long | 顺序 |
| customField01~10 | String | 自定义字段1~10（值为 null/空字符串时不返回） |

## 接口 #13：部门详情（批量）

```
POST https://openapi.ihr360.com/openapi/thirdparty/api/org/v1/organizations/list
```

**描述**：根据部门 ID 列表批量获取部门详情。请求体直接传部门 ID 数组，非分页、非搜索。

**鉴权**：Bearer token

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| departmentId | body | Array\<Long\> | **是** | 部门 ID 列表 |

### 请求示例

```json
[0, 1]
```

### 响应字段

`data[]` 直出数组（无 `content` 分页包裹）。

| 字段 | 类型 | 说明 |
|------|------|------|
| uuid | String | 部门主键 UUID |
| id | Long | 部门 ID |
| departmentCode | String | 部门编码 |
| storeNumber | String | 门店编号 |
| name | String | 部门名称（≤128） |
| parentId | Long | 上级部门 ID（-1=无） |
| parentDepartmentCode | String | 上级部门编码 |
| parentDepartmentName | String | 上级部门名称 |
| principalStaffId | String | 部门负责人 ID |
| virtual | Boolean | 是否虚拟节点 |
| costName | String | 成本中心名称 |
| costCode | String | 成本编码 |
| departmentStatus | String | ENABLE/DISABLE |
| type | String | COMPANY/DEPARTMENT/STORE |
| companySiteId | String | 工作地点 ID |
| companySiteName | String | 工作地点名称 |
| departmentDesc | String | 组织描述 |
| departmentProperty | String | 组织属性 |
| abbreviation | String | 简称 |
| establishDate | String | 设立日期 |
| effectiveDate | String | 生效日期 |
| remark | String | 备注 |

### 与 #9 获取部门清单v3 的对比

| 维度 | #9 获取部门清单v3 | #13 部门详情（批量） |
|------|-------------------|---------------------|
| 请求体 | 分页 + flexSearchItems 筛选 | 部门 ID 数组（如 `[0, 1]`） |
| 返回结构 | `data.content[]` 分页包裹 | `data[]` 直出数组 |
| 适用场景 | 按名称/编码/状态搜索 | 已知 ID 拿完整信息 |
| 特有字段 | `createdDate`, `lastUpdate`, `sequence`, `customField01~10` | `costName`, `costCode`, `companySiteName` |

## 接口 #14：获取部门字段设置信息

```
GET https://openapi.ihr360.com/openapi/thirdparty/api/org/v1/metadata
```

**描述**：查询部门字段设置信息，获取部门字段设置下所有字段的定义、类型、限制等信息。  
**用途**：在调用创建/更新部门接口前，先查元数据，确认后台哪些字段被设为必填，避免请求被拒。

**鉴权**：Bearer token

**请求方式**：GET，无需请求体。

### 响应字段

`data[]` 内每个对象：

| 字段 | 类型 | 说明 |
|------|------|------|
| columnName | String | 字段名（如 `departmentName`, `departmentCode`） |
| displayName | String | 字段中文名称（如"组织名称", "部门编码"） |
| isRequired | Boolean | **字段是否必填**（受后台配置影响） |
| isValid | Boolean | 是否有效 |

### 必填字段一览（共 16 个字段）

| columnName | displayName | isRequired |
|-----------|-------------|:----------:|
| parentDepartmentId | 上级组织 | ✅ |
| departmentName | 组织名称 | ✅ |
| organizationChartNodeType | 组织类别 | ✅ |
| establishDate | 设立日期 | ✅ |
| isVirtual | 虚拟组织 | ✅ |
| departmentCode | 部门编码 | ✅ |
| storeNumber | 门店编号 | ✅ |
| abbreviation | 简称 | ✅ |
| preparationNumber | 直属编制人数 | ❌ |
| effectiveDate | 生效日期 | ❌ |
| principalStaffId | 部门负责人 | ❌ |
| companySiteId | 工作地点 | ❌ |
| costCenterCode | 成本中心 | ❌ |
| departmentProperty | 组织属性 | ❌ |
| departmentDesc | 组织描述 | ❌ |
| remark | 备注 | ❌ |
