# 社保缴纳方案集合

> 接口编号：#72  
> 端点：`GET /openapi/thirdparty/api/insurance/v1/CompanyBenefits`  
> 鉴权：Bearer access_token

---

## 描述

获取公司的社保缴纳方案集合，包含**社保方案**、**公积金方案**和**其他福利方案**三组。GET 请求，无参数。

---

## 请求参数

无

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Object | 福利方案集合 |

### data 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| siBenefitList | Array | **社保方案列表** |
| hfBenefitList | Array | **公积金方案列表** |
| otherBenefitList | Array | **其他福利方案列表** |

### 方案对象字段

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 方案 ID |
| name | String | 方案名称（如"上海市-社保"） |
| divisionId | String | 地区 ID |
| provinceCode | String | 省份代码（如 `310000`） |
| cityCode | String | 城市代码（如 `310100`） |
| areaCode | String | 地区代码 |

## 注意事项

1. `siBenefitList`、`hfBenefitList`、`otherBenefitList` 可能为 null（无对应方案时）
2. 方案名称中通常包含城市信息（如"上海市-社保"）
3. 对应 #38 入职字段定义中的 `SI_BENEFIT`(社保方案) 和 `HF_BENEFIT`(公积金方案) 字段类型
