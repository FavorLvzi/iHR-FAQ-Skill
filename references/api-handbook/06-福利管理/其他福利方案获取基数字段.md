# 其他福利方案获取基数字段

> 接口编号：#75  
> 端点：`GET /openapi/thirdparty/api/insurance/v1/payBaseHeaders/query/OTHER`  
> 鉴权：Bearer access_token

---

## 描述

获取公司其他福利方案的基数字段信息（如企业年金）。与 #73（社保）、#74（公积金）组成完整的福利基数字段系列。

---

## 福利基数字段系列（全集）

| 接口 | 路径后缀 | 类型 | headerName 示例 |
|------|---------|------|----------------|
| #73 | `/query/SI` | 社保 | 社保申报基数 |
| #74 | `/query/HF` | 公积金 | 住房公积金申报基数 |
| **#75** | **`/query/OTHER`** | **其他福利** | **企业年金申报基数** |

---

## 请求参数

无

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Array | 基数字段列表 |

### data[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| headerId | String | 基数 ID（如 `OTHER_TYPE_0001_PB`） |
| headerName | String | 基数名称（如"企业年金申报基数"） |
| required | Boolean | 是否必填 |

---

## 响应示例

```json
{
    "data": [
        {
            "headerId": "OTHER_TYPE_0001_PB",
            "headerName": "企业年金申报基数",
            "required": false
        }
    ],
    "code": 0,
    "message": "SUCCESS",
    "errorResult": false
}
```
