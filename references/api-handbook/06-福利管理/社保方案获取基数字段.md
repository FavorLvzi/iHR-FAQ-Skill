# 社保方案获取基数字段

> 接口编号：#73  
> 端点：`GET /openapi/thirdparty/api/insurance/v1/payBaseHeaders/query/SI`  
> 鉴权：Bearer access_token

---

## 描述

获取公司社保方案的基数字段信息（如"社保申报基数"）。与 #74（公积金）、#75（其他福利）为同一系列。

---

## 福利基数字段接口系列

| 接口 | 端点路径后缀 | 类型 |
|------|------------|------|
| **#73** | `/query/SI` | 社保 |
| #74 | `/query/HF`（推断） | 公积金 |
| #75 | `/query/OTHER`（推断） | 其他福利 |

---

## 请求参数

无

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| code | int | 0=成功 |
| data | Array | 基数字段列表 |

### data[]. 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| headerId | String | 基数 ID（如 `SI_PB`） |
| headerName | String | 基数名称（如"社保申报基数"） |
| required | Boolean | 是否必填 |

---

## 响应示例

```json
{
    "data": [
        {
            "headerId": "SI_PB",
            "headerName": "社保申报基数",
            "required": true
        }
    ],
    "code": 0,
    "message": "SUCCESS",
    "errorResult": false
}
```
