## 模块说明

操作日志为**跨业务模块的审计接口**，通过 `operationModule` 指定业务域（考勤打卡、任务管理等），按时间窗查询该模块下的操作动作。用于"数据对不上"时的溯源：确认打卡/数据是否被 HR 删除或 OpenAPI 改写。

注意：`subjectName` 为通用操作描述，**不含员工姓名**；要落到具体人需结合各业务取数接口（如 #91 打卡记录）交叉定位。
