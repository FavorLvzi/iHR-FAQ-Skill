# 事假流程定义获取 · 完整技术链路（2026-08-12 用户实测文档为准）

> 本文档演示"查 XX 审批流程"的**完整调用链路**（鉴权 → 定位 → 定义 → 解析），宿主 AI 处理同类问题时按此路径执行。数据为某环境实测值，**ID 因环境而异，每次现查勿硬编码**。

## 一、鉴权（二方 Gateway，与 OpenAPI 不同域）

- Base URL: `https://v5.ihr360.com`
- Header: `Authorization: Bearer {IHR360_API_TOKEN}`（宿主自动注入，格式 `sk-irs-*`）
- 与 OpenAPI OAuth 不互通：OAuth token 调二方接口返回 401

## 二、定位审批类型（★首选，宿主 Bearer 实测可用）

```
GET /gateway/workflow/aggregate/approval/setting/findApprovalGroupVo
```

响应（提取关键字段）：

```json
{
  "code": 0,
  "data": [
    {
      "groupName": "考勤假期",
      "groupType": "GROUP_ATTENDANCE",
      "approvalSettingListVos": [
        {
          "id": "423fa64b-e395-475f-a75e-a3e78736e0ef",  // ★approvalSettingId
          "name": "事假",
          "suiteType": "AFFAIR_LEAVE",
          "processUniqueId": "992311842896621568",       // #106 单据过滤（Long）
          "formId": "fba994d8-7958-4b84-90aa-896d5303c424",
```

按 name 筛选目标类型 → 拿三件套 ID。

## 三、获取流程定义（★已发布，无并发锁）

```
GET /gateway/workflow/aggregate/approval/setting/{approvalSettingId}
（备选：draft/{id} 草稿版，可能被"已被其他管理员修改"拦截）
```

响应顶层：`basicSettingVo`（基础配置）/ `processSettingVo`（流程节点★核心）/ `formVo`（表单字段）/ `advancedSettingVo`（高级设置+抄送）。

## 四、解析流程节点（processSettingVo）

- **结构**：`childNode` 链表（Start → Task → ...）
- **nodeType**：Start / Task / Gateway / ParallelGateway / AggregationGateway / ManualTask / HandleTask（办理人）
- **signType**：SEQUENT_SIGN 逐级 / JOINTLY_SIGN 会签 / TURN_SIGN 连续多级 / **SINGLE_SIGN 单人**
- **approverType**：STAFF / REPORT_TO / DIVISION_DIRECTOR / STAFF_GROUP / APPLICANT / POSITION
- **nodeUserSettings**：dataName（人员/职位名）+ approverType + seqNo + levelSelectOrder（BOTTOM_UP/TOP_DOWN）+ endLevel 等

## 五、解析表单字段（formVo.formDetail）

字段带 `inheritCode` + `type`（REFERENCE / DATE_DURATION / REFERENCE_NUMBER / TEXTAREA / IMAGE / FILE 等）。

## 六、解析高级设置（advancedSettingVo）

`preCcList` 前置抄送 / `postCcList` 后置抄送（事假无抄送，皆空）。

## 七、事假流程最终结构（实测）

```
流程走向：开始 → 指定员工(离职测试1) 会签审批 → 结束
审批类型: 事假 (AFFAIR_LEAVE) | 版本 V2 | 前置抄送无 | 后置抄送无
审批节点: Task 会签(JOINTLY_SIGN) 指定员工(STAFF): 离职测试1
表单字段: 事假信息(REFERENCE)/开始时间(DATE_DURATION)/生效时长(REFERENCE_NUMBER)/申请事由(TEXTAREA)/图片(IMAGE)/附件(FILE)
```

## 八、输出

解析后按「流程图输出格式」输出 Mermaid `flowchart TD`（命中分支填色高亮、未命中淡紫、嵌套用 subgraph）。

## 关键注意

1. draft 有并发锁（未发布草稿时拦截）；**已发布接口 setting/{id} 无锁，首选**
2. 解锁草稿：`hasUnPublishDraft/{id}` → `draft/{draftSettingId}`
3. 条件分支：事假无条件分支；补卡/请假等复杂流程有 conditionNodes 数组
4. **ID 因环境而异**：approvalSettingId / processUniqueId 每次用 findApprovalGroupVo 现查
