# 示例：员工X 2026-07-29 考勤日报 · 全字段 + 计算推导

> ⚠️ **测试环境数据警告（最高优先级）**：本文件中的员工"员工X"及其考勤数据均为**测试环境数据**，仅用于演示思考方法论，**不是任何客户公司的真实员工**。**严禁**将本文件中的姓名、staffId、任何数值（出勤/缺勤/假期等）出现在面向客户的回答、报告或页面中。客户数据必须从客户当前环境实时查询获取。

> 本示例演示"思考引导型"回答如何落到真实数据上。本文为 skill 内置参考（数据快照），原完整报告页面已清理，实际查询时按本文方法论现场拉取。

## 一、问题

"给出员工员工X昨日的考勤日报数据，并说明对应计算逻辑（尽可能取到所有考勤日报字段）。"

## 二、调用链路（真实 API）

```
1. OAuth：POST /openapi/oauth/token  + Basic(AppID:AppSecret)
          + grant_type=client_credentials  →  Bearer token（有效期 2h）
2. 定位员工：#1 在职员工ID清单（62人）→ #28 批量任职记录（staffName 匹配）
          → 员工X（同一人 3 部门任职）
3. #93 获取日报V4：signDate=2026-07-29, staffIdList=[员工X]
4. #96 获取日报自定义字段：取 formula（确认是否被改写）
5. #79 获取所有假期类型 v2：将 customizedLeave 的 leaveTypeId 映射为中文假期名
6. #91 获取打卡记录：signTime=2026-07-29 → 佐证实际出勤小时=0
```

> 报告展示时已脱敏：不显示员工ID、接口编号、班次/部门等非公式配置项。

## 三、关键结论数据

| 字段(中文) | 字段(英文) | 值 | 计算逻辑推导 |
|-----------|-----------|----|------------|
| 应出勤小时数 | supposedAttendanceHours | **8.0** | 完全由班次"朝九晚五"决定（9-12 / 13-17，扣休息） |
| 实际出勤小时数 | actualAttendanceHours | **0.0** | 打卡∩班次 = 空∩班次 = 0；封顶 min(0, 8) = 0 |
| 缺勤小时数 | absenceHours | **8.0** | 缺勤班段：应出勤 8h −（出差/外出/请假 0 + 休息 0）= 8h |
| 缺勤次数 / 分钟 | absenceTimes / absenceMinutes | 1 / 480 | 上下班均未打卡；480min = 8h |
| 迟到 / 早退 | late* / early* | 0 / 0 | 全天缺卡归为缺勤，覆盖迟到早退判定 |
| 加班 / 标准假期 / 出差外出 | 全部 | 0 | 无任何单据 |
| 自定义假期 | customizedLeave | 共 7 项，均为 0.0 | 通过 #79 映射 leaveTypeId → 中文名，如"季度假期"、"自定义育儿假"等 |

**打卡佐证**：#91 查询 2026-07-29 打卡记录 = **0 条**，坐实"实际出勤小时=0"是因为当天确实没打卡。

## 四、自定义字段验证（关键）

#93 返回 13 个 `dailyCustomField`，公式取自 #96。其中：

- `actualAttendanceHours` / `lateMinutes` / `earlyMinutes` 三个以**同名覆盖系统字段** —— 印证"标准字段可被自定义字段引用/改写"。
- 一例测试公式缺陷：*迟到扣款金额* 的 else 分支写死 `100`，导致"缺勤"被误算成"迟到扣款 100 元"。

> 印证硬规则：**系统标准字段公式只走文档（help）；自定义字段公式 + 值走 API（#96 可取明文 formula）**。

## 五、口径对照（与 attendance-field-logic.md 一致）

1. 应出勤小时数 = 班次决定 → 8 ✅
2. 实际出勤小时数 = 打卡∩班次 − 休息，封顶 min(值, 应出勤) → 0 ✅
3. 实际出勤天数 = 实际出勤小时 ÷ 应出勤小时（月报才聚合）→ 0÷8 = 0 ✅
4. 缺勤小时数 = 应出勤 −（出差/外出/请假 + 休息）→ 8 ✅

## 六、本示例教 AI 的

- 真实数据能一眼验证"封顶""缺卡归缺勤"等规则，比纯文档更扎实。
- 自定义字段改写 + 公式缺陷，是"必须查 API 而非背公式"的最强证据。
- 月报维度（实际出勤天数 / 排休天数 / 出勤班次）需另做同款验证。
